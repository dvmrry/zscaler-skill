# Which UVM connectors and data flows the technology-partner deployment guides describe (shared.technology-partners.uvm)
Also called: uvm partner connectors; uvm technology partners; preconfigured uvm connectors

In the Armis guide, UVM offers these preconfigured Armis connectors: Armis Devices (retrieves information about the discovered devices, including their attributes and states) and Armis Common Vulnerabilities and Exposures (CVE) (retrieves vulnerability data related to devices, including matched device details). [shared.technology-partners.uvm:armis-connectors] The partner guide pages are routed from [Zscaler technology partner guides: which subject holds which partner guides (split by partner name, not strictly by product)](kb:shared.technology-partners).

**Cloud and application security connectors.** In the Arnica guide, UVM offers an "Arnica Miconfigs" preconfigured Arnica connector, which retrieves misconfigurations in your projects. [shared.technology-partners.uvm:arnica-connector] In the Apiiro guide, UVM offers a preconfigured Apiiro connector for Apiiro Secrets, which focuses on managing and securing access to sensitive information within applications. [shared.technology-partners.uvm:apiiro-connector] In the Snyk guide, UVM offers two preconfigured Snyk connectors: Snyk Connector (retrieves Software Composition Analysis (SCA) vulnerabilities discovered in project dependencies) and Snyk SAST Connector (Static Application Security Testing (SAST) retrieves potential vulnerabilities discovered by analyzing source code). [shared.technology-partners.uvm:and-snyk] In the Wiz guide, UVM offers preconfigured Wiz connectors: Wiz Vulnerability Findings, Wiz Issues (details on active security threats) and Wiz Configuration Findings (details on configurations by identifying misconfigurations). [shared.technology-partners.uvm:and-wiz] In the Orca Security guide, UVM offers preconfigured connectors for Orca Security: Orca Alerts, Orca Common Vulnerability and Exposures (CVEs), Orca Assets and Orca Vulnerabilities; Orca Vulnerabilities data can optionally be combined with AWS EC2 tag information. [shared.technology-partners.uvm:and-orca-security] In the Fortinet guide, UVM offers three preconfigured Fortinet Lacework connectors: Lacework, Lacework Compliance AWS and Lacework Compliance GCP. [shared.technology-partners.uvm:fortinet-lacework-connectors] The Microsoft Services guide lists these key UVM integrations: Microsoft Defender for Cloud (findings), Microsoft Intune (audit events and asset data), Microsoft Defender for Endpoint (alerts, vulnerabilities and software insights by machine), and Azure Cloud Assets and Azure Blob. [shared.technology-partners.uvm:and-microsoft-services]

**Asset and vulnerability connectors.** In the Qualys guide, Qualys Vulnerabilities data can optionally be combined with Zscaler Client Connector device information. [shared.technology-partners.uvm:and-qualys] In the Tenable guide, Tenable Vulnerability Management data can optionally be combined with Zscaler Client Connector device information. [shared.technology-partners.uvm:and-tenable] In the Rapid7 guide, Zscaler Nanolog Streaming Service (NSS) retrieves logs from the Zscaler cloud and sends them into InsightIDR; separately, UVM has connectors for InsightVM Vulnerabilities, Rapid7 InsightVM Assets, Rapid7 InsightCloudSec Assets and Rapid7 InsightCloudSec Findings. [shared.technology-partners.uvm:and-rapid7] The Tanium guide describes how to deploy Zscaler Client Connector to Windows devices using Tanium's Deploy module; it also says UVM offers preconfigured Tanium AEM connectors: Tanium Assets, Tanium Compliance and Tanium CVE. [shared.technology-partners.uvm:uvm-and-tanium] In the Horizon3.ai guide, UVM offers these preconfigured Horizon3 NodeZero connectors: Horizon3 Assets, Horizon3 Flat Impacts and Horizon3 Weaknesses Evidence. [shared.technology-partners.uvm:horizon3-connectors]

**Non-UVM facts from the same guides (Client Connector asset data and logs, ZIA NSS, Client Connector deployment).** In the Armis guide, the Zscaler and Armis integration periodically connects to the Zscaler cloud and retrieves asset details on devices connected via Zscaler Client Connector, and the Zscaler service sends continuous traffic logs to the integration for retrieving traffic and service metadata. [shared.technology-partners.uvm:armis-zcc-assets]

**Risk rating connectors.** In the Bitsight guide, UVM offers these preconfigured Bitsight connectors: Bitsight Findings (security-related events or configurations on an asset) and Bitsight Observations (risk category data of companies in your portfolio). [shared.technology-partners.uvm:bitsight-connectors] In the SecurityScorecard guide, UVM offers preconfigured SecurityScorecard connectors: SecurityScorecard (information about security issues or vulnerabilities detected) and SecurityScorecard Alerts (notifications or alerts about potential security incidents or suspicious activities received in your SecurityScorecard account). [shared.technology-partners.uvm:uvm-and-securityscorecard]
