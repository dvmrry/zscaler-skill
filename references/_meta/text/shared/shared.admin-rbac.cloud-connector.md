# Cloud & Branch Connector admin roles: super admin, the eleven permission categories and Unified RBAC (shared.admin-rbac.cloud-connector)
Also called: cloud connector admin roles; branch connector admin roles; cloud and branch connector role management; cbc admin permissions; cloud connector super admin; api key management permission; remote assistance management permission

A Cloud & Branch Connector admin has a role, and each role sets a permission in each of a fixed set of categories. On the About Role Management page for the Role Management page at Administration > Role Management > Branch and Cloud Connector, Zscaler provides a default super admin role with full access to the portal, assigned to the default admin and assignable to other admins; every additional role must have its access defined by permissions. [shared.admin-rbac.cloud-connector:super-admin] A role sets permissions in these categories: Dashboard, Template (Location & Provisioning), Location Management, API Key Management, NSS Logging, Cloud Connector Provisioning, Administrator Management, Forwarding (Traffic, DNS & Logs), Remote Assistance Management, Public Cloud Config Management and VDI Provisioning. [shared.admin-rbac.cloud-connector:categories]

**Where roles are managed.** Roles are listed on the Role Management page (Administration > Role Management > Branch and Cloud Connector), whose columns include Full Access (the areas of the Admin Console where admins with the role have full access) and Type (for example Cloud Connector Admin). [shared.admin-rbac.cloud-connector:role-page] Where the organization uses Unified RBAC, administrator roles for Cloud & Branch Connector are managed on a different Role Management page; Unified RBAC is a feature in limited availability, reached through the Zscaler Account team. [shared.admin-rbac.cloud-connector:unified-rbac] On the Unified RBAC Create Role page, Branch Connector Groups, Branch Connectors and Cloud Connector Group are listed under the Private Access category, in its Policy Management subcategory. [shared.admin-rbac.cloud-connector:unified-rbac-permissions] The Unified RBAC role model is in [Unified RBAC: Admin Console roles, access levels, permission categories, scopes, assignments and obfuscation](kb:shared.admin-rbac.unified). If the organization is subscribed to Authentication Service, some of the Role Management options are configurable only in the Zscaler Admin Console, and for Authentication Service-enabled tenants admin roles must be assigned in the Zscaler Admin Console. [shared.admin-rbac.cloud-connector:auth-service] Configuring roles requires the proper permissions and organizational scope. [shared.admin-rbac.cloud-connector:prerequisites]

**What each category covers.** Dashboard access lets admins view the predefined dashboards, including Logs and Insights; the page lists View Only (view all dashboards) and None (no access to dashboards). [shared.admin-rbac.cloud-connector:dashboard] Template (Location & Provisioning) lets admins create and delete location templates and provisioning templates; its View Only level allows viewing but not editing. [shared.admin-rbac.cloud-connector:template] Location Management lets admins view and edit locations; its None level gives no access to locations. [shared.admin-rbac.cloud-connector:location-mgmt] API Key Management lets admins view, remove, edit or regenerate the base URL and key; its View Only level shows the key without letting the admin edit, remove or regenerate it. [shared.admin-rbac.cloud-connector:api-key-mgmt] NSS Logging lets admins add NSS servers, deploy NSS virtual appliances, download MIB files and view NSS feeds; the page lists the levels Full and None for it. [shared.admin-rbac.cloud-connector:nss-logging] Cloud Connector Provisioning lets admins add Cloud Connector groups, access deployment templates and access Branch Connector images. [shared.admin-rbac.cloud-connector:provisioning] Administrator Management lets admins add other admins, search for configured admins and view a list of all admins configured for the organization. [shared.admin-rbac.cloud-connector:admin-mgmt] Forwarding (Traffic, DNS & Logs) gives admins access to DNS Policies, Traffic Forwarding, Gateways and Log & Control Forwarding, and lets them define firewall filtering rules in Network Services and IP & FQDN Groups. [shared.admin-rbac.cloud-connector:forwarding] Remote Assistance Management lets admins allow Zscaler Support to log in to the Admin Console; the page lists the levels Full and View Only for it. [shared.admin-rbac.cloud-connector:remote-assistance-perm] Public Cloud Config Management lets admins create, edit, delete and view Partner Integrations; the page says to contact Zscaler Support to enable this feature. [shared.admin-rbac.cloud-connector:public-cloud-config] VDI Provisioning lets admins manage Client Connector for VDI operations; its Full level allows editing and viewing all Client Connector for VDI entities. [shared.admin-rbac.cloud-connector:vdi]

What to check:
1. For an admin who cannot open a Cloud & Branch Connector page, the role's permission in the category that covers it; whether the tenant uses Unified RBAC, where roles are managed on another page; and, for Authentication Service tenants, that admin roles are assigned in the Zscaler Admin Console.
2. For an admin who cannot view or change the API key, the role's API Key Management permission.
3. For an admin who cannot enable remote assistance for Zscaler Support, the role's Remote Assistance Management permission.
