# What the technology-partner guides for Client Connector, ZPC, ZDX, SaaS security and ZPA connectivity (SAP, Autopilot) say each partner integration does (shared.technology-partners.other)
Also called: client connector partner guides; iac scan partner guides; zdx saas partner guides

The Imprivata guide describes how to install Zscaler Client Connector in both EXE and MSI formats on the Imprivata Enterprise Access Management shared workstation; specific options are required but the installation is otherwise standard, and additional CLI options can be used as needed. [shared.technology-partners.other:imprivata-installers] The partner guide pages are routed from [Zscaler technology partner guides: which subject holds which partner guides (split by partner name, not strictly by product)](kb:shared.technology-partners).

**Client Connector.** In the Jamf guide, Zscaler Client Connector captures and uses Device Posture Profile criteria in policy decisions for both ZIA and ZPA, and the guide explains how Client Connector uses the device's risk score as determined by the Jamf Trust app. [shared.technology-partners.other:jamf-trust-risk-score] In the Google ChromeOS Flex guide, Zscaler supports ChromeOS Flex for managed devices through Google's ChromeOS device management, which is accessible through the Google Admin console, and the guide allows organizations to deploy and run Zscaler Client Connector for ChromeOS Flex. [shared.technology-partners.other:chromeos-flex-client-connector] The DataBee integration with Zscaler is for compliance tracking, for example highlighting non-compliant users who turn off the Zscaler Client Connector, and fetches a list of enrolled devices within the organization using the Zscaler Client Connector API. [shared.technology-partners.other:databee-zcc-api]

**Zscaler Posture Control and IaC scan.** In the Microsoft Azure DevOps guide, integrating the Zscaler IaC Scan app with Azure Repos enables the IaC Scan app to scan and monitor Infrastructure as Code (IaC) files for misconfigurations; the IaC Scan tool scans the IaC templates for misconfigurations and known vulnerabilities. [shared.technology-partners.other:azure-devops-iac-scan] In the Jenkins guide, the ZPC IaC Scan app scans and identifies security misconfigurations in the IaC Terraform, Helm, Kubernetes and CloudFormation templates for both freestyle and pipeline jobs in Jenkins, and the IaC Scan plugin automatically triggers a scan and displays the scan results within the code. [shared.technology-partners.other:jenkins-iac-templates]

**ZPA connectivity.** The Microsoft Windows Autopilot guide covers the approach where Windows Autopilot with Hybrid Azure AD leverages ZPA for connectivity to on-premises AD during the enrollment process. [shared.technology-partners.other:and-microsoft-windows-autopilot] Zscaler and SAP Enterprise Cloud Services (ECS) created an ECS-managed service that deploys App Connectors inside a customer's ECS-managed service environment on the AWS, Azure or GCP hyperscalers, giving zero trust connectivity from desktop-based client devices to the SAP applications running in the ECS environment. [shared.technology-partners.other:and-sap]

**SaaS security and ZDX.** ZDX for Zoom allows IT to monitor calls or meetings among two or more participants; the Zoom quality of service dashboard uses the Mean Opinion Score (MOS) as the main measurement of voice quality and can filter data by any extension. [shared.technology-partners.other:and-zoom] The Microsoft SharePoint Online guide covers these SharePoint ZIA security and ZDX performance visibility integrations: SaaS Security Data Loss Prevention (DLP), SaaS Security Malware Detection, SSL Decryption, Cloud Application Access Control and ZDX for SharePoint. [shared.technology-partners.other:and-microsoft-sharepoint-online] In the Salesforce guide, ZIA provides Salesforce SaaS security by using access control, identity control, SaaS security posture management, Data Loss Prevention (DLP) and a SaaS API to scan Salesforce attachments for malicious content; the ZDX service provides user-specific experience monitoring and visibility to the Salesforce service. [shared.technology-partners.other:and-salesforce] The ServiceNow guide covers SaaS Identity Proxy, Isolation, SaaS Security Data Loss Prevention, SaaS Security Malware Detection, Cloud Application Access Control, ZDX for ServiceNow and Zscaler Cloud Protection (ZCP) ServiceNow Incident Creation. [shared.technology-partners.other:and-servicenow] In the Slack guide, ZIA SaaS security and ZDX SaaS monitoring operate as separate stand-alone services that are not dependent on one or the other; the guide covers SaaS Identity Proxy, Tenant Restrictions, SaaS Security Data Loss Protection, SaaS Security Malware Detection, Cloud Application Access Control and ZDX for Slack. [shared.technology-partners.other:and-slack]

**Other platforms.** The SentinelOne guide configures integrations between the Zscaler Zero Trust Exchange (ZTE) and the SentinelOne Singularity Platform, where Hyperautomation extends this by orchestrating policy changes across Zscaler and SentinelOne; its linked video list includes "Zscaler UVM and SentinelOne Integration Demo". [shared.technology-partners.other:and-sentinelone] The Securonix guide describes how to deploy Zscaler security log data in the Securonix SNYPR application, and to integrate Zscaler features with it. [shared.technology-partners.other:and-securonix]
