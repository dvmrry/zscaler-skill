# Real User Monitoring in ZDX: prerequisites, the Real User Score and the RUM views (zdx.applications.rum)
Also called: real user monitoring; rum; real user score; real-user performance; core web vitals; rum browser extension; rum errors tab

Real User Monitoring is the capture of metrics on user interactions with applications through their web browsers, alongside the synthetic probes of [ZDX probes: Web and Cloud Path probes, what they measure and how they run](kb:zdx.probes); the application settings it is enabled in are in [ZDX applications: predefined, custom and network applications, and the application API](kb:zdx.applications). Real User Monitoring captures metrics for analyzing user interactions with applications through their web browsers on Windows and macOS devices, for Single-Page Applications or Multi-Page Applications, with web page metrics such as Page Fetch Time, Page Loading Time and Core Web Vitals (Largest Contentful Paint). [zdx.applications.rum:rum-what]

**Prerequisites.** RUM needs an appropriate subscription level (the subscription table supports Real User Monitoring only on Advanced Plus), the appropriate permissions for a ZDX role to configure applications and to view user information and the performance dashboard, the appropriate version compatibility for Client Connector and ZDX Module, the latest RUM browser extension on the device's browser (Chrome Web Store: Zscaler Real User Monitoring (RUM); Microsoft Edge Add-ons: RealTimeUserMonitoring), and ZUpmApplication.exe allowlisted on the device. [zdx.applications.rum:rum-prerequisites] RUM configuration cannot continue on a device without the RUM browser extension, which a mobile device management solution such as Microsoft Intune can install on multiple devices; Zscaler recommends creating a custom RUM collection, RUM is enabled when an application is configured, and an alert rule can be configured for RUM. [zdx.applications.rum:rum-extension]

**Score.** If an application has RUM enabled its score is the Real User Score, the experience of all users accessing the RUM-enabled application across all locations during the selected time period, on a scale and categories similar to the ZDX Score; the Score Trend is based on ZDX Scores for synthetic monitoring only, on Real User Scores for Real-User Monitoring only, and on both when both are used. [zdx.applications.rum:rum-score] How the Real User Score is calculated is open [gap:zdx.applications.rum:real-user-score-calculation].

**In the console.** An application's details page shows the Summary, Real-User Performance and Errors tabs only with Real User Monitoring enabled, while Web Probe Performance and Network Probe Performance show either way; the Browsers filter is available only for RUM applications. [zdx.applications.rum:rum-tabs] The Real-User Performance tab evaluates page views, route changes, page load time and time to first byte; Most Viewed Pages lists each page's path URL with its average and 95th percentile page fetch time, and the Page Overview adds Total Requests, Resources, Resource Size, Uncompressed Resources, Uncached Resources, Number of Users, Total Errors, Largest Contentful Paint (LCP), Interaction to Next Paint (INP) and Cumulative Layout Shift (CLS). [zdx.applications.rum:rum-performance] RUM's Core Web Vitals metrics include First Contentful Paint, Total Blocking Time, Total Long Tasks (longest long task duration), Total Long Task Duration and users by Largest Contentful Paint, Interaction to Next Paint and Cumulative Layout Shift; the Top XHR and Fetch Analysis lists XMLHttpRequests and fetch calls with their average resource duration and average resource size. [zdx.applications.rum:rum-web-vitals] The Errors tab shows how many errors the application's page has encountered, as a graph of total errors, error rate and average error rate over time, switchable between JavaScript Errors and Network Errors views. [zdx.applications.rum:rum-errors] RUM data appears in the Applications Overview, Application Details, Users Overview, User Details and Performance Dashboard: for a selected RUM application the Performance Dashboard shows the Page Views and Load Time trend, with an indication that 95 percent of the page loading time is below an amount; the Users Overview shows the number of active RUM users, a distribution of Poor, Okay and Good Real-User Scores and each user's Real-User Score from 1 to 100; and the user page shows page load time, a page load and blocking time trend, and errors over time. [zdx.applications.rum:rum-where]
