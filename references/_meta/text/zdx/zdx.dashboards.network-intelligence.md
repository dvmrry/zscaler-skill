# Network Intelligence: ISP and ASN latency baselines, anomalies and severity (zdx.dashboards.network-intelligence)
Also called: network intelligence; network intelligence dashboard; isp latency baseline; asn latency; network anomaly; peer impact analysis; sankey isp view

Network Intelligence is the console view of ISP and ASN network behavior measured against a latency baseline. Network Intelligence provides end-to-end multi-path network visibility from Last Mile ISPs to the Zero Trust Exchange to applications. ZDX runs Cloud Path probes to gather network metrics such as latency and packet loss, establishes a baseline for network latency and compares performance against it, using ML-based algorithms to identify anomalies. [zdx.dashboards.network-intelligence:what-it-is] Network Intelligence needs a ZDX subscription level that supports it and View Only permission for the Network Intelligence Dashboard; the subscription table lists it as not supported on Standard, Microsoft 365 and Advanced and supported on Advanced Plus. [zdx.dashboards.network-intelligence:subscription]

**Overview and filters.** The opening overview shows network anomalies for the last 14 days as a total per 24-hour period, highlighting severe and medium issues across geolocations with more than 50 users, the top 5 cities by user count with their anomaly levels, and the top 5 ASNs by measured latency compared to a baseline. Interactions in these widgets do not apply to global filters. [zdx.dashboards.network-intelligence:overview-widgets] Network Intelligence filters by Zscaler Data Centers, Application, Zscaler Locations or Geolocations, and its time range offers 2, 4, 6, 12, 24 or 48 hours, Current or Custom. A rippling effect appears on the map for geolocations with more than 50 users, while for geolocations with fewer than 50 users anomalies are detected at runtime without the effect, and network data is not populated until a network anomaly geolocation is selected from the drill-down view. [zdx.dashboards.network-intelligence:filters-map]

**Legs.** The legs Network Intelligence analyzes are Client to Zero Trust Exchange (from the client's ISP to the Zero Trust Exchange, with a forward path from the ISP to the data center and a reverse path from the Zero Trust Exchange to the Last Mile ISP), Zero Trust Exchange to Application, Client to Application (Direct) and Client to Application (from the client's ISP to the application). [zdx.dashboards.network-intelligence:legs]

**Insight charts.** The User Experience & Network Insights charts filter to up to the top 5 ISPs or Zero Trust Exchanges with the highest number of probes and show P50 and P95 latency, probe count, the number of users and their ZDX Score over time, a P50 Packet Loss described as the 95th-percentile value of packet loss over time, and Cloud Path probe errors for up to the top 5 impacted Cloud Path probes. Compare shows a historical or geographical comparison of up to 5 ISPs or locations. [zdx.dashboards.network-intelligence:insight-charts] A network anomaly (red shade) with no users with a poor ZDX Score (gray shade) is not impacting the users' digital experience; for example, latency going from 10 to 40 ms is an anomaly at 3 times the 10 ms baseline, yet 40 ms does not normally impact users. [zdx.dashboards.network-intelligence:anomaly-without-users]

**Severity.** The ISP or ASN View is a Sankey visualization aggregating all IP addresses of the same ASN. Links are yellow (medium severity) when IP addresses are impacted by at least 2 times the baseline with an average latency between 50 ms and 100 ms, red (high severity) at least 3 times the baseline with an average latency above 100 ms, and dotted red for applications with a poor ZDX Score; if a baseline is not established, the values 50 ms (red) and 25 ms (yellow) are used. [zdx.dashboards.network-intelligence:sankey-severity] ASN details indicate the level of latency severity from the P50 latency's deviation from the baseline, with levels at P50 of at least 3 times the baseline, at least 2 times and below 3 times, and below 2 times. They also give the probe count, the count of unique users, average latency, P90 latency, average leg latency, leg loss and a Peer Impact Analysis of whether customers on the same Inter ASN path are also impacted. [zdx.dashboards.network-intelligence:asn-severity]

**Tables.** The ISP Performance table displays the top 200 Last Mile ISPs by ASN, sorted by Baseline Deviation by default to list the most deviated ISPs, with a baseline from the previous 7 days and the names of the Zero Trust Exchange data centers connected to the ISP. The Application Performance table displays the performance of applications accessed by users, with a baseline from the previous 7 days. [zdx.dashboards.network-intelligence:performance-tables]
