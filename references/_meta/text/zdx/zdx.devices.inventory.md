# Hardware, process, software and software patch inventory in the ZDX console (zdx.devices.inventory)
Also called: hardware inventory; hardware overview; process inventory; software inventory; software patch inventory; cpu incident; end of life software; inventory settings

ZDX has four inventory views in the console: hardware, process, software and software patch. Hardware Overview and Hardware Inventory show current information about the organization's devices and their hardware based on their associated users. They need the minimum required Client Connector and ZDX Module versions, a ZDX subscription level that supports Hardware Inventory and the proper ZDX role; the subscription table lists Software and Device Inventory as not supported on Standard and Microsoft 365 and supported on Advanced and Advanced Plus. [zdx.devices.inventory:hardware-requirements] The minimum versions are not given [gap:zdx.devices.inventory:minimum-versions]. The hardware views show the current device count and the total active users from the last 14 days until the start of the UTC day, with the change over the past 24 hours, and chart memory and OS distribution. The inventory table gives each device's name (the vendor device name, with model and OS), user, vendor, hardware model, CPU and memory, and the download captures all currently known devices. [zdx.devices.inventory:hardware-views]

**Process Inventory.** Process Inventory monitors processes that might be impacting the behavior of users' devices; process calculations are updated in one-minute rolling intervals and the top processes are displayed every five minutes. It needs the minimum required Client Connector and ZDX Module versions, a ZDX subscription level that supports it and a CPU usage threshold set for devices; the subscription table lists Process Inventory as supported only on Advanced Plus. [zdx.devices.inventory:process-requirements] The Process Overview tiles show top processes that have exceeded the threshold within a 5-minute interval, color-coded according to number of incidents. The Process Inventory table gives each process's name, the number of devices impacted, CPU incidents (incidents that exceeded the configured CPU threshold) and the average percentage of RAM used. The process details table gives the bytes read from and written to the disk and the bytes uploaded by the device. [zdx.devices.inventory:process-incidents]

**Software Inventory.** Software Inventory shows current and historical information about software versions and updates on users' devices. It needs the minimum required Client Connector and ZDX Module versions, a ZDX subscription level that supports it and the inventory data collection setting enabled, and its data might take up to one day to be available after Data Collection is enabled. The subscription table lists Software and Device Inventory as not supported on Standard and Microsoft 365 and supported on Advanced and Advanced Plus. [zdx.devices.inventory:software-requirements] The Software Overview shows the current count of installed software, vendors, users and devices from the day Software Inventory was enabled until the start of the UTC day. The inventory table groups software by a software group, gives End of Life (when the vendor no longer supports or maintains the software) and End of Support (when it no longer receives updates, patches or technical assistance) dates, and its download captures all known installations every 24 hours. [zdx.devices.inventory:software-overview] Per software version the details give the folder on the user's system where the software is found, a version history with the date it was last updated, and the date it was originally installed. [zdx.devices.inventory:software-details]

**Software Patch Inventory.** Software Patch Inventory identifies each patch, associated with a user and device, as either a software or security patch update. It needs the required Client Connector and ZDX Module versions, a ZDX subscription level that supports it, an admin role configured for inventory management and the setting to collect Software Patch Inventory data enabled; the subscription table lists it as supported on Standard, Microsoft 365, Advanced and Advanced Plus. A patch's Patch Type is an Update, a Security Update or N/A, and its details give the device hostname, the operating system version and the install date. [zdx.devices.inventory:patch-inventory]

**Inventory Settings.** The Inventory Settings page lets admins configure the settings for data collection for Software Inventory, Software Patch Inventory, Wi-Fi data collection or Process Inventory, and minimum versions of Zscaler Client Connector and ZDX Module are required. [zdx.devices.inventory:inventory-settings] If Collect Software Inventory Data is enabled Zscaler collects software inventory data, and if Collect Patch Inventory Data is enabled Zscaler collects the current distribution of software patches on user devices as inventory data. [zdx.devices.inventory:collect-switches] Wi-Fi data collection can be opted into to collect the signal strength and retransmission rate to identify low-performing Wi-Fi devices, by enabling Use Signal Strength and Retransmission Rate for Wi-Fi Data Collection. [zdx.devices.inventory:wifi-collection] Process Inventory monitors the number of CPU Incidents that exceed the CPU Usage threshold (for example CPU Usage > 10%) for a duration of 5 minutes, and the threshold is entered between 0 and 100%. [zdx.devices.inventory:cpu-threshold]

**Through the API.** The API's software inventory reads are not covered here and are open [gap:zdx.devices.inventory:api-inventory-reads].
