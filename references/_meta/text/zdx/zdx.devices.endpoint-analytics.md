# Microsoft Endpoint Analytics (Intune) scores in ZDX (zdx.devices.endpoint-analytics)
Also called: endpoint analytics; microsoft endpoint analytics; intune endpoint analytics; startup performance; software reliability; core boot score; core sign-in score

Endpoint Analytics scores in ZDX are built from Microsoft Intune data.After Microsoft Intune is integrated with ZDX, metrics are garnered from the Microsoft Intune API and mapped to individual ZDX users and devices to provide Endpoint Analytics scores and metrics. The Intune application integration should be configured first, and the user details page provides Endpoint Analytics information for a specified user device. [zdx.devices.endpoint-analytics:source] Data is collected from the Intune API every 3 hours, although metrics might not repopulate every 3 hours within the UI. Some Startup Performance events might take up to 24 hours to be displayed, and some Software Reliability events up to 3 days. [zdx.devices.endpoint-analytics:freshness]

**Setting up the integration.** The integration of Microsoft Intune with ZDX provides access to Endpoint Analytics for user and device insights; its Monitoring Criteria filters identify the users from whom data can be collected for Endpoint Analytics, with selections among the filters cumulative and selections within a single filter not cumulative. [zdx.devices.endpoint-analytics:intune-integration] The Intune integration must be authenticated with Microsoft before it can be saved and reauthenticated whenever the Monitoring Criteria settings are updated; Zscaler uses sign-in and read permissions for it, and Validate verifies that the setup with Microsoft was successful. [zdx.devices.endpoint-analytics:intune-auth] On the Data Collection page integrations (for example Microsoft Intune) are configured for data collection to access Endpoint Analytics, each showing the date it was configured (Onboarded On), and a webhook for alerting can be configured there. [zdx.devices.endpoint-analytics:data-collection-page]

**Scores.** The Endpoint Analytics Score reflects the weighted average of the Startup Performance score and the Software Reliability score, and its scores are calculated on a scale from 0 (poor) to 100 (exceptional). The device's Health Status shows its most recent status, designated Unknown, Insufficient Data, Needs Attention or Meeting Goals. [zdx.devices.endpoint-analytics:score-scale] Startup Performance reflects the weighted average time from system power-on to completion of a user's successful sign-in. The Startup Score is a weighted average of the Core Boot Score (an average based on the time from power-on to sign-in) and the Core Sign-in Score (an average based on the time from credentials being entered to a rendered desktop with CPU usage below 50% for at least 2 seconds), and the page lists the top ten processes impacting startup, those whose CPU usage might be running above 50%. [zdx.devices.endpoint-analytics:startup-performance] Software Reliability reflects the reliability of all installed applications and software, based on crash frequency and duration of usage, and the page shows details of software events within the past 14 days, including each event's publisher, the company that licenses the software. [zdx.devices.endpoint-analytics:software-reliability] How the weighted averages are weighted is open [gap:zdx.devices.endpoint-analytics:score-weights].
