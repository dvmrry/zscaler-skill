# Console reports: predefined reports, Data Explorer views and Quarterly Business Review reports (zdx.reports.console)
Also called: predefined reports; system generated reports; data explorer; data explorer views; quarterly business review; qbr; probe assignments report; user location report; top users with poor zdx scores

The ZDX console has three kinds of reports besides its dashboards: predefined reports, Data Explorer views and Quarterly Business Review reports; the API's report reads are in [Reading ZDX report data: time ranges, paging, users and what the reads return](kb:zdx.reports).

**Predefined reports.** Details for each predefined report are aggregated day to day and most reports are captured in a rolling 14-day cycle. They need the System Generated Reports permission and a supporting subscription (the subscription table lists System-Generated Reports as not supported on Standard and Microsoft 365 and supported on Advanced and Advanced Plus), and each report's Data Source specifies which data is captured: All Cloud Path, All Web Probes or All Devices. [zdx.reports.console:predefined-basics] The Cloud Path: End-to-End report captures the average latency in the Cloud Path within a 14-day time range, with a P95 line calculated from the selected locations and up to 20 device locations in its legend. The DNS Performance report captures the average DNS latency within a 14-day time range, and the Last Mile ISP Performance report captures ISP latency within a 14-day time range, displaying up to 20 ISPs at a time. [zdx.reports.console:latency-reports] The Application Performance report captures the daily distribution of ZDX Scores within a 14-day time range, and the ZDX Score by Application report captures the average ZDX Score per application within a 14-day time range, displaying up to 20 applications at one time. On hover the Wi-Fi Distribution graph shows the device count per Wi-Fi band and its percentage from the total number of user devices across the organization. [zdx.reports.console:score-reports] The Active Users by Zscaler Destination report captures the current distribution of active users and devices per Zscaler destination; on hover the graph shows the user and device counts within a 2-hour time range, and up to 100 destinations can be viewed within the table. [zdx.reports.console:active-users-report] The Top Users with Poor ZDX Scores report captures the top 100 users within a 14-day time range who have the lowest Poor ZDX Scores, based on the selected application, and counts the number of times probes were run for that application within the 14-day timeline. [zdx.reports.console:poor-users-report] The Probe Assignments report captures the number of enabled probes assigned to a given user in a 24-hour time range based on probe usage, and needs the appropriate permission. The probe ranges are 0-10, 11-20, 21-25 or >25 with a default filter of >25, and if the query finds more than 1,000 impacted users the report displays the first 1,000. [zdx.reports.console:probe-assignments] The User Location report gives an overview of user devices' geolocations and granular information in Location History, including each geolocation's latitude and longitude and its source information. A geolocation must be selected before data is displayed, and the report displays up to 5,000 devices. [zdx.reports.console:user-location]

**Data Explorer.** Data Explorer lets admins build and organize their own customized views of applications and metrics; a view's data source is End User Monitoring or Managed Monitoring and its aggregation type across all users is Average, Minimum or Maximum. Only the Super Admin or the admin who created a view can edit or delete it, and the subscription table gives Data Explorer Views, Applications and Metrics as not supported on Standard and Microsoft 365, 30, 1 and 1 on Advanced, and 100, 4 and 4 on Advanced Plus. [zdx.reports.console:data-explorer] The two articles give different aggregation types [divergence:zdx.reports.console:aggregation-types] and different metric limits [divergence:zdx.reports.console:managed-metric-count].

**Configuring a view.** Configuring a Data Explorer view needs a ZDX subscription level that supports Data Explorer and a ZDX role with the proper permission level, and a view can be created from either End User or Managed Monitoring data. [zdx.reports.console:de-prerequisites] In an End User view, selecting a UCaaS application allows adding other UCaaS applications and selecting a non-UCaaS application allows adding other non-UCaaS applications; the applications selected determine the metrics available, and the metrics-based filters specify conditions or thresholds on the chosen metrics. [zdx.reports.console:de-apps-metrics] The Configuring Data Explorer Views article selects the Average, Minimum, Maximum or Median method for data aggregation across all users, with Average as the default. [zdx.reports.console:de-aggregation] For an End User view, data is displayed in 5-minute intervals if the time range is 24 hours or less, and in 1-hour intervals if it is greater than 24 hours but less than or equal to 14 days; some filters are unavailable if the selected time range is greater than 48 hours. [zdx.reports.console:de-granularity] An End User view groups data by Zscaler Locations, Geolocations, Departments, Applications, Last Mile ISPs or Zscaler Data Center; grouping by Applications renders views for each metric and other options render views for each application and metric, and with more than one metric in chart format the Group By option is limited to Applications. [zdx.reports.console:de-group-by] An End User view can be displayed in chart or tabular format, the configured table information can be captured in a CSV file with Export and then the Download icon, and the total number of views that can be saved depends on the ZDX subscription level. [zdx.reports.console:de-end-user-output] A Managed Monitoring view has a default time range of 24 Hours, filters by Zscaler Managed Locations, takes up to 10 probes and up to 10 metrics, automatically selects Page Fetch Time and End-to-End Latency if a Web probe is configured with a Cloud Path companion probe, and can be displayed as chart, scatter, range, tabular or multipath. A Percentile Threshold such as P99 or P95 can be selected, the Show Errors toggle (disabled by default) displays red markers for probe errors, and in the tabular format only the top 1,000 rows are displayed. [zdx.reports.console:de-managed] The range format is unavailable when multiple probes or metrics are selected. The multipath (Cloud Path) visualization is unavailable if multiple probes are selected, allows a time range only between 2 hours and 7 days, has Zscaler Managed Locations set by default for Group By with no other option, has latency metrics selected by default without a way to change them, and by default shows data from the last 24 hours. [zdx.reports.console:de-multipath] Only the ZDX Super Admin or the admin who created the view can edit a configured Data Explorer view, and likewise only they can delete one. [zdx.reports.console:de-edit-delete]

**Quarterly Business Review.** A new Quarterly Business Review report is generated on the first weekend of every month and stored as a PowerPoint file in the Zscaler cloud. The reports are available to users of all ZDX subscription levels, support can enable them if they are not visible, and generating and viewing them needs a minimum of 100 active devices for 30 days. [zdx.reports.console:qbr-availability] A QBR report shows a quarterly snapshot of Application ZDX Score, Network Average Latency and Users Monitored, where an application's score is the average of the lowest value each user experienced over the calendar quarter, plus monthly overviews compared to the previous 6 months of incidents, network incidents, application incidents, application ZDX Scores, DNS resolution time and average latency from the source network to Zscaler. It also shows the top ISPs by users (performance being the average time for the egress router at the user's location to reach the ISP, with any metric under 100 ms considered acceptable), alerts triggered with average remediation time, Wi-Fi versus wired device counts, device counts per operating system, event name and model, and a matrix of ZDX feature support for Standard, M365, Advanced and Advanced Plus. [zdx.reports.console:qbr-contents] What the QBR shows about threats is open [gap:zdx.reports.console:qbr-threats].

  - zscaler-help: The aggregation type is Average, Minimum or Maximum.

  Impact: Whether Median is offered for every view or only for End User views, or is a newer option, is not stated.

  - zscaler-help: A Managed Monitoring view can have up to 10 metrics.
  - zscaler-help: The subscription table's Data Explorer Metrics is 1 on Advanced and 4 on Advanced Plus.
  Impact: Whether the table's row covers only End User views and the 10 applies to Managed Monitoring, or one of them is out of date, is not stated; the limit for a given view and tier is unsettled.
