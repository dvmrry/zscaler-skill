# Onboarding Microsoft Teams, Webex and Zoom Call Quality tenants: prerequisites, authentication and monitoring criteria (zdx.applications.uc-tenants)
Also called: call quality tenant; ucaas tenant; onboard teams call quality; onboard webex call quality; onboard zoom call quality; zoom qss; zdx autosense prerequisites

A unified communication application needs its tenant onboarded before its probes can be configured ([For unified communication applications a tenant must be onboarded before their probes can be configured; the onboarding articles cover Microsoft Teams, Webex and Zoom call quality.](kb:zdx.applications:uc-tenant-onboarding)); this is what the onboarding of a Microsoft Teams, Webex or Zoom tenant asks for. Each of the Webex, Microsoft Teams and Zoom Call Quality configuration articles requires, before onboarding a tenant, the required versions of Zscaler Client Connector and ZDX Module to configure a ZDX Autosense probe, a ZDX subscription level that supports ZDX Autosense, the Windows Filtering Platform (WFP) driver installation setting for ZDX Autosense enabled in the Zscaler Admin Console, and the setting to collect device hostname information enabled in the Zscaler Admin Console. [zdx.applications.uc-tenants:prerequisites]

**Authentication.** A new Webex tenant must be authenticated with Webex before it can be saved, and the Webex, Microsoft Teams and Zoom tenants must each be reauthenticated if their criteria settings are configured or updated. [zdx.applications.uc-tenants:authentication]

**Probes it creates.** When a Microsoft Teams Call Quality tenant or a Zoom Call Quality tenant is onboarded for the first time, a ZDX Autosense Cloud Path probe that detects the destination IP address is generated automatically. [zdx.applications.uc-tenants:autosense-auto-probe] Whether onboarding a Webex tenant does the same is not stated [gap:zdx.applications.uc-tenants:webex-autosense]. The Autosense probe type is in [For a Call Quality Monitoring (CQM) application the Cloud Path probe type shown automatically is the ZDX Autosense feature, which discovers the Cloud Path Host associated with the application and lets the application and its meetings be monitored; it is configured automatically as part of the Cloud Path probe when a CQM application is first onboarded, and ZDX Autosense must be enabled to use it.](kb:zdx.probes.configuration:cqm-autosense).

**Per platform.** To authenticate M365 for the Microsoft Teams application integration the admin must be a Global Administrator in Azure Active Directory; a Microsoft Teams Web App is automatically added under the Predefined Apps Collection; and if the organization does not use an email ID to access Microsoft Teams Call Quality, the admin should log in with the Zscaler Client Connector Login ID to ensure successful alignment between Microsoft and the Zscaler service. [zdx.applications.uc-tenants:teams-requirements] A Zoom tenant is onboarded as either a Zoom API tenant or a Zoom Quality of Service Subscription (QSS) tenant for Zoom's data streaming service, chosen as the Tenant type (Zoom API, Zoom QSS); both cannot be onboarded at the same time. [zdx.applications.uc-tenants:zoom-tenant-types]

**Monitoring criteria.** The Microsoft Teams and Webex articles configure Inclusion Criteria for User Groups, Users and Departments, and the Zoom article configures Inclusion and Exclusion Criteria for them; in the Teams article meetings are monitored and displayed only for the selected ZDX users in the Inclusion Criteria, with selections among the filters cumulative and selections within a single filter not cumulative, and in the Zoom article Exclusion Criteria exclude selected users from monitoring. [zdx.applications.uc-tenants:monitoring-criteria] The Zoom exclusion semantics are in [ZDX call-quality metrics per device and meeting](kb:zdx.devices.call-quality).

**Checking the setup.** After onboarding, Validate verifies that the setup with the platform was successful: optional for Zoom, and clicked within the dialog window for Webex. [zdx.applications.uc-tenants:validate]
