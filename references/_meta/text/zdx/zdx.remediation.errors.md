# Remediation job error messages and their ZUPM_WORKFLOW_ECODE reasons, grouped by what they report (zdx.remediation.errors)
Also called: remediation errors; ZUPM_WORKFLOW_ECODE; zupm workflow ecode; remediation job failed; script certificate verification failure; script execution blocked by execution policy; workflow expired before it could start

These are the error messages a Remediation job reports, each with an internal ZUPM_WORKFLOW_ECODE reason; Remediation itself is in [ZDX Remediation: remote PowerShell scripts, jobs, signing, prerequisites and troubleshooting](kb:zdx.remediation). The reasons below drop the ZUPM_WORKFLOW_ECODE_ prefix.

**Timing.** Workflow timing errors: INTERNAL_ERR is an unexpected internal error (no action required); EXECUTION_TIMEOUT means the Remediation job reached its expiration and cannot run anymore, and EXPIRED_BEFORE_START that it expired before it could start the run (both: extend the job's expiration); EXPIRED_DURING_EXEC means the script expired during its run (extend the job's duration). [zdx.remediation.errors:timing-errors]

**Aborts.** Workflow aborts: POLICY_ABORTED means an admin aborted the job (no action required); REM_DISABLED means the Remediation Settings were not enabled for the user or device; TASK_ABORTED means an admin aborted it or an overriding script run occurred (no action required); NOT_FOUND_ON_DEVICE is described as a failure because an admin aborted it (no action required). [zdx.remediation.errors:abort-errors]

**Tasks and policy configuration.** Task and policy configuration errors: ABORTED_ON_TASK_ERR means the job aborted because of a task the device does not recognize or support; UNSUPPORTED_TASK_CATEGORY means an unsupported task category was received, the supported categories being SCRIPT and LOG_COLLECTION; POLICY_CONFIG_MISSING means the script is invalid due to removal or expired certification (upload the job with a valid certification); TASK_VALIDATION_ERR means the script contains an invalid task object, a null task, or an unsupported category; TASK_MAX_RETRY_REACHED means the job failed and reached the maximum number of retries (rerun the script when the user's device is available). [zdx.remediation.errors:task-errors]

**Deferral.** Deferral errors: USER_DEFERRED means the job was rescheduled; MAX_DEFER_REACHED is described as the job exceeding the maximum number of Remediation jobs; SCRIPT_RUN_USER_DEFERRED means the user postponed the job and SCRIPT_RUN_USER_DECLINED that the user declined it (no action required for these); LOG_FETCH_MAX_DEFER_REACHED means the job did not run because the maximum number of Remediation jobs was exceeded (wait for the other jobs to complete, then re-run it). [zdx.remediation.errors:deferral-errors]

**Download and signature.** Download and signature errors: SCRIPT_DOWNLOAD_FAILED means the script cannot be downloaded due to the network connection or an invalid URL (retry when the network connection is stable); SCRIPT_CERT_VALIDATION_FAILED labels both a message that the script's certification is unverified or missing (check the client's device for missing certificates) and one that the script's certificate cannot be verified (contact Zscaler Support); SCRIPT_INVALID_SIGNATURE means the digital signature is invalid (check the script's properties); SCRIPT_UNSIGNED means the script is not signed or the signature is invalid; SCRIPT_CERT_REVOKED means the certificate is revoked (check the revocation server is accessible and the OS is up to date, otherwise disable the revocation check). [zdx.remediation.errors:signature-errors]

**Execution.** Execution errors: SCRIPT_EXECUTION_POL_DISALLOWED and SCRIPT_EXECUTION_POL_SIGNED_ONLY mean the job is blocked by PowerShell's Execution Policy (both described as Restricted Mode); SCRIPT_TYPE_NOT_SUPPORTED means the job has an unsupported type; SCRIPT_UNKNOWN_RESULT means the script failed to run due to an unknown JSON response; SCRIPT_EXECUTION_ERR means runtime errors within the script (check and resolve them); SCRIPT_EXECUTION_TIMEDOUT means the defined timeout was hit (extend the job's runtime); SCRIPT_EXECUTION_ABORTED means an admin aborted the job; SCRIPT_HANDLER_INIT_FAILED means the job failed to initialize (contact Zscaler Support); SCRIPT_JOB_ID_NOT_FOUND means an invalid ID in the Client Connector Script Execution (SE) Platform; SCRIPT_ORCHESTRATOR_RPC_FAILURE means the Script Orchestrator Service is unavailable. [zdx.remediation.errors:execution-errors]

**Log collection and notifications.** Log collection and notification errors: LOG_FETCH_ERR means logs could not be collected due to an internal error and LOG_FETCH_TIMEDOUT that the upload process exceeded its runtime (no action required for both); NOTIFICATION_INTERNAL_ERR, NOTIFICATION_SEND_FAILURE and NOTIFICATION_HANDLER_INIT_FAILED mean an internal error during notification, a failure to send it, and an error initializing the handler (contact Zscaler Support for all three); NOTIFICATION_NO_RESPONSE means the user's response timed out and NOTIFICATION_FRAMEWORK_DISABLED that the Zscaler Notification framework is disabled (no action required for both). [zdx.remediation.errors:log-notification-errors]

**Table anomalies.** Several rows of the published table read inconsistently [gap:zdx.remediation.errors:table-anomalies].
