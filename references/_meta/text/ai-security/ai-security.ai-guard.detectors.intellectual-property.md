# The AI Guard Intellectual Property detector: reproduction of a confidential context, what it ignores, sensitive context and threshold (ai-security.ai-guard.detectors.intellectual-property)
Also called: ip detector; ai guard ip detector; ai guard sensitive context

The Intellectual Property (IP) detector flags a prompt that reproduces or leaks specific sensitive content from a confidential context (numerical data, named entities, source code, proprietary text), even when rephrased, abbreviated or written in another language, when the user appears to be reproducing or extracting specific confidential content from the context document the customer has loaded; unlike a topic detector, which catches what subject is being discussed, it catches whether actual private data is being reproduced. [ai-security.ai-guard.detectors.intellectual-property:what-it-flags] This subject is the IP detector runbook; the detector list is in [AI Guard's detectors: the capabilities Help lists and the detectors the policy editor configures](kb:ai-security.ai-guard.detectors).

**Sensitive context.** The IP tile's Sensitive Context field takes the intellectual property information to filter; the runbook's example is a sentence giving a project's launch date. [ai-security.ai-guard.detectors.intellectual-property:sensitive-context]

**What it catches.** The runbook lists near-verbatim reproduction, paraphrase and synonym substitution, abbreviated and reformatted numbers, named-entity carry-over, partial or reformatted source code (captured at the token level), paraphrased legal and contractual clauses (detected via semantic overlap), and reproduction of confidential English content in French, German or any of 28 supported languages as cases the IP detector catches. [ai-security.ai-guard.detectors.intellectual-property:catches] The 28-language count is disputed: [ai-security.ai-guard.detectors:supported-languages](kb:ai-security.ai-guard.detectors:supported-languages).

**What it ignores.** The runbook lists generic topic questions (a question about a typical M&A breakup fee does not trigger even if the context contains a specific figure), vague summarization requests, codename mentions alone (asking about a name is not revealing its contents), educational and best-practice queries, and incidental overlap of common numbers (years, percentages used in general context) as cases that do not trigger the IP detector. [ai-security.ai-guard.detectors.intellectual-property:does-not-trigger]

**Threshold.** The IP threshold defaults to 0.7, which Zscaler strongly recommends keeping; the runbook's ranges are 0.85 to 1.00 (only near-verbatim or unmistakable reproductions trigger, suited to initial Block-mode roll-outs on high-value IP), 0.7 to 0.84 (the default band, for production deployments), 0.5 to 0.69 (borderline cases, for investigation or audit mode and not recommended for Block mode) and below 0.5 (very permissive, not recommended for production, useful only for internal debugging). [ai-security.ai-guard.detectors.intellectual-property:threshold]

**Model.** The IP runbook answers yes, 28 languages are supported, says the bi-encoder is multilingual, and says the model is retrained periodically as new false-positive patterns surface, with updates rolled out transparently and no customer action needed. [ai-security.ai-guard.detectors.intellectual-property:model] The 28-language count is disputed: [ai-security.ai-guard.detectors:supported-languages](kb:ai-security.ai-guard.detectors:supported-languages).
