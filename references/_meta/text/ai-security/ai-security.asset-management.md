# AI Asset Management in the AI Security Admin Portal: what it inventories, signing in, first-time configuration order, table behavior (ai-security.asset-management)
Also called: ai asset management; ai security admin portal; ai-console.zscaler.com; ai security getting started; ai infrastructure discovery; ai security configuration steps

AI infrastructure discovery inventories models, MCP servers, agents and AI apps, with dashboard metrics for risk-level, type, environment and cloud distribution and drill-down from widgets to inventory lists. [ai-security.asset-management:infra-discovery-scope] AI Security gives an inventory-style view of five supporting resource types: workloads, datastores, identities, guardrails and AI software libraries; libraries appear as data becomes available. [ai-security.asset-management:resource-inventory] Public AI visibility covers usage analytics (traffic volume, user counts, top-used apps, department-wise usage), category-based views by AI app type, and MCP traffic visibility. [ai-security.asset-management:public-ai-usage] Which AI platforms are supported is open [gap:ai-security.asset-management:ai-platform-support].

**Signing in.** Signing in to the AI Security Admin Portal requires an active Authentication Service user account and the AI Security entitlement enabled for that user account. [ai-security.asset-management:signin-prereqs] The AI Security Admin Portal can be reached three ways: directly at ai-console.zscaler.com, from the Authentication Service Portal at <tenant>.zslogin.net (subdomain and domain may vary by tenant), or from the Experience Center at console.zscaler.com. [ai-security.asset-management:signin-routes] Once the organization is provisioned for AI Security, a registration email is sent to complete account setup. [ai-security.asset-management:registration-email]

**Configuration order.** The configuration guide lists nine steps in order: set up the account, DLP engines and sensitive data, onboard cloud accounts, scan settings, users, business units, AI posture policies, issue rules, and external integrations and notifications. [ai-security.asset-management:config-steps] AI Security classifies data types with predefined DLP engines and dictionaries synced from Internet & SaaS (ZIA). **Tables.** Table setting changes in the AI Security Admin Portal are kept in the browser local storage and are lost if the cache is cleared or a different browser is used; not all settings are available for all tables. [ai-security.asset-management:tables-settings-storage] For some tables at least one column must stay visible; resetting columns to default does not affect sort order; table search shows matching rows even when the term is in a hidden column. [ai-security.asset-management:tables-columns-search]

**Programmatic access.** The inventory API is in [The AI Security inventory API (AI Infrastructure, AI-SPM): read-only assets and issues, cursor paging, filters and limits](kb:ai-security.asset-inventory-api).

What to check:
1. For a sign-in problem, whether the user has an active Authentication Service user account and the AI Security entitlement enabled for it.
2. Table settings that seem lost after a different browser or a cleared cache.
