# Zscaler Client Connector Long-Term Support (LTS) policy (portfolio.usage-terms.client-connector-lts)
Also called: client connector lts; long-term support; lts version

Zscaler identifies one of the supported Client Connector versions per desktop OS platform as the LTS version, supported for up to 12 months from the date of the LTS announcement regardless of how the set of supported versions changes. [portfolio.usage-terms.client-connector-lts:definition] The LTS version is not updated with new features during the 12 months, but new releases based on it may be made available to fix bugs and security issues. [portfolio.usage-terms.client-connector-lts:no-features]

**Where it applies.** LTS currently applies only to Windows, macOS and Linux; Zscaler Client Connector for iOS and for Android on ChromeOS are typically deployed from their respective app stores, where it is not possible to maintain multiple versions. [portfolio.usage-terms.client-connector-lts:platforms]

**Choosing a version.** Each LTS version is chosen based on widespread customer adoption. [portfolio.usage-terms.client-connector-lts:selection] LTS is in general not the recommended version; the recommended version is typically the latest GA version, and Zscaler recommends LTS for environments whose change cycles prevent frequent updates to GA versions. [portfolio.usage-terms.client-connector-lts:recommended]

**Next LTS.** The projected next LTS version is announced at least 6 months before it takes effect, and it is chosen from versions already available to tenants. [portfolio.usage-terms.client-connector-lts:next-lts] The LTS policy states it is effective as of January 31, 2025. [portfolio.usage-terms.client-connector-lts:effective]
