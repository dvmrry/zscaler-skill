# Dated end-of-support notices for Client Connector operating systems and posture features (portfolio.usage-terms.client-notices)
Also called: client connector end of support; android 32-bit; macos catalina; windows 7; device admin samsung; client certificate posture android

Each notice below is what it says on its announcement date.

**Operating systems.** The notice dated July 15, 2021 says Client Connector version 1.8 and later for Android will not support 32-bit devices, and that support for 32-bit is still available with previous Client Connector versions as of that date. [portfolio.usage-terms.client-notices:android-32] The notice dated July 12, 2023 says Client Connector version 3.9 and later no longer supports macOS Catalina. [portfolio.usage-terms.client-notices:catalina] The notice dated March 11, 2020 says Zscaler Client Connector will continue to support Windows 7 until 2021, i.e. 12 months from Microsoft's EOS date, which Microsoft announced on January 14, 2020. [portfolio.usage-terms.client-notices:windows7]

**Android posture and Device Admin.** The notice dated August 9, 2023 says Device Admin support is removed for new installations with Client Connector 1.13 for Android, upgrades of previous releases include it until 1.14, and the enableKnox installation parameter is removed with 1.14; it advises removing Client Certificate posture checks for Samsung Android devices from ZPA access policy. [portfolio.usage-terms.client-notices:samsung-device-admin] The notice dated Jun 11, 2026 says that beginning with Client Connector version 5.0 for Android, Zscaler ends support for the Client Certificate posture type on all Android devices, superseding the announcement published August 9, 2023, which ended it on Samsung Android devices only; it says to update Private Access access policies to remove these checks before users install or upgrade to 5.0 or later for Android and Android on ChromeOS. [portfolio.usage-terms.client-notices:android-client-cert]
