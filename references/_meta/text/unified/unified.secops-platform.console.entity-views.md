# Entity-page tools in the admin portal: filters, columns, grouping, entity drawers, saved views, third-party tickets and formatting rules (unified.secops-platform.console.entity-views)
Also called: secops platform saved views; entity drawer UI Config; formatting rules; Create 3rd Party Issue

**Filters.** Filtering fields depend on the page: dashboards with data from several entities filter by dimensions but not measurements, while entity pages typically filter by both; filter options vary by field type and by whether the field is repeated, and applied filters reset when you leave the page. [unified.secops-platform.console.entity-views:filter-scope] Selecting values in the list filter of a repeated field returns records containing at least one of them, which works like the Equals (Any) operator. [unified.secops-platform.console.entity-views:filter-repeated-list] Conditional filters on repeated fields can be checked against any or all of the field's values, except Is Empty and Is Not Empty, which are Boolean filters on the field as a whole with no All or Any variation. [unified.secops-platform.console.entity-views:filter-repeated-conditional] Clear Selection empties one filter's values, deselecting it in More removes it from the filters bar, and Clear All Filters removes all active filters. [unified.secops-platform.console.entity-views:filter-clearing]

**Columns and grouping.** Table columns (measurements and dimensions) are added, removed and ordered in the Manage Table Columns window (in-use list and available list), sorted by clicking a header, and restored with Reset to Default followed by Apply. [unified.secops-platform.console.entity-views:columns] Grouping of entity pages is available for UVM Tickets, Assets, Findings and Exceptions; AEM Assets, Violation Tickets, Policy Violations and Users; Agentic SOC Incidents, Alerts, Assets and Users; and Identity Protection Users, Identity Findings, Tenants and Alerts. [unified.secops-platform.console.entity-views:grouping-pages] Grouping creates collapsible sections by the chosen field and is removed with Clear Selection; grouping preferences can be saved in a saved view. [unified.secops-platform.console.entity-views:grouping-behaviour]

**Entity drawers.** Entity drawers can be configured under Settings > UI Config for UVM Tickets, Assets, Findings and Exceptions; AEM Assets, Violation Tickets, Policy Violations and Users; Agentic SOC Incidents, Alerts, Assets and Users; and Identity Protection Users, Identity Findings, Tenants and Alerts. [unified.secops-platform.console.entity-views:drawer-pages] A drawer is configured per entity and type (for UVM tickets the example types are CVE, DEFAULT and MISCONFIG); Save as New Type uses an existing type as the template and leaves the original types unaffected, and Severity and Status Timeline checkboxes show those items in the drawer's top panel. [unified.secops-platform.console.entity-views:drawer-types] System drawer tabs can be rearranged, extended with fields, deleted and restored (the Details tab can place fields in a left or right column); custom tabs can additionally be edited but a deleted custom tab cannot be restored. [unified.secops-platform.console.entity-views:drawer-tabs]

**Saved views.** Saved views exist on entity pages (UVM Tickets, Findings, Assets, Exceptions; AEM Assets, Violation Tickets, Policy Violations; Agentic SOC Incidents, Assets, Alerts, Users; Identity Protection Users, Tenants, Identity Findings, Alerts), on named system dashboards, and when viewing items in a dashboard widget. [unified.secops-platform.console.entity-views:saved-view-pages] The saved-view page's AEM list and the Users page disagree about saved views on AEM > Users [divergence:unified.secops-platform.console.entity-views:aem-users-saved-views]. The entity lists otherwise differ between the grouping, drawer and saved-view pages [gap:unified.secops-platform.console.entity-views:entity-list-differences]. The system dashboards that support saved views are UVM Overview, Remediation History, Risk, Explore Vulnerabilities and Asset Coverage; AEM Policy Compliance, Asset Inventory and Tool Coverage And Gap; the Agentic SOC SOC Workbench Dashboard; and Identity Protection Critical Findings and Findings Overview. [unified.secops-platform.console.entity-views:saved-view-dashboards] A saved view stores filters, grouping, sorting and field selections; accounts come with system-saved views for common use cases, and views can be reset to default, favorited, created, edited and deleted. [unified.secops-platform.console.entity-views:saved-view-content]

**Third-party tickets.** Tickets can be sent to an external work-management system one at a time from the ticket drawer or in bulk with Create 3rd Party Issue (one external ticket per platform ticket), but not in bulk to different outegrations such as Jira Bugs and Jira Tasks. [unified.secops-platform.console.entity-views:third-party-bulk] An existing external ticket is linked with Manually connect by entering only its ticket ID (for example INC0012345), not its URL; one third-party ticket can link to only one platform ticket. [unified.secops-platform.console.entity-views:third-party-link] With two-way sync configured, creating or linking a third-party ticket triggers the sync and updates the platform ticket per the outegration settings; after unlinking, updates no longer sync. [unified.secops-platform.console.entity-views:third-party-sync] Tickets can be filtered by link state using the Ticket External Issue Type field (select integrations) or adding the Empty field to display tickets with no linked third-party ticket. [unified.secops-platform.console.entity-views:third-party-filter]

**Formatting rules.** Numeric formatting rules apply a colour to a measurement by operator and threshold (Between needs a start and end value) and are evaluated top to bottom, with the top condition winning where conditions overlap. [unified.secops-platform.console.entity-views:formatting-numeric] Dimension-based formatting rules colour dimension values: rules can be configured for the top 25 dimension values, the page says this rule applies only to pie, bar, and table charts, and repeated fields are not currently supported. [unified.secops-platform.console.entity-views:formatting-dimension] A rule's fallback is either Back to Default or a Customize colour for values that meet no condition; rules are created under Configure > Formatting Rules and can be applied to custom dashboard widgets (Style tab) and to AEM compliance policies; the AEM procedure is written for a numeric rule. [unified.secops-platform.console.entity-views:formatting-fallback-apply]
