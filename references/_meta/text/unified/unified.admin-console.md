# Zscaler Admin Console: navigation, home page, search, account settings, tables, supported browsers, read-only maintenance and remote assistance (unified.admin-console)
Also called: zscaler admin console; admin console navigation; experience center home page; recently accessed; remote assistance; account settings

Signing in to the Zscaler Admin Console is in [Signing in to the Zscaler Admin Console: URLs, sign-in methods, lockouts, password and MFA reset, and the upgrade to Experience Center](kb:unified.admin-console.sign-in). The console's top bar has the navigation menu, Recently Accessed to the left of the Search menu, the Search menu, the Wand icon (displays ZAgent), the Help icon (context-sensitive help on the Page Help tab), the Tools & Resources tab, the Activation icon (activates configuration changes that impact Internet & SaaS features) and the Account icon (switch between Zscaler clouds and tenants if applicable, view the username and organization information, view or change the password, display language or time zone, and sign out). [unified.admin-console:top-bar] Tools & Resources offers Remote Assistance, Help Portal, Support Portal, Cyber Academy, Terms and Policies and Share Feedback. [unified.admin-console:tools-and-resources]

**Navigation.** The navigation menu's top-level categories are Analytics, Administration, Internet Access, Private Access, Cyberthreat Protection, Digital Experience, Data Security, Infrastructure, Zero Trust Branch, Zero Trust Cloud (Cloud & Branch Connector features), Zero Trust Browser and Data Explorer (insights, logs such as log streaming, event logs and audit logs, and other log-related settings). [unified.admin-console:navigation-categories] From the console the AI Security admin portal and the Service Portal for Authentication Service can be reached via SSO. [unified.admin-console:sso-portals]

**Maintenance.** During scheduled maintenance and regular upgrade periods the Zscaler Admin Console is in read-only mode: content can be viewed and navigated, but no parameters can be configured or edited; after the upgrade is complete the console automatically refreshes and enables editing. [unified.admin-console:maintenance-read-only]

**Home page.** The home page appears when an admin logs in to the Zscaler Admin Console and its cards can be added, deleted, rearranged and resized; Customize in the lower-right corner begins editing, and the resize icon toggles a card between half and full size. [unified.admin-console:home-page] The six analytics cards are Networking, Private Applications, Digital Experience, Cybersecurity, Devices, and Appliances, each drawn from the matching dashboard, and Go to Full View in the lower-right corner of an analytics card displays the complete dashboard; the other cards are Recently Viewed (the pages navigated to most recently), News (articles curated by Zscaler on internet security topics), Learn About Products (videos) and Resources (technical documentation, product tours and a feedback form). [unified.admin-console:home-cards] The data time ranges of the cards are open [gap:unified.admin-console:home-card-ranges].

**Search.** Search results include Zscaler Admin Console pages (except items in the Help menu) and do not include field names, toggle names or tooltips; Ctrl+K sets the cursor focus on the Search menu, search provides auto-complete suggestions and keeps a history of recent searches, and Recently Accessed lists the pages recently selected from search results or navigated to. [unified.admin-console:search] The search exclusion list also has a fourth item too short to quote [gap:unified.admin-console:search-exclusions].

**Account settings.** The account menu shows the Login ID (the ID used to log in to the Zscaler Admin Console), the Organization ID (the unique identifier of the organization), a Private Access Microtenant choice when the organization has multiple Private Access (ZPA) Microtenants, and the Internet & SaaS and Private Access clouds provisioned for the organization; when an admin changes clouds, the admin sees only the entitlements granted on that cloud. [unified.admin-console:account-menu] Default Internet & SaaS Cloud and Default Private Access Cloud choose the clouds an admin logs in to by default; the page says the Private Access drop-down menu is displayed if there is only one cloud that has been provisioned for the organization. [unified.admin-console:default-clouds] How that condition reads is open [gap:unified.admin-console:default-private-access-cloud]. In some locations the user interface language can be changed to English (US), Chinese (Traditional), French, German, Japanese or Spanish. [unified.admin-console:languages] The Zscaler service saves transactions in UTC and the account time zone is used only for exporting logs to CSV files; it does not affect the generated logs in the console, because the system time zone determines their time stamp. [unified.admin-console:time-zone] The console password must contain at least 8 characters and include 1 number, 1 uppercase character and 1 special character, and only ASCII characters are allowed; the Zscaler service applies the strongest restrictions and complexity. [unified.admin-console:password] Account settings choose a Light, Dark or System theme (System applies the device's system display theme preference), and the New Navigation Experience introduced for Experience Center, which an admin can revert to the Original experience at any time. [unified.admin-console:theme-and-navigation]

**Tables.** Every time an admin changes a table's settings they are stored in the browser's local storage so that the changes are preserved at the next logon; clearing the cache or using a different browser loses the settings, and not all settings are available for all tables. [unified.admin-console:table-settings-storage] Table search shows the applicable rows even if the term is in a hidden column; resetting columns to default settings does not affect sort order; clipped data can be viewed in a tooltip; for some tables at least one column must be visible at all times, and the page's example is that for Insight log tables Deselect All columns renders the table empty; and Save Applied Filter saves a filter, with an Information icon next to the filter name indicating unsaved changes. [unified.admin-console:table-behaviors]

**Supported browsers.** On Windows 10 and later the console supports the two most recent versions of Google Chrome, Mozilla Firefox and Microsoft Edge; on macOS 10 and later it supports the two most recent versions of Google Chrome and Mozilla Firefox. The page says older versions of these browsers should be compatible but are no longer actively tested, and other browsers should be compatible but are not actively tested. [unified.admin-console:supported-browsers] Safari and Linux are not listed [gap:unified.admin-console:browsers-unlisted].

**Remote Assistance.** Remote Assistance allows Zscaler Support to securely and remotely log in to the Zscaler Admin Console with either view-only or full admin privileges, without creating new admin accounts or sharing passwords; only admin users with Remote Assistance Management enabled for their role can make changes in the Remote Assistance window, opened by clicking the Help icon, selecting the Tools & Resources tab and clicking Remote Assistance. [unified.admin-console:remote-assistance] Either or both options can be chosen: View-Only lets Zscaler Support view the screen without making changes, with an Access Ends On date within 90 days after which view-only access automatically expires; Full Access (Read/Write) lets Zscaler Support read data and make changes, with an Access Ends In time after which full access automatically expires. [unified.admin-console:remote-assistance-options] The Cloud & Branch Connector page gives a different duration for view-only access [divergence:unified.admin-console:remote-assistance-duration]. Obfuscate Data conceals user names, data and device information (such as device name, hostname and owner) from Zscaler Support, and after Remote Assistance is enabled the console displays a message that Remote Assistance is enabled until the access time expires or Remote Assistance is disabled. [unified.admin-console:remote-assistance-obfuscate] Whether the ZIA legacy remote assistance API sets the same console setting is open [gap:unified.admin-console:remote-assistance-api], and so is the longest Full Access time [gap:unified.admin-console:full-access-longest].
