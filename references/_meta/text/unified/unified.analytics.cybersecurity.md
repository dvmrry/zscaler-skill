# Cybersecurity dashboards: Transactional Activity, Advanced Threats, Sandbox Threats, Threat Locations and SSL Inspection (unified.analytics.cybersecurity)
Also called: cybersecurity dashboard; transactional activity dashboard; advanced threats dashboard; sandbox threats dashboard; threat locations dashboard; ssl inspection dashboard

The Cybersecurity, Transactional Activity, Advanced Threats, Sandbox Threats, Threat Locations and SSL Inspection dashboards each take a time range between 1 Day and 90 Days that applies to all data in the dashboard, with a default of 14 Days. [unified.analytics.cybersecurity:time-range] These are separate dashboards from the Cybersecurity Insights report in [Threat reports: Cybersecurity Insights, Sandbox Activity and Sandbox Files Found Malicious](kb:zia.reports.security); the ZIA predefined dashboards are in [ZIA Insights: the Admin Console's traffic charts, log viewer and dashboards](kb:zia.insights). Whether they read the same data as Cybersecurity Insights is not stated [gap:unified.analytics.cybersecurity:data-source].

**Cybersecurity dashboard.** The Cybersecurity dashboard's widgets show transactions detected and blocked (toggling between Malicious Transactions and Policy Blocks), the top threat categories stopped, the countries where threats originate, the flow and dispensation of files sent to the sandbox, and SSL traffic that occurred and was inspected; links open the Transactional Activity, Advanced Threats, Threat Locations, Sandbox Threats and SSL Inspection dashboards. [unified.analytics.cybersecurity:cybersecurity-widgets]

**Transactional Activity.** The Transactional Activity dashboard has Threats and Policy Blocks tabs: Threats charts malicious threats over the period and the top users and departments generating them; Policy Blocks charts transactions blocked for policy reasons, with widgets named Top Application Class, Top URL Categories Blocked, Top Cloud Applications Blocked and Top Blocked File Types. [unified.analytics.cybersecurity:transactional-activity]

**Advanced Threats.** The Advanced Threats dashboard (Cyberthreat Protection > Insights > Advanced Threats) provides an overview of cybersecurity threats and charts the incidents recorded for the period; its category selection includes or excludes threat categories, and Unknown represents incidents the service could not classify under a threat category or that were not classifiable under any of the preceding categories. [unified.analytics.cybersecurity:advanced-threats] The Advanced Threat category selection lists Malware, Spyware, Virus, Sandbox Adware, Sandbox Anonymizer, Sandbox Malware, Sandbox Offensive Security Tools, Sandbox Ransomware, Suspected Spyware or Adware, Adware/Spyware Sites, Advanced Security, Botnet Callback, Browser Exploit, Crypto Mining, Domain Generated Algorithm Domains, Malicious Content, Suspicious Content, Peer-to-Peer, Phishing, Suspicious Destinations, Unauthorized Communication, Webspam, Cross-site Scripting and Unknown. [unified.analytics.cybersecurity:advanced-threat-categories]

**Incidents.** The Advanced Threat Incidents and Sandbox Incidents tables give each incident's Name, Category, Impacted Systems (the number of systems affected), Status (the action taken, for example Allowed or Blocked) and first and last known dates; clicking a row shows additional detail on two tabs. [unified.analytics.cybersecurity:incident-table] On the Sandbox Threats and Advanced Threats dashboards an incident's details include Policy Action, Event Type, Duration (between the first and last known attempt), Total Transactions, Total Bytes, the Sandbox Category (if the file is sent for sandbox analysis), the MD5 of the file that triggered the rule, SHA-2 (256-bit), Destination IP and URL Category, and the originating Client IP (the client device's address) and Client External IP (the client's internet gateway location IP), which the Impacted Systems tab shows. [unified.analytics.cybersecurity:incident-details] The Advanced Threats details list repeats SHA-2 and Total Bytes [gap:unified.analytics.cybersecurity:page-defects].

**Sandbox Threats.** The Sandbox Threats dashboard shows Sandbox policy actions for known files (analyzed and classified malicious or benign) and unknown files (encountered for the first time), filterable by Status Allowed or Blocked; unknown-file verdicts are categorized as Allow & Scan, Quarantine and Allow/Do Not Scan. [unified.analytics.cybersecurity:sandbox-threats] A quarantined file could also be counted under Allow & Scan if it was allowed while in quarantine; malicious files downloaded due to the Allow & Scan policy action are patient 0 events, which Zscaler recommends investigating. [unified.analytics.cybersecurity:sandbox-patient-zero] The Sandbox Activity Report's reading in [Known malicious files might have been allowed because the organization does not have Advanced Sandbox or the correct Sandbox rule configured. A quarantined file could also be counted under Allow & Scan if it was allowed while in quarantine. Malicious files downloaded due to the Allow & Scan policy action are patient 0 events.](kb:zia.reports.security:sandbox-activity-reading) holds two of the three statements in [unified.analytics.cybersecurity:sandbox-patient-zero].

**Threat Locations and SSL Inspection.** The Threat Locations dashboard (Cyberthreat Protection > Insights > Threat Locations) can include or exclude geolocations and shows a choropleth map of threats by location, with a bar chart of the applications that generated the most threats. [unified.analytics.cybersecurity:threat-locations] The SSL Inspection dashboard shows threats blocked due to SSL inspection by application, and the applications, locations and URL categories with the most traffic for which SSL inspection is not enabled. [unified.analytics.cybersecurity:ssl-inspection] SSL inspection itself is in [ZIA SSL/TLS inspection](kb:zia.ssl-inspection).
