# Custom dashboards, widget types, dashboard templates and reports in the admin portal (unified.secops-platform.console.dashboards-reports)
Also called: secops platform custom dashboards; dashboard widgets; My Reports; Template Gallery dashboards

**Measurements and dimensions.** Reports, dashboards and saved views use measurements and dimensions: a dimension defines how data is grouped and a measurement the value calculated and displayed; dimensions are grouped by Main Entity and the measurement list follows the selected dimension. [unified.secops-platform.console.dashboards-reports:measure-dimension-model]

**Widget types.** Per widget type the required counts of dimensions and measurements are: bar 1 to 2 dimensions and 1 to 5 measurements; line 1 dimension (a date breakdown counts as one) and 1 to 5 measurements; pie 0 to 1 dimensions and 1 measurement. [unified.secops-platform.console.dashboards-reports:widget-limits-bar-line-pie] The line example's dimension count is open [gap:unified.secops-platform.console.dashboards-reports:line-example-dimensions]. A standard table has no limit on dimensions or measurements, a pivot table takes one row dimension, one column dimension and 0 to 5 measurements, and tile and trend widgets take no dimensions and exactly one measurement. [unified.secops-platform.console.dashboards-reports:widget-limits-table-tile] Bar widgets come as vertical or horizontal, stacked and 100% stacked; line widgets as line or spline; pie widgets as pie or donut; table widgets as standard or pivot; any widget type can be previewed as a table; trend widgets are only available with historical data. [unified.secops-platform.console.dashboards-reports:widget-variants]

**Custom dashboards.** A custom dashboard needs at least one widget; Viewers and Editors can each be Public (all users in the account) or specific users, leaving the Viewers or Editors drop-down blank keeps the dashboard private, edit access overrides view access, and dashboards can be tagged and pinned to apps. [unified.secops-platform.console.dashboards-reports:dashboard-access] Dashboards can start from preconfigured templates on the Template Gallery page (edited and saved as new, or duplicated) that can be customized; separately, the Create New Dashboard window offers Import Template to upload a dashboard template. [unified.secops-platform.console.dashboards-reports:dashboard-templates] A dashboard pinned to an app appears on that app's My Dashboards page. [unified.secops-platform.console.dashboards-reports:dashboard-pinning] The dashboards list (Explore > Dashboards) shows creator, sharing settings, the apps a dashboard is shared to, tags, last update and scheduled-export status, supports activating and deactivating scheduled exports, sending an export email, and bulk tag editing that either adds to or replaces existing tags. [unified.secops-platform.console.dashboards-reports:dashboards-page] A dashboard widget can be edited, shown as a table, expanded to full screen, duplicated with the same measurements, dimensions, filters and visualization settings, set to scroll, exported to CSV, deleted, resized and rearranged. [unified.secops-platform.console.dashboards-reports:widget-actions]

**Reports.** The Reports page (Explore > Reports) lists each report's ID, app, creator, sharing status, last run time in UTC, last updater and scheduled export details (frequency, format and destination), and reports can be activated, deactivated, rerun, duplicated and tagged. [unified.secops-platform.console.dashboards-reports:reports-list] Reports can be delivered on a schedule and exported in CSV, JSONL or Excel format, and exports can be triggered programmatically via an API. [unified.secops-platform.console.dashboards-reports:reports-formats-api] A report has Viewers and Editors (Public or selected users, edit overriding view), a Current or History data type with a preconfigured, custom or dynamic date range for history, and can be saved with Done, Save, Save & Run or Save As New; it can also be opened from My Reports under Vulnerabilities, Assets, Identities and SOC Workbench. [unified.secops-platform.console.dashboards-reports:reports-create] Report schedules and the export API are covered in [The Agentic SecOps Platform under AEM, UVM, Agentic SOC and Identity Protection: data fabric, data sources and the Reporting API](kb:portfolio.secops-platform); the dashboard schedule details and the API contract are open [gap:unified.secops-platform.console.dashboards-reports:export-schedule-details].
