# Source mapping in the Agentic SecOps Platform: workspace, value methods, explode, minimum fields, keys, parser types and Explore (unified.secops-platform.data.mapping)
Also called: mapping data sources; source mapping; explode field; file parser types; system managed mapping

Mapping is configured per source, and only mapped fields are available for unification and consumption. [unified.secops-platform.data.mapping:map-per-source-only-mapped] Mapping requires that the source has run successfully at least once and a role with Read and Edit permissions under the Platform - Data Source Mapping resource. [unified.secops-platform.data.mapping:map-prereq]

**The workspace.** The mapping page has three workspace sections: Ingested Data (source fields from the most recent successful ingestion run), Entities (the data model fields to map to) and Create New Connection. [unified.secops-platform.data.mapping:map-workspace] A source's mapping page shows a status label: Default Mapping for a Zscaler-provided preconfigured mapping, Custom Mapping once any part of a default is modified (including adding connections, editing logic or pasting connections), and System Managed Mapping for a read-only mapping that cannot be edited. [unified.secops-platform.data.mapping:map-labels] Some sources use system-managed mappings that Zscaler maintains and that cannot be edited or customized. [unified.secops-platform.data.mapping:map-system-managed] Which sources use system-managed or default mappings is not stated [gap:unified.secops-platform.data.mapping:map-which-sources].

**Reverting and copying.** Apply Default Mapping, when supported, overwrites custom logic and returns the label to Default Mapping; Paste Connections replaces the source's current mapping; Unmap All Fields removes all mapped connections. [unified.secops-platform.data.mapping:map-revert-copy] Saved mapping changes apply to future scheduled runs of the source; to apply them to existing data immediately, the source is processed from the Sources page. [unified.secops-platform.data.mapping:map-apply-timing]

**Setting a value.** A mapped field's value is set by Script (Python), Value (a fixed constant for every record from the source), Field (a direct one-to-one pass-through with no transformation) or Composite (several source fields combined into one). [unified.secops-platform.data.mapping:map-value-methods] A Composite mapping concatenates the selected source fields in the order selected and automatically inserts an underscore as the separator; it is primarily used to build a unique key. [unified.secops-platform.data.mapping:map-composite-separator] Nested source fields are referenced with dot notation; the mapping UI supports nesting only up to the third level, and deeper paths are entered manually in the Field method. [unified.secops-platform.data.mapping:map-nested-depth]

**Scripts.** A mapping script runs against a source row passed in as a dictionary named row; the returned value must match the type of the target field, and source fields referenced inside a script show no connection lines in the workspace and are absent from the Mapped filter. [unified.secops-platform.data.mapping:map-script-row] Validate checks a mapping script's syntax; Test Script runs it against example input without affecting live data, using the full dataset of the last successful run if that run was within 90 days and otherwise a 50-record preview. [unified.secops-platform.data.mapping:map-script-validate-test] The platform's required timestamp format is %Y-%m-%dT%H:%M:%SZ; because sources provide timestamps in various formats, the page's example uses a simple script to normalize the Asset First Seen date to it. The same page says to always map the First Seen date when mapping assets and findings, and to map lifecycle fields such as first_seen and last_seen when available. [unified.secops-platform.data.mapping:map-date-format] The platform returns None when a date script fails to produce a valid result, and the page lists None as the result for an empty string, a null, the number 12345 and a pre-epoch date. [unified.secops-platform.data.mapping:map-date-edge-cases] The Python modules a script may import are not stated [gap:unified.secops-platform.data.mapping:map-script-modules].

**Exploding arrays.** Exploding supports a standard array of strings, an array nested inside a JSON object, and an array of objects, and can be applied through the Explode Field icon or the Explode Values checkbox in the script editor. [unified.secops-platform.data.mapping:map-explode-cases] Only one field can be exploded per mapping, and the exploded value must be mapped to a key field of the entity (typically via Composite with a parent identifier); otherwise every record generated from the array shares one ID and each overwrites the previous one until only the final value remains. [unified.secops-platform.data.mapping:map-explode-limits]

**Minimum fields and keys.** At minimum, an Asset mapping must include source_key, type and name, and a Finding mapping must include source_key, type, title, description, original_severity_score and original_severity. [unified.secops-platform.data.mapping:map-min-fields] Entity keys should be unique and stable source-provided IDs rather than values that commonly change such as display names or IP addresses; where no single field is unique, a composite key should be built. [unified.secops-platform.data.mapping:map-entity-key] Custom entities and fields can be added from the mapping page, but the help says they typically need advanced downstream configuration such as relationships and aliases and should be applied cautiously. [unified.secops-platform.data.mapping:map-custom-entities]

**Parsing and exploring.** File parsing defaults to Auto for all sources; the selectable parser types are JSONL, JSON, CSV, Excel, XML and PYTHON_STREAM, and selecting one matters most for AnySource ingestion. [unified.secops-platform.data.mapping:parser-types] The Explore window shows the full dataset of the last successful run if it was within 90 days, and otherwise a 50-record preview. [unified.secops-platform.data.mapping:explore-window] Field statistics in Explore, available when the source has run successfully within 90 days, show Record Count, Distinct Value, Value Coverage (null, empty or populated) and a Value Distribution histogram of the top 20, 50, 100 or 200 values. [unified.secops-platform.data.mapping:explore-stats]
