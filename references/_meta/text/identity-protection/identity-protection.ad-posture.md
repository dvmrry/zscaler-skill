# Active Directory posture in Identity Protection: dashboard, issues, roadmap, reports, remediation, privileged account tracking and password analysis (identity-protection.ad-posture)
Also called: active directory posture; ad posture; ad posture dashboard; risk reduction roadmap; ad executive summary report; ad delta report; privileged account tracking; password analysis

The AD Posture dashboard shows the domain risk severity (Critical, High, Medium or Low), the top 5 issues and the top 10 users and computers with the highest risks, and filters results by AD domain and timestamp. [identity-protection.ad-posture:dashboard-top-lists] From the AD Posture dashboard an admin can run an on-demand scan for the selected domain, include AD decoy users and computers in the posture scan, and delete a scan report, which deletes all posture results for that domain. [identity-protection.ad-posture:dashboard-scan-actions]

**Issues.** Zscaler ITDR detects five risk types in an AD domain: Insecure Kerberos Configuration, Insecure Permissions, Certificate Authority Misconfiguration, Insecure Password Account And Group Management, and Domain Controller Risk. [identity-protection.ad-posture:risk-types] The AD Posture dashboard groups issues into four severity levels (Critical, High, Medium, Low), shown as a bar chart. [identity-protection.ad-posture:issue-severity-chart] An AD issue's detail page lists type of risk, severity, a remediation assessment of Easy, Moderate or Difficult, MITRE ATT&CK ID, and a reference link to ANSSI checklist mapping. [identity-protection.ad-posture:issue-detail-fields] The severity scale differs between pages [divergence:identity-protection.ad-posture:severity-scale]. The remediation scale differs between pages [divergence:identity-protection.ad-posture:remediation-scale]. When an AD issue has several remediations, ITDR shows a flowchart of workflows with the most appropriate remediation first, exportable as an SVG file. [identity-protection.ad-posture:multiple-remediation-flowchart] In an AD issue's multi-remediation flowchart, choosing a workflow and clicking a step can show a PowerShell command, a downloadable remediation script and caveats. [identity-protection.ad-posture:remediation-detail-content] The Actions menu of an AD issue page can export affected user account and computer details as a CSV file and copy specific columns, click Remediations to remediate AD issues, and click Add Objects to Safelist to add the AD object to the safelist. [identity-protection.ad-posture:who-is-affected-actions] The full catalogue of AD checks is not in these articles [gap:identity-protection.ad-posture:issue-catalogue].

**Top users and computers.** Clicking Top 10 Users & Computers opens a page with All, Users and Computers tabs with Identity, Type, Type of Risk, Critical Group Membership, Identity Classification and Severity columns, and the table downloads in Excel format. [identity-protection.ad-posture:top-objects-columns]

**AD computer details.** The AD computer details page, reached by clicking an AD computer on the Active Directory Posture dashboard, has a Summary tab that shows the computer's name, Created On, Identity Classification, Last Password Change and Critical Group Memberships. [identity-protection.ad-posture:computer-summary-fields] The AD computer details page defines a privileged AD computer as one with powerful permissions to perform nearly any action in the AD, and a service AD computer as one created to run a particular service or application on Windows with the minimum permissions required. [identity-protection.ad-posture:computer-classification] The AD computer Summary tab shows the total number of posture risks or misconfigurations the computer is exposed to (examples: Account control rights, Stale computer passwords) and of recent risky changes, and lets the admin forward the attack details to ZIA and ZPA for automated containment, which block according to the defined policy. [identity-protection.ad-posture:computer-summary-counts-containment] On the AD computer Posture tab each risk shows a Type of Risk (examples: Credential Exposure, Weak Permissions), a Severity (examples: Critical, High, Moderate, Low), a Remediation assessment (examples: High, Moderate, Easy), a MITRE ATT&CK technique ID and tactic, and the Who is affected details. [identity-protection.ad-posture:computer-posture-tab] On the AD computer Posture tab, the remediation details give a remediation assessment of Easy, Moderate, or Difficult and include a Remediation Script that can be downloaded and run in PowerShell. [identity-protection.ad-posture:computer-posture-remediation] The computer Posture tab's severity and remediation scales are among those that differ [divergence:identity-protection.ad-posture:severity-scale] [divergence:identity-protection.ad-posture:remediation-scale]. The AD computer Change Detection tab lists recent risky or bad changes detected in the computer, each with a Change Date, an Issue (examples: Privileged account delegation, Unconstrained Delegation), a Change description and an Impact that indicates the change has a bad impact. [identity-protection.ad-posture:computer-change-detection-tab] On the AD computer Change Detection tab, the View icon opens issue and remediation details that include the Issue Name, a Type of Risk (examples: Delegation Abuse, Account Management, Credential Exposure), the MITRE ID and an Investigate section. [identity-protection.ad-posture:computer-change-view-details]

**On-demand scan.** After an AD domain is configured for scanning, the scan is triggered at the scheduled time; an on-demand scan can also be triggered from ITDR > Manage > Active Directory Posture with the Trigger a new scan icon, and results appear on the Active Directory Posture dashboard once it completes. [identity-protection.ad-posture:on-demand-scan-trigger]

**Risk Reduction Roadmap.** The AD Risk Reduction Roadmap categorizes risk severity as Critical, High, Medium or Low, has a slider for the current and target severity, and then lists issues with affected user and computer counts and remediation links. [identity-protection.ad-posture:risk-reduction-roadmap]

**Reports.** The AD posture scan report has Issues, Users and Computers tabs; it can be downloaded as an Excel report, with users and computers downloadable as CSV, and an issue can raise a ServiceNow ticket. [identity-protection.ad-posture:scan-report] AD posture scan reports are permanently deleted when the retention policy period expires. [identity-protection.ad-posture:scan-report-retention] The retention period itself is not in these articles [gap:identity-protection.ad-posture:report-retention-period]. The AD Executive Summary report downloads as a PDF; its Domain Security Rating is Critical or High if a single critical or high issue is found, and Total Changes Detected covers the last 30 days. [identity-protection.ad-posture:executive-summary] The AD Executive Summary report's Report Scope and Monitoring Capabilities section shows only enrolled reports, and its change detection section lists the last 10 suspicious and positive changes. [identity-protection.ad-posture:executive-summary-scope] The AD delta report compares two historical AD scans and downloads as PDF or Excel; the Excel version calls the first scan Scan B and the second Scan A. [identity-protection.ad-posture:delta-report] The AD delta report PDF reports issues resolved, new issues and overall risk level, and its Excel version has Export Summary and Detailed Changes tabs. [identity-protection.ad-posture:delta-report-contents]

**Remediation.** Remediating AD identities from the ITDR Admin Portal requires a configured server agent, which runs the actions in the background via single or multiple API calls. [identity-protection.ad-posture:remediation-server-agent] AD remediation actions can be taken on identities with active detected changes or with compromised or weak passwords. [identity-protection.ad-posture:remediation-eligible-identities] The AD remediation actions are Disable User, Enable User and Reset Password (which support bulk remediation and, for Reset Password, force a password change at next login) and Revoke Group Membership (not bulk, and only static privilege groups). [identity-protection.ad-posture:remediation-actions] If an AD identity has pending remediations and another remediation is attempted, a warning appears offering Resubmit or Close. [identity-protection.ad-posture:remediation-pending-warning] AD remediation history shows Status as Success, Failed, Enforcing or Pending; an action the server agent does not run within 24 hours shows a timed-out message with Failed status; Download CSV returns the latest 5,000 results. [identity-protection.ad-posture:remediation-history] A downloaded AD remediation script is copied to the primary domain controller and run in administrative PowerShell by importing it with import-module and then running Invoke-Remediation. [identity-protection.ad-posture:remediation-script-run] Change remediation is in [Active Directory and Entra ID change detection in Identity Protection: monitored issues, cycle, Impact values and remediation](kb:identity-protection.change-detection).

**Privileged account tracking.** The AD Privileged Account Tracking report lists only accounts with the Evolving status; machine learning marks suspicious logins from a user's login trend and severity is Low, Medium, High or Critical. [identity-protection.ad-posture:privileged-account-tracking] Marking a privileged-account tracking activity as safe stops the machine learning system flagging that activity as suspicious for that user. [identity-protection.ad-posture:privileged-account-safe]

**Password analysis.** Password analysis is enabled in the server agent policy; the agent identifies compromised or weak passwords by checking hashes against leaked databases, common patterns and custom dictionaries and monitors reuse, locally on the selected domain controller without leaving the customer environment. [identity-protection.ad-posture:password-analysis-method] The Password Analysis dashboard counts analyzed accounts (regular and privileged), accounts with weak passwords, and accounts with leaked passwords, and shows the percentage of AD users with reused passwords in pie charts for regular and privileged users. [identity-protection.ad-posture:password-analysis-dashboard] The Password Analysis Details page says to make sure attribute collection is enabled for ITDR to collect AD user account attributes, and offers weak-password lists: Crackable Passwords, Custom Keywords Dictionary, Have I Been Pwned, Have I Been Pwned (Top 1 Million), Keyboard Walks and Leaked Dictionaries. [identity-protection.ad-posture:password-analysis-details] The Password Analysis Details page classifies Password Weakness as Crackable or Leaked and shows a Password Reuse Count. [identity-protection.ad-posture:password-weakness-values]

What to check:
1. Whether a server agent is configured before an AD remediation is attempted from the ITDR Admin Portal.
2. For a remediation showing Failed in the history, whether the server agent ran the action within 24 hours.
3. Which remediation-assessment scale (Easy, Moderate, Difficult or High, Moderate, Easy) the field being read shows before comparing assessments across pages.

Sources disagree (name both sides):
- The AD issue detail page gives severity as Critical, High, Medium, and Low; the AD user and computer details pages, Posture tab, give Critical, High, Moderate, and Low. [divergence:identity-protection.ad-posture:severity-scale]
  - zscaler-help: The issue detail page gives severity as Critical, High, Medium, and Low.
  - zscaler-help: The user details page, Posture tab, gives severity as Critical, High, Moderate, and Low; the Credential Exposure tab of that page repeats the same list.
  - zscaler-help: The computer details page, Posture tab, gives severity as Critical, High, Moderate, and Low.
  Impact: The middle severity level is named Medium on the issue and scan-report pages and Moderate on the user and computer details pages; the pages do not say whether they are the same level.
- The AD issue detail page gives the remediation assessment as Easy, Moderate, Difficult; the AD user and computer details pages, Posture tab, each give both Easy, Moderate, Difficult and High, Moderate, Easy. [divergence:identity-protection.ad-posture:remediation-scale]
  - zscaler-help: The issue detail page gives the remediation assessment as Easy, Moderate, Difficult.
  - zscaler-help: The user details page, Posture tab, gives the remediation assessment as High, Moderate, and Easy in one field and as Easy, Moderate, or Difficult in the remediation description.
  - zscaler-help: The user details page, Posture tab, also gives the remediation description and assessment as Easy, Moderate, or Difficult.
  - zscaler-help: The computer details page, Posture tab, gives the remediation assessment as High, Moderate, and Easy in one field.
  - zscaler-help: The computer details page, Posture tab, also gives the remediation details assessment as Easy, Moderate, or Difficult.
  Impact: The issue, user and computer pages name different values for the same remediation assessment of an AD issue (Difficult on some, High on others), and the user and computer Posture tabs show both scales; the pages do not say which scale governs or whether they map onto each other.
