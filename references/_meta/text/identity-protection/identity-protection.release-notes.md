# ITDR release notes, 2023 to 2026, as dated entries (identity-protection.release-notes)
Also called: itdr release notes; release upgrade summary; zscaler itdr release upgrade summary

This subject records what the dated entries of the Zscaler ITDR Release Upgrade Summary pages say, and not what the product does now [gap:identity-protection.release-notes:current-behaviour]. [Identity Protection (ITDR): how it reads identity stores and endpoints, what it needs, and what can be automated](kb:identity-protection.overview) is the hub for the current behaviour.

**January 09, 2026.** In the release note dated January 09, 2026: the command to create a role for Amazon GuardDuty containment was updated to create a common role to access the AWS account instead of a tenant-specific role. [identity-protection.release-notes:2026-01-09-guardduty-role]

**November 04, 2025.** In the release note dated November 04, 2025: Attribute Collection was enabled by default for all Active Directory scan configurations, including for customers who had it disabled. [identity-protection.release-notes:2025-11-04-attribute-collection] In the release note dated November 04, 2025: an icon to access error logs was added for server agents and endpoint agents, and the Tenant Name field in the Tenant Details window was renamed Tenant ID. [identity-protection.release-notes:2025-11-04-ui-changes]

**August 18, 2025.** In the release note dated August 18, 2025: Active Directory Privileged Account Tracking was added; it monitors anomalous login activity using a machine learning system, accepts up to 200 user accounts per AD domain for explicit tracking in addition to default privileged users, and lets incidents be marked safe to prevent future alerts for similar behavior. [identity-protection.release-notes:2025-08-18-privileged-account-tracking] In the release note dated August 18, 2025: the Entra ID Executive Summary, AD Executive Summary, Entra ID Delta, Active Directory Delta and Endpoint Credential Exposure PDF reports were enhanced, and the two Executive Summary reports gained change detection information. [identity-protection.release-notes:2025-08-18-pdf-reports] In the release note dated August 18, 2025: server agent-based threat detection gained four detections: Account Reconnaissance, Password Spray, External IP Authentication (DC) and Kerberos Service Ticket Anomaly, the last described as checking anomalous Kerberos service ticket requests using machine learning. [identity-protection.release-notes:2025-08-18-server-threat-detection] In the release note dated August 18, 2025: Settings > User & Roles > SSO was renamed IdP Providers, Settings > Users & Roles > Support Users was renamed Zscaler Remote Assistance, and Settings > Advanced Settings > Maintenance was renamed Manage Events & Evidence. [identity-protection.release-notes:2025-08-18-tab-renames] [Deception and ITDR single sign-on and authentication settings: Authentication Service, SAML and OpenID identity providers, password login, OTP and support access](kb:deception.sso)

**June 23, 2025.** In the release note dated June 23, 2025: Active Directory Remediations were added, requiring a configured server agent and allowing actions on specific or multiple identities in bulk; the actions were Enable User, Disable User, Reset Password and Revoke Group Membership, with remediation logs available afterwards. [identity-protection.release-notes:2025-06-23-ad-remediations] In the release note dated June 23, 2025: Identity Search was added to search identities across Active Directory, Entra ID and Okta on a single page, by username, first name, last name, email address and more, with results correlated with ITDR posture information. [identity-protection.release-notes:2025-06-23-identity-search] In the release note dated June 23, 2025: ITDR integration with ServiceNow was added, allowing an incident to be created on the AD Posture, AD Change Detection, Endpoint Credential Exposure, Entra ID Posture and Entra ID Change Detection dashboards. [identity-protection.release-notes:2025-06-23-servicenow] In the release note dated June 23, 2025: Okta system logs for threat detection were stated to be retained for only 14 days, with the retention period not modifiable. [identity-protection.release-notes:2025-06-23-okta-log-retention] In the release note dated June 23, 2025: threat detection on a domain controller through a server agent was added, covering DCSync, DCShadow, Kerberoasting, AS-REP roasting, Suspicious DPAPI access, Suspicious Group Additions and Brute Force. [identity-protection.release-notes:2025-06-23-server-threat-detection] In the release note dated June 23, 2025: the dashboards Identity Posture, Change Detection, Entra ID and Identity Risk Summary were renamed Active Directory Posture, Active Directory Change Detection, Entra ID Posture and Risk Summary. [identity-protection.release-notes:2025-06-23-dashboard-renames]

**April 14, 2025.** In the release note dated April 14, 2025: an event or attacker could be marked as unsafe, which removes the allowlist rules and flags the attacker for further investigation. [identity-protection.release-notes:2025-04-14-mark-unsafe] In the release note dated April 14, 2025: DNS Hostname (Specific) and DNS Hostname (RegEx) were added as endpoint selection criteria for endpoint credential exposure and threat detection policies, selecting by complete FQDN or by a regular expression for the FQDN. [identity-protection.release-notes:2025-04-14-dns-hostname-criteria] In the release note dated April 14, 2025: the Local Security Authority (LSA) Protections scan type was added, which checks registry keys to confirm whether LSA protection is enabled and can be enabled or disabled when configuring the endpoint credential exposure scan. [identity-protection.release-notes:2025-04-14-lsa-protections] In the release note dated April 14, 2025: Password Reuse Analysis was added, showing on the Password Analysis dashboard the percentage of AD users who have reused passwords in pie charts for regular and privileged users, with a Summary tab count of other AD user accounts that share the same password excluding the affected user. [identity-protection.release-notes:2025-04-14-password-reuse] In the release note dated April 14, 2025: posture checks for Entra ID identities supported both active and eligible role assignment types, with the role assignment type shown on the Roles > Entra tab of an affected identity. [identity-protection.release-notes:2025-04-14-entra-role-types] In the release note dated April 14, 2025: when an event or attacker is marked as safe due to an allowlist rule, the specific rule that triggered the action can be viewed on the Event Logs page. [identity-protection.release-notes:2025-04-14-allowlisted-rules]

**March 05, 2025.** In the release note dated March 05, 2025: AD and Entra ID Scan Delta Reports were added, comparing two historical scans to show newly introduced risks, resolved issues and updates to existing risks, downloadable in PDF or Excel formats. [identity-protection.release-notes:2025-03-05-delta-reports] In the release note dated March 05, 2025: copying specific table columns, up to 1,000 rows, to paste into CSV, JSON, Notepad or other compatible files was added across modules. [identity-protection.release-notes:2025-03-05-copy-columns] In the release note dated March 05, 2025: the Windows OOBE Priv Esc, Windows OOBE Files and Unmanaged Local Admins scan or exposure types were added; Browser cookies, Saved Browser Credentials, LSASS Application secrets, LSASS Login Sessions, Insecure UAC Settings, Active Sessions, Recent Run Commands, Recent Powershell Commands and Certificate Files were removed; and Cached Domain Logon Credentials gained credential cleanup support. [identity-protection.release-notes:2025-03-05-credex-types] In the release note dated March 05, 2025: the Endpoint Credential Exposure dashboard gained a domain risk category or severity level, the top 5 credential exposure issues, severity and risk charts and a Risk Reduction Roadmap; a Detailed Findings page was added; and the Severity column was removed from the Identities page table. [identity-protection.release-notes:2025-03-05-credex-dashboard] In the release note dated March 05, 2025: Entra ID Remediations were added with the actions Disable User, Revoke Session, Enforce MFA, Enforce MFA or phishing-resistant MFA, Remove Active Role Assignment and Remove Group Membership, and permissions for running them can be added or removed while deploying the script in the Azure portal. [identity-protection.release-notes:2025-03-05-entra-remediations] In the release note dated March 05, 2025: ITDR supported exporting all event fields in JSON format. [identity-protection.release-notes:2025-03-05-export-event-fields] In the release note dated March 05, 2025: integration with Amazon GuardDuty was added to isolate and contain attackers who interact with decoys by blocking access to those users across AWS resources. [identity-protection.release-notes:2025-03-05-guardduty-integration] In the release note dated March 05, 2025: the Risk Reduction Roadmap was added for AD, Entra ID and endpoints, letting you assess the current domain risk severity (Critical, High, Medium or Low) and set a target severity level for a prioritized remediation roadmap. [identity-protection.release-notes:2025-03-05-risk-reduction-roadmap] In the release note dated March 05, 2025: ZPA containment support was extended to Authentication Service-enabled tenants, where a contained user cannot reach real apps and only app decoys remain accessible. [identity-protection.release-notes:2025-03-05-zpa-containment-zidentity] In the release note dated March 05, 2025: Active Directory Monitoring with Server Agent was listed under Feature in Limited Availability. [identity-protection.release-notes:2025-03-05-server-agent-la] In the release note dated March 05, 2025: the server agent entry said session tracking can be enabled in the server agent policy to monitor logon activities for all AD administrators and privileged accounts, and that password analysis can be enabled and configured in the policy, with the analysis done locally on the selected domain controller and not leaving the customer environment. [identity-protection.release-notes:2025-03-05-server-agent-session-password]

**December 04, 2024.** In the release note dated December 04, 2024: ITDR attribute collection was described: AD user and computer attributes such as objectSid, description, pwdLastSet and department are collected by the Windows endpoint agent assigned to scan the domain once collection is enabled, while Entra ID attribute collection is enabled by default after a tenant is connected. [identity-protection.release-notes:2024-12-04-attribute-collection] In the release note dated December 04, 2024: when an issue has multiple remediations, a remediation flowchart was added that prioritizes the most suitable remediation first; it can be exported as an SVG file and AD objects can be added to the safelist. [identity-protection.release-notes:2024-12-04-remediation-flowchart]

**October 15, 2024.** In the release note dated October 15, 2024: new Entra ID posture checks were added for best practice violations for applications, multi-factor authentication, insecure privilege management and data loss. [identity-protection.release-notes:2024-10-15-entra-posture-checks]

**August 14, 2024.** In the release note dated August 14, 2024: credential cleanup of exposed endpoint credentials was added for these exposure or scan types only: Saved Windows Credentials, AWS Credentials, Azure Credentials, Google Cloud Credentials, Database Connections, Saved VNC Passwords and Admin AutoLogon Settings. [identity-protection.release-notes:2024-08-14-credex-cleanup-types] In the release note dated August 14, 2024: an expiration date could be set when adding an item to a safelist, after which the item is added back into scan results, and objects in the safelist are not counted towards risk scoring. [identity-protection.release-notes:2024-08-14-safelist-expiration] In the release note dated August 14, 2024: custom change detection policies were added for critical property changes in AD (users, groups, computers) and Entra ID (users, service principals, roles) identities, with specific users notified when changes pertaining to a policy are detected. [identity-protection.release-notes:2024-08-14-custom-change-detection] In the release note dated August 14, 2024: Focus Area was renamed Detailed Findings and Recommendations, Add to Safelist was renamed Add Issue to Safelist, the Active Directory Vulnerability report was renamed Active Directory Posture Scan Report, and the LDAP Activity module in AD Threat Detection Policies was renamed Suspicious LDAP Activity. [identity-protection.release-notes:2024-08-14-ui-renames] [How the AD and Entra ID issue, object and change detection safelists work](kb:identity-protection.safelists) [Active Directory and Entra ID change detection in Identity Protection: monitored issues, cycle, Impact values and remediation](kb:identity-protection.change-detection)

**July 08, 2024.** In the release note dated July 08, 2024: ITDR Notifications were added to email executive summary reports or bad change details to configured recipients after AD domains, Entra ID tenants and endpoints are scanned. [identity-protection.release-notes:2024-07-08-notifications] In the release note dated July 08, 2024: all safelists moved from the Settings module to ITDR > Settings, with Active Directory Posture Safelist renamed Active Directory Issue Safelist, Change Detection Safelist renamed AD Change Detection Issue Safelist and Entra ID Posture Safelist renamed Entra ID Issue Safelist. [identity-protection.release-notes:2024-07-08-safelist-relocation]

**June 05, 2024.** In the release note dated June 05, 2024: ITDR - Microsoft Entra ID was added, with an Entra ID tenant connected and scanned from ITDR > Manage > Entra ID, a dashboard at ITDR > Dashboard > Entra ID, and change classification as good, bad or info. [identity-protection.release-notes:2024-06-05-entra-id-posture] In the release note dated June 05, 2024: after configuring an endpoint credential exposure scan, scan types that run on the endpoints could be enabled or disabled. [identity-protection.release-notes:2024-06-05-credex-scan-type-toggle] In the release note dated June 05, 2024: the Identity Risk Summary dashboard was added, collating top or critical misconfigurations and vulnerabilities from identity solutions such as Active Directory and Microsoft Entra ID together with top endpoint credential exposures, with MITRE ATT&CK mappings. [identity-protection.release-notes:2024-06-05-identity-risk-summary]

**April 17, 2024.** In the release note dated April 17, 2024: containment integration with Identity Threat Protection with Okta AI was added, pushing user risk scores to Okta using the Shared Signals Framework (SSF) so that Okta, based on the score and Okta policies, can end sessions, prompt an MFA challenge or invoke a workflow. [identity-protection.release-notes:2024-04-17-okta-ai-containment] In the release note dated April 17, 2024: endpoint credential exposure scan data could be downloaded as a .zip file containing a CSV file for each credential exposure issue. [identity-protection.release-notes:2024-04-17-credex-scan-data] In the release note dated April 17, 2024: ITDR no longer supported phone and text message notifications, and the Phone and SMS options were removed from rules, the notification template options were removed, and the phone field was removed from User Details and Edit Profile. [identity-protection.release-notes:2024-04-17-phone-sms-removed] In the release note dated April 17, 2024: Okta identity system logs identified as potentially suspicious could be viewed under the Okta tab on the Threats page. [identity-protection.release-notes:2024-04-17-okta-threat-detection]

**February 14, 2024.** In the release note dated February 14, 2024: safe processes could be added using regular expressions, so a single safe process can match multiple processes by a pattern in the process names. [identity-protection.release-notes:2024-02-14-safe-process-regex] In the release note dated February 14, 2024: a Show all agents toggle was added under the Actions menu on the Endpoint Settings Agents page to list active and inactive endpoint agents. [identity-protection.release-notes:2024-02-14-show-all-agents] In the release note dated February 14, 2024: the Investigate module was described with per-event actions Contain with Zscaler Internet Access (ZIA), Contain with Zscaler Private Access (ZPA), Mark as safe, Add to blocklist and Delete an event, and extended details of ThreatParse, Chronology and Event Logs. [identity-protection.release-notes:2024-02-14-investigate-actions] In the release note dated February 14, 2024: Orchestrate was described as creating and managing rules, API tokens and event notification templates, and integrating with security solutions to transmit event logs in real time, contain threats and enrich security events. [identity-protection.release-notes:2024-02-14-orchestrate] In the release note dated February 14, 2024: Deceive > Landmine Agents > Agents, Settings, Update Phase Groups and Safe Processes moved to Settings > Endpoint Settings > Agents, Agent Configuration, Agent Update Groups and Safe Processes, and ITDR > Scan Agents moved to ITDR > Manage > Active Directory Posture. [identity-protection.release-notes:2024-02-14-ui-moves] In the release note dated February 14, 2024: ITDR integrations were described: Okta for viewing identity metadata, identifying real-time changes and acting on an Okta identity, and ZIA and ZPA for traffic violation insights on the AD user account and for containment. [identity-protection.release-notes:2024-02-14-okta-zia-zpa-integrations]

**November 02, 2023.** In the release note dated November 02, 2023: the ITDR Active Directory Assessment Posture report was added, showing a unified domain risk score on a scale of 0 to 100, the most prevalent risk types and an issue priority matrix, and downloadable as a PDF file. [identity-protection.release-notes:2023-11-02-assessment-report] In the release note dated November 02, 2023: a Change Detection Safelist was added so detected change detection issues can be reviewed and marked as safe. [identity-protection.release-notes:2023-11-02-change-detection-safelist] In the release note dated November 02, 2023: the Identity label on the left-side navigation was renamed to ITDR. [identity-protection.release-notes:2023-11-02-ui-renames]

**August 31, 2023.** In the release note dated August 31, 2023: a Windows landmine policy could be created with the ITDR - Active Directory attack detection module to detect credential misuse, entitlement exposures and privilege escalation activities against AD via the Landmine Agent. [identity-protection.release-notes:2023-08-31-ad-attack-detection] In the release note dated August 31, 2023: AD domains could be scanned via a Microsoft Windows landmine agent to discover identity vulnerabilities such as AS-REP roasting and kerberoasting. [identity-protection.release-notes:2023-08-31-ad-scan-via-landmine]
