# The Findings Overview and Remediation dashboards in the Identities menu: widgets, filters, views and PDF export (identity-protection.findings-dashboards)
Also called: findings overview dashboard; identities > remediation; remediation dashboard; identity findings overview

**Findings Overview.** The Findings Overview dashboard analyzes identity findings by severity, finding type, tenant, identity, asset and user type, and shows their exploitability and remediation ease. [identity-protection.findings-dashboards:overview-scope] The Findings Overview dashboard is opened by clicking Identities in the Agentic SecOps Platform Admin Portal and then Overview in the left-side navigation. [identity-protection.findings-dashboards:overview-location] The Findings Overview dashboard data is based on the selected view and filters; the view can be saved, and the dashboard data can be exported as a PDF file with the Export icon. [identity-protection.findings-dashboards:overview-view-export] The Findings Overview top panel tiles give an overview of identity findings categorized by easy exploit and severity level; each tile shows the current number of findings in the account and clicking the number opens the Identity Findings page. [identity-protection.findings-dashboards:overview-top-tiles]

The Findings Overview page has widgets for identity findings by severity, by tenant by severity, and by identity provider (total findings per identity provider and the overall count). [identity-protection.findings-dashboards:overview-severity-widgets] The Findings Overview page has a Finding By Remediation Ease widget showing findings by remediation complexity (the page's example is prioritizing a finding that is high risk and easily remediated), and an Exploitability widget showing findings by exploitability and severity. [identity-protection.findings-dashboards:overview-ease-widgets] The Findings Overview page has widgets for findings by assets (total, critical and high findings per asset), assets by number of findings grouped by severity, findings by identities (total users and their findings), findings by user type and severity, and users by number of findings grouped by severity. [identity-protection.findings-dashboards:overview-asset-identity-widgets] The Findings Overview page has a widget of identity findings by finding type, exploit ease and severity with the total per type, and a corresponding widget limited to admins. [identity-protection.findings-dashboards:overview-type-widgets]

**Remediation dashboard.** The Remediation dashboard (Identities > Remediation) provides insights into critical identity risks such as insecure account management and credential exposure, with metrics on severity distribution, exploitability, remediation ease, and findings across tenant, type and identities. [identity-protection.findings-dashboards:remediation-purpose] On the Remediation dashboard, filters can be applied and a view saved, and the data can be downloaded as a PDF with the Export icon. [identity-protection.findings-dashboards:remediation-filters-export]

The Remediation dashboard's Statistics widget shows total critical findings that can be easily exploited and remediated plus newly detected critical findings; Critical Findings By Tenant is a bar chart of critical findings per tenant, and Critical Findings By Type groups risks by vulnerability type (for example insecure password and group management, weak authentication measures, insecure permissions). [identity-protection.findings-dashboards:remediation-statistics-tenant-type] Critical Findings By Remediation Ease is a donut chart dividing critical findings into easy, moderate and difficult by the effort required to fix them, with a table of vulnerabilities (for example exposed passwords, legacy authentication, missing MFA) and their remediation ease. [identity-protection.findings-dashboards:remediation-ease-widget] The exploit-ease widget (Critical Findings By Exploit Ease) is a donut chart dividing critical findings into exploitable levels such as easy, moderate and difficult, with a table of vulnerabilities and exploit ease ratings; the page says easily exploitable represents the highest risk because such findings require minimal attacker effort. [identity-protection.findings-dashboards:remediation-exploit-widget] The Remediation dashboard has Critical Findings By Admin (proportion of admin accounts with active critical findings, with a table by vulnerability type), Findings By User Type (critical identity findings across internal users, external users and other identities, with the total at the center) and Admin Related Critical Findings By Exploit Ease (ease level of attack and number of active critical findings). [identity-protection.findings-dashboards:remediation-admin-user-widgets]
