# ZPN_ERR_AUTH_SAML_EXPIRED: a status code of ZPA User Activity Log (LSS zpn_trans_log) (zpa/user-activity-log)
- Help article (Error codes): SE: User authentication timed out due to expired SAML. The Public Service Edge or Private Service Edge was disconnected because the user’s SAML authentication expired, causing an authentication timeout. Resolution: Ask the user to reauthenticate. If the error persists, contact Zscaler Support.
