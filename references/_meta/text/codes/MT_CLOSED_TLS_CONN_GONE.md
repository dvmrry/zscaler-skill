# MT_CLOSED_TLS_CONN_GONE: a status code of ZPA User Activity Log (LSS zpn_trans_log) (zpa/user-activity-log)
- name: SE: TLS session not present
- error type: InternalError
- status: Info
- admin action: NA
- Help article (Info codes): SE: TLS session not present. The Public Service Edge or Private Service Edge closed the application session because the parent TLS session to Zscaler Client Connector or the App Connector is no longer present. Resolution: Typically, application sessions are closed by the ZPA Public Service Edge or ZPA Private Service Edge when users disconnect from the service. Normally, no further action is required. To learn more, contact Zscaler Support.
