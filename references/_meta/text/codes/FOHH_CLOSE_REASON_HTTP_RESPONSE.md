# FOHH_CLOSE_REASON_HTTP_RESPONSE: a status code of ZPA User Activity Log (LSS zpn_trans_log) (zpa/user-activity-log)
- Help article (Info codes): SE: Connection failed because HTTP return code was not 200. The Public Service Edge or Private Service Edge connection was closed because the returned code was not 200. The returned code 200 means that a connection is OK. If the code does not come back with 200, the connection is closed. Resolution: No action required.
