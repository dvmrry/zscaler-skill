- error type: InternalError
- status: Error
- admin action: NA
- Help article (Error codes): CLT: Protocol not supported. The IP protocol of the incoming Microtunnel request is not supported by the Zscaler Client Connector. Resolution: Verify that the initiating client machine does connect to the receiving Zscaler Client Connector with a protocol other than TCP, UDP, or ICMP. If the error persists, contact Zscaler Support.
