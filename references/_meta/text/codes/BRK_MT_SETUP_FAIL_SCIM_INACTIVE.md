# BRK_MT_SETUP_FAIL_SCIM_INACTIVE: a status code of ZPA User Activity Log (LSS zpn_trans_log) (zpa/user-activity-log)

- error type: ActionableError
- status: Error
- admin action: Ask admin to sync user accounts via SCIM to activate users
- Help article (Error codes): SE: Application access blocked because user was not active with SCIM. The Public Service Edge or Private Service Edge has failed to set up the data connection due to the user being deactivated or not synced in SCIM. Resolution: Ask an admin to sync user accounts via SCIM to activate users. To learn more, see About SCIM. If the problem persists, contact Zscaler Support.
