- Help article (Error codes): AC: Error connecting to server. The App Connector experienced an error while setting up a data connection to a specific server. This was because the application server closed the connection with TCP Reset (RST), the server was not listening on the port, or the App Connector did not support PRA. Resolution: Verify if the application is reachable from the App Connector, check the available server capacity, or contact Zscaler Support to learn more.
