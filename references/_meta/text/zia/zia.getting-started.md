# Getting started with Internet & SaaS: recommended provisioning and forwarding methods, deployment options and editing conventions (zia.getting-started)
Also called: step-by-step configuration guide; internet and saas getting started; zia deployment options; duplicate a rule; delete confirmation

**Provisioning and authentication.** The configuration guide says users must be provisioned and authenticated to implement group and user policies and granular reporting; provisioning uploads usernames, groups and departments to the service database, and authentication lets the service identify traffic to enforce department, group and user policies and log by user and department. [zia.getting-started:provisioning-vs-authentication] Of the available provisioning and authentication methods, Zscaler recommends SAML for authentication and SCIM for provisioning. [zia.getting-started:recommend-saml-scim] The provisioning methods page words the same recommendation in [Zscaler recommends SCIM for provisioning and SAML identity federation for authentication. Directory synchronization is recommended if SAML is not feasible and the organization has more than 100 users; the hosted user database if SAML or SCIM are not feasible and the organization has up to 100 users.](kb:zia.ad-integration.provisioning-methods:recommendation).

**Forwarding.** Zscaler recommends that organizations forward all internet traffic, for all protocols and all destination ports, to the Zscaler service. [zia.getting-started:forward-all-traffic] The guide says there are 4 preferred ways to forward traffic, calls a GRE tunnel ideal for forwarding internet-bound traffic from the corporate network, and says configuring locations is a requirement for GRE tunnels. [zia.getting-started:gre-and-locations] When PAC files forward traffic to the Zscaler service, Zscaler recommends using them in combination with tunneling, Surrogate IP and Zscaler Client Connector. [zia.getting-started:pac-combination] The guide says forwarding to Public Service Edges is not always the right choice for some portions of an organization, which can instead forward to Private Service Edges or Virtual Service Edges for Internet & SaaS. [zia.getting-started:private-virtual-edges] The What is Zscaler Internet & SaaS? page lists these ways to connect traffic: Zscaler Client Connector, Cloud Tunnels (GRE or IPSec tunnels from branch office routers or SD-WAN gateways) and PAC files. [zia.getting-started:deployment-options] The What is Zscaler Internet & SaaS? page says the Zscaler ZTE is the world's largest security cloud with over 150 data centers, and the Traffic Forwarding reference architecture says ZIA is available in 150+ data centers. [zia.getting-started:data-center-count]

**Logging.** The guide describes the Nanolog Streaming Service, without scoping it to a feed kind, as using a virtual machine to stream traffic logs in real time from the Zscaler NSS to a SIEM such as Splunk or ArcSight. [zia.getting-started:nss-via-vm] Cloud NSS, which has no on-premises connectors, is in [VM-based NSS and Cloud NSS: subscriptions, transport and what each needs](kb:shared.nss.delivery-modes).

**Editing.** A duplicated policy rule is identical to the original except for the Rule Order value, which shows the next available rule order; duplicating (cloning) DLP dictionaries is a different process. [zia.getting-started:duplicate-rule] Some items are deleted with the Delete icon, which opens a confirmation window where CONFIRM must be typed before clicking Delete. [zia.getting-started:delete-confirm]
