# Indexed Document Match: IDM templates, limits, scheduling and match accuracy (zia.dlp.indexed-document-match)
Also called: IDM; indexed document match; IDM index template; IDM template; document fingerprinting

By fingerprinting and indexing documents, IDM templates make it possible to create a document repository the service can use to identify completely or partially matching documents when evaluating outbound traffic with the DLP policy. Text-based and non-text-based documents (for example binary files) can be uploaded. An IDM-defined rule searches for matching documents as a whole, not for keywords and phrases; in the vendor's example, an employee's completed form is caught as a partial match for the indexed form. [zia.dlp.indexed-document-match:what-it-is] An organization can create up to 512 IDM templates. The largest file that can be uploaded to an IDM template is 100 MB, and up to 100 GB of files can be indexed for the organization. [zia.dlp.indexed-document-match:limits] The VM that hosts template creation is in [DLP Index Tool: configuration object, VM requirements and deployment notes for VMware, AWS and Azure, SSO and VM commands](kb:zia.dlp.index-tool), the dictionary kinds that use templates are in [DLP dictionaries: predefined, cloned and custom](kb:zia.dlp.dictionaries), and Endpoint DLP's use of IDM is in [Endpoint IDM, Endpoint EDM and Share Files Externally](kb:zia.dlp.endpoint-sensitive-information).

**The Indexed Document Match page.** The Indexed Document Match page lists each template's Template Name (as specified in the Index Tool), VM Name (the VM ID as specified in the Index Tool Configuration), the Number of Documents currently indexed by the template, Last Modified and Modified By, and lets an admin delete a template. [zia.dlp.indexed-document-match:idm-page]

**Creating a template.** A manual IDM template is one where an admin uploads the organization's critical documents by hand; a first-time manual template accepts only one file, and more are added by editing the template after saving. A scheduled IDM template sets up an SSH connection and scheduled updates between the template and the organization's storage server: the template takes the document server's Host and Port and the File Path of the directory holding the documents, the admin downloads the SSH key, creates a user with the username copied from the Index Tool, adds the key to that user's trusted keys and gives the user read access to the directory, and the schedule has a Repeat of Monthly, Weekly or Daily, a time, a time zone and an Update Now option. The template cannot be saved until the setup is configured properly and verified. [zia.dlp.indexed-document-match:manual-and-scheduled] After a template is saved, its Status column shows Completed if it was created properly, Created if it was created but the documents are not indexed yet, or Error if it was not created properly. The template name cannot be changed after creation; a new template is needed to change it. Documents in a manual template are submitted or deleted in the Index Tool; for a scheduled template the changes are made on the document server, and the template updates at the scheduled time or on an immediate update scheduled in the Index Tool. [zia.dlp.indexed-document-match:status-and-immutability]

**Match accuracy in a dictionary.** Adding an IDM template to a custom dictionary requires choosing a match accuracy level: the percentage of similarity a user-uploaded document must meet to count as a match for an indexed document. Low is detected when one of two conditions occurs: a user-uploaded document matches at least 25% of an indexed document, or an indexed document matches at least 50% of the user-uploaded document. Medium is the same pair at 50% and 75%. High is detected when a user-uploaded document matches at least 75% of an indexed document. [zia.dlp.indexed-document-match:match-accuracy] An IDM dictionary has an Exclude 100% Match option; selecting Yes stops Zscaler triggering the dictionary for documents that are a 100% match of already-indexed documents. [zia.dlp.indexed-document-match:exclude-exact-match]
