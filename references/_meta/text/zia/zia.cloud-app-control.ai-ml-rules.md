# AI & ML Applications rules: granular actions, prompt capture, tenant profiles (zia.cloud-app-control.ai-ml-rules)
Also called: ai ml applications rule; gen ai cloud app control; capture prompts; promptCaptureEnabled; chatgpt granular actions; claude tenant profile; block uploads to chatgpt

AI & ML is the one category with a dedicated rule flow. The Help portal documents an AI/ML Applications rule as its own flow: select AI & ML Applications in the left-side menu, then click Add Rule. [zia.cloud-app-control.ai-ml-rules:separate-flow]

**What can be controlled per app.** The AI/ML rule page lists these granular actions: ChatGPT (Chatting, Uploading, Downloading, Deleting, Sharing, Inviting, Login); Google Gemini (Chatting, Downloading, Renaming, Uploading); Microsoft Copilot (Chatting, Deleting, Renaming, Sharing, Uploading); Perplexity (Chatting, Deleting, Sharing, Uploading); Poe (Chatting, Deleting, Sharing, Uploading); Runway (Creating, Deleting, Downloading, Renaming, Sharing). [zia.cloud-app-control.ai-ml-rules:granular-actions-by-app] When several applications are selected together only their common granular actions appear, and the page requires SSL/TLS Inspection for granular actions to work as expected. [zia.cloud-app-control.ai-ml-rules:common-actions-and-ssl] Which applications have granular controls differs between sources [divergence:zia.cloud-app-control.ai-ml-rules:granular-app-coverage]. Granular enforcement needs decryption, so confirm the traffic is inspected first: [Cloud App Control and SSL inspection: what CAC can see](kb:zia.cloud-app-control.ssl-visibility). How action strings are discovered and shaped: [Cloud App Control actions and action discovery](kb:zia.cloud-app-control.actions).

**Prompt capture.** The Capture Prompts option categorizes and stores end-user prompts, up to 2 KB each, for generative AI applications. Prompts are stored in Zscaler logs for the period the organization defines, and authorized users with log access can view them. The option appears only when the selected Gen AI applications support prompt configuration, and the page points administrators to Configuring Advanced Policy Settings. [zia.cloud-app-control.ai-ml-rules:capture-prompts] The Go SDK rule model has `promptCaptureEnabled` (bool), described as whether capture of end-user prompts for generative AI applications is allowed or blocked, and applicable only when the Gen AI Applications Access field is Allow. [zia.cloud-app-control.ai-ml-rules:prompt-capture-go-field] The Python SDK rule model has no prompt-capture attribute and no `promptCaptureEnabled` key in its request format, so a Python client cannot set or read the field. This shows a client-model difference only; it does not show whether a tenant offers the feature. [zia.cloud-app-control.ai-ml-rules:prompt-capture-not-in-python] What happens when Gen AI Applications Access is not Allow is open [gap:zia.cloud-app-control.ai-ml-rules:prompt-capture-vs-denied-access].

**Tenant restriction for AI apps.** In the AI/ML rule UI, Tenant Profiles appears only when ChatGPT is the selected cloud application, and the applications selected under the tenant profiles must not be exempted from SSL/TLS Inspection. [zia.cloud-app-control.ai-ml-rules:tenant-profiles-visibility] The Tenant Profiles feature itself, its supported application list, and the Claude token question belong to [Tenant Profiles: SaaS tenant restriction](kb:zia.tenant-profiles).

**Embedded AI outside the AI & ML category.** On the Productivity & CRM Tools rule page, Embedded AI selects Allow to use the embedded AI applications on Atlassian sites or Block to prevent their use, and is Allow by default. Embedded AI Prompts, when enabled, allows Zscaler to store end-user prompts up to 2 KB in size in logs for up to 6 months, or for the period defined by the organization, and authorized users with access to Zscaler logs can view the prompts entered in the Gen AI applications embedded in the Atlassian application. These options appear only if Gen AI is enabled for the organization. [zia.cloud-app-control.ai-ml-rules:embedded-ai-atlassian] Whether one retention ceiling covers both prompt-capture options is open [gap:zia.cloud-app-control.ai-ml-rules:embedded-ai-prompt-retention].
