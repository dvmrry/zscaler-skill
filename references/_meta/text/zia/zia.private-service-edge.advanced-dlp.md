# Advanced DLP Private Service Edge for EDM and IDM (zia.private-service-edge.advanced-dlp)
Also called: advanced dlp private service edge; advanced dlp pse; edm pse; idm pse; exact data match on prem; indexed data match on prem

The Advanced DLP Private Service Edge is a complementary, dedicated hardware role within the Zscaler cloud that provides on-premises support for Private Service Edge customers who also need Advanced DLP features such as Exact Data Match (EDM) and Indexed Data Match (IDM). [zia.private-service-edge.advanced-dlp:complementary-role] An Advanced DLP Private Service Edge cluster must be deployed alongside a standard Private Service Edge cluster; it is installed in tandem with standard Private Service Edges and dedicated to the organization's EDM and IDM workload traffic. [zia.private-service-edge.advanced-dlp:alongside-standard-cluster] The Advanced DLP Private Service Edge cluster is not deployable on its own: it must be deployed alongside a standard Private Service Edge cluster. [zia.private-service-edge.advanced-dlp:requires-standard-cluster]

**Traffic.** Customer proxy traffic is still directed to the standard Private Service Edge cluster VIP addresses; if required, that cluster forwards the traffic to the Advanced DLP Private Service Edge cluster for additional processing, evaluation and trigger response. [zia.private-service-edge.advanced-dlp:traffic-path] If the Advanced DLP evaluation returns a block trigger, the packet flow stops at that point and the outbound traffic is blocked. [zia.private-service-edge.advanced-dlp:block-trigger]

**Sizing and addressing.** The description table lists two models: Advanced DLP Private Service Edge 3 (3 instances, integrated LB, 1GE, sized for ISP link speeds of 1 Gbps download) and Advanced DLP Private Service Edge 5 (5 instances, integrated LB, 10GE, sized for ISP link speeds of 2 Gbps download); the sizing tables also include a Private Service Edge 5 with Dedicated LB (6 instances, up to 4 LBs, 2 to 4 Advanced DLP Private Service Edges per cluster). The cluster is typically a 1:1 match with the standard Private Service Edge cluster footprint, with a minimum of two servers and no standalone deployment. [zia.private-service-edge.advanced-dlp:models-and-footprint] Advanced DLP Private Service Edge addresses are public IPv4 only; with RFC 1918 addressing and NAT they must have 1:1 static NAT to a public IPv4 address. [zia.private-service-edge.advanced-dlp:ipv4-only] The standard cluster's own budget is in [Choosing a Private Service Edge design and node count](kb:zia.private-service-edge.sizing) and [Addresses, NAT, IPv6 and ports a Private Service Edge needs](kb:zia.private-service-edge.ip-requirements).

**Placement.** An Advanced DLP Private Service Edge cluster can be deployed wherever the standard cluster resides: inside the DMZ (recommended), outside the corporate firewall, or behind the network firewall (which requires Zscaler approval). Behind a firewall or ACL device, the rules published at config.Zscaler.com/<Zscaler Cloud Name>/zia-private-dlp apply. [zia.private-service-edge.advanced-dlp:placement]

What EDM and IDM are, how dictionaries and engines reference them, and how the policy is evaluated is DLP behavior and lives in [DLP engines: the unit a rule references](kb:zia.dlp.engines).
