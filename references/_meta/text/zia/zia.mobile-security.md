# ZIA Mobile Security: Mobile Malware Protection and Mobile App Store Control (zia.mobile-security)
Also called: mobile security; mobile policies; Policies > Mobile Security

Mobile Security has two policies, and the question decides which subject answers.

1. **Is an app blocked for what it does?** The security and privacy actions, their default and the recommended policy are in [Mobile Malware Protection: the two security and six privacy actions, defaults, how it works and the recommended policy](kb:zia.mobile-security.malware-protection).
2. **Is an app store blocked for downloads?** The browse-but-not-download rules, their criteria and limits are in [Mobile App Store Control: browse-but-not-download rules, default, criteria, limits and the recommended rule](kb:zia.mobile-security.app-store-control).

Which of the two policies needs the Mobile Security subscription is open [gap:zia.mobile-security:mobile-subscription].
