# Location groups: manual and dynamic, conditions, limits, predefined groups (zia.locations.groups)
Also called: location group; manual location group; dynamic location group; predefined location group; corporate user traffic group; guest wifi group; workload traffic group; location group limit; extranet location group

**Types.** A location group is manual (members assigned by hand) or dynamic (members are the locations and sublocations that match chosen attributes, and the group updates itself as they change). The API names the types `STATIC_GROUP` and `DYNAMIC_GROUP`. [zia.locations.groups:two-types] A dynamic group takes the locations and sublocations that match all of its conditions; a location that matches them and also has other attributes set still qualifies (a group of name starts with NYC and Enforce Bandwidth Control enabled takes "NYC Office 1" even though that location also enforces firewall control). [zia.locations.groups:match-all-conditions] A dynamic group's conditions can use City/State/Province (Contains, Ends With, Equals or Starts With, with at least three letters), Country, Enable AUP, Enable Caution, Enforce Authentication, Enforce Bandwidth Control, Enforce Firewall Control, Location Type, Managed By (SD-WAN partner), Name (same operators) and Use XFF from Client Request. There is no condition on SSL Inspection. [zia.locations.groups:condition-attributes]

**Predefined groups.** Five predefined dynamic groups are view-only: Corporate User Traffic Group, Guest Wifi Group, IoT Traffic Group, Server Traffic Group and Workload Traffic Group. The one matching a location's Location Type is filled in automatically and cannot be edited there. [zia.locations.groups:predefined-groups] How locations get into them is in [How locations land in groups: location type, defaults, exclusion flags and Terraform support](kb:zia.locations.group-assignment).

**Membership and limits.** A location can join a group independently of its sublocations and a sublocation independently of its parent, and a location or sublocation can belong to several manual and dynamic groups at once. [zia.locations.groups:membership-independent] An organization can have 256 location groups (manual and dynamic together) and each group can hold up to 32K locations and sublocations. The limits table lists the 32K per group without separating manual from dynamic groups. [zia.locations.groups:limits] A sublocation and a group are additive: a group does not replace a sublocation, since membership is independent of nesting ([zia.locations.groups:membership-independent]) and rules take locations as well as groups ([Which policies scope by location and location group](kb:zia.locations.rule-scoping)).

**Extranet and use.** A manual group can be an Extranet Location Type group tied to one extranet resource, after which only locations assigned to that extranet can be added; a dynamic group's Extranet Resource condition adds all locations assigned to the chosen extranet unless another condition excludes them. [zia.locations.groups:extranet-groups] Location groups define an admin's scope and can be selected in policies and in reporting such as Insights and Dashboards. [zia.locations.groups:what-groups-are-for]

Rules take both locations and groups: [Which policies scope by location and location group](kb:zia.locations.rule-scoping).
