# ZIA dashboards, widgets and notes: predefined dashboards, limits, units, time frames and drill-down (zia.insights.dashboards)
Also called: predefined dashboards; web overview dashboard; dashboard widgets; view restricted; cloud application trend widget; total bandwidth consumption widget; dashboard notes

Predefined dashboards (previously called Web Overview) carry widgets according to the organization's subscriptions; for example a web-security-only subscription sees web widgets and not mobile ones. Each dashboard contains widgets that present interactive charts that jump to individual transactions. [zia.insights.dashboards:predefined-by-subscription] The predefined dashboards are Web Overview (web traffic at a high level), Security (blocked threats by class), Web Browsing, Cloud Applications, Mobile Applications, Email Overview, DNS Overview, Firewall Overview, Bandwidth Control, Office 365, IPS Overview, Endpoint DLP and Email DLP Overview. [zia.insights.dashboards:predefined-set] The Email Overview dashboard, which provides information about the email traffic of the organization, is visible only to users who are admins. [zia.insights.dashboards:email-overview-admins] The Endpoint DLP dashboard is listed with no description [gap:zia.insights.dashboards:endpoint-dlp-dashboard].

**Permissions and customization.** A dashboard or widget shows "View Restricted" when the admin lacks permission to view its content; depending on role permission and scope an admin can customize, view and edit the predefined dashboards, and customizations are visible only to that admin. [zia.insights.dashboards:view-restricted] A customized dashboard must be reset to show newly released widgets, and a reset discards the admin's changes, including widgets the admin created. The service reopens the last dashboard viewed after the admin logs back in. [zia.insights.dashboards:reset] Zscaler recommends setting dashboards to reset automatically every 15 minutes, in Account Settings, so the session does not time out and the data stays current. [zia.insights.dashboards:auto-reset-15] User-related widgets include locations and users by default; the Exclude Location filter on a new or edited widget removes locations, for every user-related widget except those in the default Security dashboard. [zia.insights.dashboards:exclude-location]

**Time frame and units.** Dashboards show the last 24 hours by default and keep the chosen time frame across dashboards; only the Bandwidth Control and Office 365 dashboards offer 30 days, and a multi-day frame shows the sum of bytes or transactions per day. [zia.insights.dashboards:time-frame] Bandwidth widgets show a data rate in bps, Kbps, Mbps and Gbps; all other widgets, including Top Throttled Locations, show a data amount in bytes, KBs, MBs and GBs. [zia.insights.dashboards:units] The widget data types and units are in [ZIA Insights chart settings: units, chart types, top-N, filters, history and the data types that appear only on an Insights page](kb:zia.insights.data-types).

**Widget limits and top items.** A dashboard title holds up to 50 characters, a widget title up to 50 characters, a dashboard up to 12 widgets and a custom report up to 20 widgets. [zia.insights.dashboards:limits] The Ranges and Limitations table lists a widget row with no scope [divergence:zia.insights.dashboards:widget-limits]. A dashboard widget charts Web, Mobile, Firewall, DNS, EDLP, Email DLP or Extranet data, as the organization's subscriptions allow; Users, Departments and Locations filters take up to 200 values with include or exclude. [zia.insights.dashboards:widget-data] A widget displays the top five items and groups the rest under Other, whose items Show Details lists. [zia.insights.dashboards:top5-other] On the Configuring Widgets page, pie and line charts display the top 5 results and Other, the cumulative total of the remaining results, while bar charts and tables display the top 100 results with the rest grouped under Other. [zia.insights.dashboards:chart-type-top-n] The same page gives both a top-5 and a top-100 rule [divergence:zia.insights.dashboards:widget-top-items]. Widgets with a table, bar chart or line chart can be resized within the dashboard's fixed 1024 x 768 resolution to fixed size options; pie chart widgets cannot be resized; a deleted widget cannot be restored. [zia.insights.dashboards:resize]

**Particular widgets.** The service classifies threats on the Security dashboard into two classes, Viruses and Spyware and Advanced Threats; the Sandbox Patient 0 Events widget is available only with Advanced Sandbox, and a tenant with Advanced Sandbox that does not see it resets the Security dashboard. [zia.insights.dashboards:security-dashboard] The Cloud Application Trend widget shows, on hover, the risk scores Microsoft Cloud App Security (MCAS) provides with Zscaler's aggregated score, downloadable as CSV; this information is on the dashboard and in the CSV only, not in logs, and a blank cell means the service could not retrieve the data. The widget supports visibility into 1,000 applications. [zia.insights.dashboards:cloud-app-trend] In the Cloud Application Trend CSV, one Zscaler score runs 0 to 100 with lower safer, another Zscaler score runs 1 to 100 with higher riskier, the MCAS score runs 0 to 10 with higher safer and the Bitglass score runs 0 to 10 with higher safer; Usage is the total traffic proxied through Zscaler for the app, in bytes. [zia.insights.dashboards:cloud-app-csv-scores] In the Cloud Applications widget a Miscellaneous <Cloud Application Category> Apps row groups newly added, lesser-known predefined applications of that category: its Net Usage (GB) is cumulative for the grouped apps and its per-application columns (Category, Threat Index, Risk Level) show No Data. [zia.insights.dashboards:misc-apps] The Total Bandwidth Consumption widget shows bandwidth in bits per second for the past 24 hours by default; with a 30-day time frame it adds a 95th percentile trend line of inbound or outbound traffic, whichever is highest, drillable to a 5-minute view, and shows that line only 30 days after the Bandwidth Control policy is enabled. [zia.insights.dashboards:bandwidth-95th] The Firewall Overview Top Applications widget by default does not display internal apps and apps that the Zscaler firewall has not identified; editing the widget's Network Application filter adds them. [zia.insights.dashboards:firewall-top-apps]

**Notes.** Dashboards and interactive reports (standard and custom) take up to 7 notes each, of up to 256 characters; any admin whose role has full Dashboard Access and Reporting Access can add notes or modify other admins' notes, and a posted note shows who last added or modified it and when. [zia.insights.dashboards:notes] A note attaches to its specific dashboard or report, not to a specific iteration of it; on the Web Overview dashboard the notes appear in the same place after the widgets or the time frame are changed. [zia.insights.dashboards:notes-scope] Interactive report widgets are in [Interactive Reports: standard, custom and scheduled reports, export, import and printing](kb:zia.reports.interactive).

What to check:
1. Whether a widget shows five items or a hundred before reading its Other bucket, since the same page gives both rules for bar charts and tables.
2. Whether a widget limit is a per-dashboard or a per-report figure before quoting 12 or 20.
3. Whether a missing widget is a permission result (View Restricted) or a dashboard that needs a reset.

Sources disagree (name both sides):
- The Configuring Widgets page says a widget displays the top 5 items and groups everything else under Other, and also that bar charts and tables display the top 100 results. [divergence:zia.insights.dashboards:widget-top-items]
  - zscaler-help: A widget displays the top 5 items and groups everything else under Other.
  - zscaler-help: Bar charts and tables display the top 100 results, with the remaining results grouped under Other.
  Impact: A bar chart or table widget shows 5 or 100 items depending on which sentence governs; the page does not say whether the top-5 sentence describes only pie and line charts.
- About Dashboards gives 12 widgets per dashboard and Configuring Widgets gives 20 per custom report, while the Ranges and Limitations Reporting table lists 20 widgets with no scope. [divergence:zia.insights.dashboards:widget-limits]
  - zscaler-help: A dashboard can contain up to 12 widgets.
  - zscaler-help: A report can display up to 20 widgets.
  - zscaler-help: The Reporting table lists Widgets at 20, with no dashboard or report scope.
  Impact: The unscoped 20 reads as a dashboard limit if taken alone, against the 12 per dashboard the other page gives; it matches the per-report 20, but the table does not say so.
