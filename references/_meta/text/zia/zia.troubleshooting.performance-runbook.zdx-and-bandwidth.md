# Performance runbook: ZDX evaluation, Bandwidth Control throttling and additional network checks (zia.troubleshooting.performance-runbook.zdx-and-bandwidth)
Also called: ZDX score drop; Bandwidth Action Throttled; Cloud Path hop-by-hop

**ZDX.** The ZDX evaluation applies when the organization has a ZDX subscription and requires ZDX probes configured for at least one impacted application. [zia.troubleshooting.performance-runbook.zdx-and-bandwidth:zdx-prerequisite] For an impacted user the runbook compares the ZDX Score against a known good point in time and inspects Cloud Path hop-by-hop latency and packet loss across Client > Egress, Egress > Service Edge and Service Edge > Destination legs. [zia.troubleshooting.performance-runbook.zdx-and-bandwidth:zdx-score-cloud-path] The runbook correlates Web Probe Page Fetch Time components (DNS, TCP connect, SSL handshake, Server Processing/TTFB, redirects) to separate app from network contributors, and checks Device Health (CPU, memory, Wi-Fi quality, tunnel type) in the incident window. [zia.troubleshooting.performance-runbook.zdx-and-bandwidth:zdx-web-probe-device]

**Bandwidth Control.** To check for Bandwidth Control throttling, the runbook verifies Bandwidth Control is enabled on the Location or its Sublocations and that Web Insights shows Bandwidth Action Throttled, or Throttled response bytes and Throttled request bytes, for the impacted Location or Sublocation. [zia.troubleshooting.performance-runbook.zdx-and-bandwidth:bandwidth-control-check] For users of a Known Location with the bandwidth control policy enabled, the runbook suggests a sublocation with fewer client IPs and bandwidth control disabled on it, then reviewing top bandwidth users and the policy if performance improves. [zia.troubleshooting.performance-runbook.zdx-and-bandwidth:bandwidth-control-remedy]

**Additional checks.** The runbook's additional checks include reverting the latest network change, reviewing ISP details (single or multi, provider, link size), load balancing across ISPs, and failovers to a secondary ISP link. [zia.troubleshooting.performance-runbook.zdx-and-bandwidth:additional-checks]
