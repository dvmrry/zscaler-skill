# ZIA Sandbox (zia.sandbox)
Also called: sandbox; cloud sandbox; advanced sandbox; why wasn't my file sandboxed; file blocked by sandbox; file stuck in quarantine

Sandbox questions arrive as "why was this file blocked", "why was it not analyzed", or "why is it stuck". Ask them in this order; skipping a step is how a Sandbox answer ends up blaming the wrong engine.

1. **Which engine blocked it?** The Blocked Policy Type in the transaction log decides whether this is a Sandbox question at all: [Which engine blocked the file, and what a Sandbox verdict means](kb:zia.sandbox.verdicts). Malware Protection and ATP are covered in [ZIA Malware Protection](kb:zia.malware-protection) and [ZIA Advanced Threat Protection](kb:zia.atp).
2. **Was the file ever eligible for analysis?** Subscription tier, file type and size, static pre-checks, and whether the traffic was decrypted: [What Sandbox analyzes and why a file may not be](kb:zia.sandbox.coverage), with the decryption side in [Where SSL inspection sits in ZIA web policy evaluation (the two passes)](kb:zia.ssl-inspection.pipeline).
3. **What does the report say, and how far can it be trusted?** [Sandbox reports, quota, and trusting report content](kb:zia.sandbox.report). Endpoint hits from CrowdStrike and Microsoft Defender for Endpoint: [CrowdStrike and Microsoft Defender for Endpoint integrations and the endpoint hits reports](kb:zia.sandbox.edr-integrations).
4. **Is the file held, or does the user keep re-downloading?** One-time links, per-request hashes, and Public Service Edge lag: [Files stuck in Sandbox quarantine](kb:zia.sandbox.quarantine).

The rules that decide what happens to first-seen files are in [Sandbox rules: first-time file behavior and the default rule](kb:zia.sandbox.rules); the out-of-band submission calls are in [Submitting files to Sandbox and out-of-band inspection (Discan)](kb:zia.sandbox.submission); the tenant's custom hash list is in [Sandbox custom MD5 hash list](kb:zia.sandbox.md5-blocklist). URL Filtering can block before Sandbox is reached: [ZIA URL Filtering](kb:zia.url-filtering). Provider and SDK defects on Sandbox resources are in [When the ZIA Terraform provider reports success after an error, or crashes](kb:zia.terraform.error-handling) and [What ZIA Terraform data sources return, drop, or get wrong](kb:zia.terraform.data-source-fidelity).
