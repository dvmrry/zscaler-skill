# ZIA end user notifications: browser templates, browser appearance and the Client Connector-based route (zia.eun)
Also called: EUN; end user notification; end user notifications; browser EUN; EUN template; Global EUN Configuration; caution interval; block page customization; EUN CSS; EUN languages

A ZIA policy action can reach the user as a notification in the browser or through Client Connector. Browser notifications are summarized in [Browser-based notifications (block, caution, AUP and quarantine) are provided by the Zscaler service, and their messages can be customized in multiple languages. Over HTTPS a block notification is shown only with SSL/TLS inspection; otherwise the user gets a 403 error in transparent mode or a Connection Refused error in explicit mode.](kb:zcc.notifications:browser-eun), and their templates and appearance are below. The Client Connector route is in [Client Connector-based end user notifications from the ZIA side: prerequisites, channels, details, shared settings and languages](kb:zia.eun.client-connector), with the overview claims [ZIA can notify users of a policy action through Client Connector on the endpoint. This is supported for Inline Web DLP, Endpoint DLP, Cloud App Control, Firewall Filtering, DNS Control and IPS Control.](kb:zcc.notifications:zia-eun-via-zcc) and [Each of those policies has a default message, custom messages can be tied to individual rules, and the notification shows only when it is enabled in the rule. An organization can have at most 64 custom messages across policies.](kb:zcc.notifications:zia-eun-messages). URL Filtering is not among the policies that notify through Client Connector [URL Filtering is not among the policies that notify through Client Connector; a blocked URL category is reported by the browser-based block notification.](kb:zcc.notifications:url-filtering-not-listed). The messages for the DLP Confirm action are in [User Confirmation notification templates for the DLP Confirm action: channels, introductory text, languages, link syntax and shared settings](kb:zia.eun.user-confirmation).

**Browser EUN templates.** Browser EUN templates hold custom block and caution messages. For a Cloud App Control, URL Filtering or File Type Control rule with a block or caution action to display one in the browser, the rule must reference one of the templates. Zscaler EUNs come with default messages for each policy type, and elements such as the message per action, company name, logo, displayed information and duration can be customized. [zia.eun:browser-template-purpose] A template has a unique name and a channel (Cloud App Control, URL Filtering or File Type Control); Reset All restores the default notification messages provided by the service. The EUN Templates list is paginated with up to 500 templates per page. [zia.eun:template-fields] The browser EUN is supported for either the Block or Caution action in the Cloud App Control policy, URL Filtering rule or File Type Control policy. [zia.eun:template-supported-actions]

**Caution interval.** Caution Interval sets how often the service displays the Caution notification when a user is browsing a restricted site: 30 seconds, 1, 5, 15 minutes, 1, 6, 8, 12 hours, or 1 to 7 days; at least 5 minutes is recommended for complex websites such as social networking sites. A template's interval applies if the template is associated with a Cloud App Control policy, URL Filtering rule or File Type Control policy; if not, the interval on the Global EUN Configuration tab applies. [zia.eun:caution-interval] In the vendor's example, a URL Filtering rule with the Caution action for Travel and Online Shopping and a 15-minute interval applies the interval across both categories: the service does not show the Caution notification for other URLs the user accesses in either category until 15 minutes have elapsed. [zia.eun:caution-interval-across-categories] If Enforce Authentication is disabled for a location or sublocation, Enable Caution must be selected for the location with the Caution Interval set greater than 1 minute for the service to display Caution notifications to unauthenticated users. [zia.eun:unauthenticated-caution] The default Global EUN Configuration interval is not given on these pages [gap:zia.eun:global-caution-default].

**Details shown in a template.** A Cloud App Control template always shows the Cloud App and Cloud App Category (selected by default and not unselectable), and can add the Rule Name, App Activity and a Recommended Cloud App, the application the organization recommends as an alternative. [zia.eun:info-cloud-app-control] A URL Filtering template always shows the Website URL and URL Category (selected by default and not unselectable), and can add the Rule Name. [zia.eun:info-url-filtering] A File Type Control template always shows the Activity and File Type (selected by default and not unselectable), and offers Cloud Application, Rule Name, File Name, URL and File Size as further details. [zia.eun:info-file-type-control] The maximum number of browser templates is not stated [gap:zia.eun:template-limit].

**Appearance.** The service provides templates for the Acceptable Use Policy, caution, quarantine and block notifications (URL Categorization, Security Violation and Web DLP Violation). They are made of discrete table rows and columns, each row using a CSS style to control its properties, and the message or text fields on the Global EUN Configuration page accept CSS styles, HTML tags and JavaScript to change fonts, colors, borders and dimensions. [zia.eun:templates-and-markup] CSS style and JavaScript are not rendered when previewing EUN templates. [zia.eun:preview-not-rendered] The row classes are bh (box header), eu_co rsn (reason), eu_co (EUN content), eu_co ln (link), eu_co fo (footer), s_img (static image), red (background), eu_h (EUN header), btn (button), uq_cd (unique code) and eu_co st (static text). [zia.eun:css-classes] Zscaler Support uses the class uq_cd to identify EUNs, and Zscaler strongly recommends not modifying it. [zia.eun:uq-cd-reserved] All notification templates have two footers: one with contact information for the organization's IT Support, and the Zscaler footer with the Zscaler logo (class s_img) and, by default, a message (class eu_co st). [zia.eun:footers] Background colors and classes by template: the Acceptable Use Policy template uses green and class gr, caution uses yellow and class yl, block uses red and class red, and quarantine uses orange and class or. [zia.eun:background-classes] By default a notification occupies 90% of the browser's width with a maximum width of 790 pixels; the vendor's example resizes them with a style on the m_tbl class setting width 75% and max-width 500px. [zia.eun:default-size] Whether this customization also applies to Client Connector EUNs is not stated [gap:zia.eun:css-scope].

**Languages.** Browser EUNs support English, Simplified and Traditional Chinese, Dutch, French, German, Japanese, Brazilian and European Portuguese, Russian, Spanish, Spanish (Latin America), Italian, Indonesian, Korean, Turkish, Thai and Vietnamese. The service detects the browser's language setting and shows EUNs in that language, or in English if the browser language is not supported. [zia.eun:browser-languages] External EUN pages, used when users are redirected to an external site, are global for the entire organization, so the external site needs its own browser language detection. The Authentication dialog box is displayed only in English, and the Acceptable Use Policy message can contain several languages as a free-form text field but gets no browser language check. [zia.eun:language-exceptions]

The EUN template objects that rules reference by ID were not checked in the API, SDKs or Terraform [gap:zia.eun:api-surface].

What to check:
1. Whether the rule that fired references an EUN template, since a browser notification for a block or caution action is shown only when the rule references one.
2. Which caution interval applies: the template's, if it is associated with the rule, or otherwise the Global EUN Configuration interval.
