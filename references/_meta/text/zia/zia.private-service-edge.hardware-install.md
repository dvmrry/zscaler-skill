# Racking and cabling Private Service Edge hardware, and the Cloud Operations handoff (zia.private-service-edge.hardware-install)
Also called: pse installation guide; pse ports; pse ipmi port; pse te0; pse sfp optics; pse cabling

Installing a Private Service Edge is a physical step that ends in a handoff to Zscaler Cloud Operations. Both Private Service Edges of a pair must be installed in the same location. The Advanced DLP page says both servers must be installed in the same location alongside the organization's standard Private Service Edges. [zia.private-service-edge.hardware-install:pair-same-location] Zscaler uses only the ports labeled in the installation steps; any unlabeled ports on the server are unused and can be ignored. [zia.private-service-edge.hardware-install:unlabeled-ports]

**Private Service Edge 3.** On the Private Service Edge 3 the 1Gb RJ45 IPMI port is used for out-of-band management, the 1Gb or 10Gb RJ45 OS/Management port (te0) is used for server management, and the 1Gb RJ45 service ports e0 through e3 carry the service's incoming and outgoing web traffic and host the IP address of a Private Service Edge instance. The guide lists up to 7 CAT6 Ethernet cables. [zia.private-service-edge.hardware-install:ports-pse3]

**Private Service Edge 5.** The Private Service Edge 5 guide lists an RJ45 MTS port (te1) used for the Message Transport System and 10Gb SFP service ports te4 and te5 used for incoming and outgoing web traffic, together with 2 10G SFP+/SFP optic modules or direct attach cables. Connecting at the higher supported speed does not change any provided capacity numbers. [zia.private-service-edge.hardware-install:ports-pse5]

**Dedicated Load Balancer.** On the Dedicated Load Balancer the 10Gb or 25Gb SFP service ports are bundled by LACP in pairs: LB instance 1 uses twe0 and twe4, and LB instance 4 (if required) uses twe3 and twe7. The guide lists up to 6 10G SFP+/SFP optic modules or direct attach cables, and the load balancer takes 1U of space and is 17.2 inches wide. [zia.private-service-edge.hardware-install:ports-dedicated-lb] The optics count against the instance pairs is not reconciled [gap:zia.private-service-edge.hardware-install:dedicated-lb-optics].

**Private Service Edge 10.** The installation page has a Private Service Edge 10 Installation Guide section whose package list names 1 Private Service Edge 10. [zia.private-service-edge.hardware-install:pse10-listed] Nothing more is established for it [gap:zia.private-service-edge.hardware-install:pse10-details].

**After installation.** After installation the customer emails its assigned project manager on the Zscaler Cloud Operations team, including the company name and Private Service Edge location. Cloud Operations then verifies remote connectivity, installs the Zscaler software, activates the Private Service Edges in the Zscaler cloud, activates the proactive monitoring capability, and tests that they are ready for service. [zia.private-service-edge.hardware-install:cloud-ops-handoff] Placement and switch settings are in [Where to place a Private Service Edge and how to configure the network around it](kb:zia.private-service-edge.deployment); addresses per node are in [Addresses, NAT, IPv6 and ports a Private Service Edge needs](kb:zia.private-service-edge.ip-requirements).
