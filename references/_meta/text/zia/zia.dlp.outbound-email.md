# Outbound Email DLP rules in the SDKs and Terraform provider (zia.dlp.outbound-email)
Also called: outbound email dlp; emailDlpRules; email dlp rule actions csv; zia_outbound_email_dlp

Outbound Email DLP rules are managed separately from web DLP rules and, like Endpoint DLP ([Endpoint DLP API families in the SDKs and Terraform provider](kb:zia.dlp.endpoint-dlp)), are known from client code rather than the vendor contract.

The Go SDK manages Outbound Email DLP rules at `/zia/api/v1/emailDlpRules` with get, lite list, list, create, update and delete, plus `GetActions`, which returns raw CSV bytes. [zia.dlp.outbound-email:go-endpoint] The Python SDK's `get_actions` calls `/emailDlpRules/actions` and returns the CSV mapping of supported outbound email DLP rule actions as bytes. Up to v1.11.2 it returned them in a 2-tuple with the error; from v1.11.3 it returns the (content, response, error) tuple. [zia.dlp.outbound-email:python-endpoint] The Go and Python release notes mention only the actions CSV endpoint, although the list, lite, get and CRUD methods are also present in code. The methods shipped in Go v3.8.41 and Python v1.9.39. [zia.dlp.outbound-email:release-notes-understate]

Terraform provider v4.8.0 added the `zia_outbound_email_dlp` resource and data source. [zia.dlp.outbound-email:terraform-resource] The Terraform delete and create-retry handlers for these rules share the defects described in [When the ZIA Terraform provider reports success after an error, or crashes](kb:zia.terraform.error-handling). The Zscaler Incident Receiver that outbound email policy rules forward to is in [Where a DLP match goes: notification, ICAP, Incident Receiver and Cloud-to-Cloud](kb:zia.dlp.incident-forwarding).

How the feature behaves, from the help, is in [Outbound Email DLP policy: smart host flow, per-recipient evaluation, criteria and header actions](kb:zia.dlp.outbound-email-policy), [Outbound Email DLP email tenants and mail-server setup (SEG, Gmail, Exchange)](kb:zia.dlp.outbound-email-tenants) and [DLP domain profiles and recipient profiles](kb:zia.dlp.email-profiles).
