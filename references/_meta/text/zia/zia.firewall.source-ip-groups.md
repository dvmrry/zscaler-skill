# ZIA source IP groups: IPv4/IPv6 split, predefined groups, entry formats (zia.firewall.source-ip-groups)
Also called: source IPv4 groups; source ip group; source ip address groups

A source IP group is a single reusable object for enforcing rules across security policies such as Firewall, DLP, URL Filtering and SSL/TLS Inspection, and a change to a group's addresses applies to all linked security controls. [zia.firewall.source-ip-groups:purpose] Source IP groups let consistent inbound and outbound security rules be applied from unified source IP groups. [zia.firewall.source-ip-groups:inbound-outbound]

**IPv4 and IPv6.** Source IPv4 and IPv6 addresses are managed in separate groups. Two predefined groups, All IPv4 and All IPv6, contain all addresses of their type; custom groups can be created for IPv4 only, and custom IPv6 groups are not currently supported, so only the predefined All IPv6 group is available. [zia.firewall.source-ip-groups:ip-families] The Source IPv4 Groups page lets an admin view details for read-only predefined groups. [zia.firewall.source-ip-groups:predefined-read-only]

**Writing one.** A custom source IPv4 group is created from individual, subnet or range IP addresses: an address (for example 198.51.100.100), a range (for example 192.0.2.1 - 192.0.2.10) or an address with a netmask (for example 203.0.113.0/24). [zia.firewall.source-ip-groups:entry-formats] A source IPv4 group name may contain only alphanumeric characters, underscores, hyphens and periods, and its description cannot exceed 10,240 characters. [zia.firewall.source-ip-groups:name-description]

**Size.** The limits table gives 4,000 source IP address groups. [zia.firewall.source-ip-groups:group-count] The per-group entry cap is open [gap:zia.firewall.source-ip-groups:per-group-cap]. Other caps are in [Firewall rule, criteria and group limits](kb:zia.firewall.limits).
