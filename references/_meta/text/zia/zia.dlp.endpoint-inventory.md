# Endpoint inventory and Application Investigation: detected removable storage, printers, portable devices and applications (zia.dlp.endpoint-inventory)
Also called: Inventory; Application Investigation; Application Inventory

The inventory provides visibility into the use of removable storage devices (for example USB drives, external hard drives), printers, portable devices (for example mobile phones and cameras) and applications within an organization, and automatically detects their usage and displays the permission access based on the device control policy. [zia.dlp.endpoint-inventory:inventory-scope] The removable storage view offers Usage Distribution by Action (the percentage-wise distribution of removable storage device violation by action) and Create Device Rule, which creates a rule based on the parameters of the selected device. The printer view lists each printer's Port (the communication endpoint through which a computer sends print jobs to a printer) and offers Create Printer Rule. The portable device view exports to CSV, and the application view lists Number of Devices. [zia.dlp.endpoint-inventory:inventory-actions]

**Device detail pages.** The removable storage details page shows the vendor ID, product ID and serial number of the connected device, a 30-day activities and incidents trend by severity, and a Why section with the triggered rule (and the other rules that matched) and DLP engine name; its How shows destination, destination path, vendor ID and product ID. The printer details page shows the UNC path, hardware ID and port; its What shows file name and its How shows destination, destination path, printer local name, hardware, port and UNC path. The portable device details page's What shows source path and its How shows destination, vendor ID, product ID and serial number. [zia.dlp.endpoint-inventory:device-details-family] The inventory pages show some absences that the articles do not explain [gap:zia.dlp.endpoint-inventory:inventory-absences].

**Application Investigation.** Application Investigation shows the number of applications detected on Windows and macOS endpoints, the number of distinct applications and the number with a CVE. It breaks instances down by code signing certificate status (Valid Signature, Certificate Expired, Unsigned, Not Valid or Invalid Signature) and by threat type (Benign, Malicious, Suspicious or Unknown), and lists top applications that maintain non-system certificate trust stores. [zia.dlp.endpoint-inventory:application-investigation-overview] The endpoint detects an application's threat type by a local signature check to verify applications from trusted providers. If a signature is unknown or compromised, ZDP consults the Zscaler Zero Trust Exchange, which cross-references the file against global threat feeds, proprietary intelligence and sandbox history to determine a final verdict of Benign, Suspicious, Malicious or Unknown. [zia.dlp.endpoint-inventory:threat-type-verdict] The Application Investigation inventory filters by Product Name, OS, Code Signing Certificate Status, Threat Type, Category, Vulnerabilities or Application Name, and exports to CSV. It lists each application's last execution and vulnerability severity (Low, Medium, High or Critical) based on the Common Vulnerabilities and Exposures (CVE) rating. [zia.dlp.endpoint-inventory:application-investigation-inventory] An application's details show a version's digital certificate, copyright, MD5 and SHA256 when the version is expanded, and a CVE Severity Score. The Application Investigation details page counts Instances where the application was detected, while the Inventory Applications details page counts Endpoints where it was detected. [zia.dlp.endpoint-inventory:application-details] Run the Application Inventory Scan is the setting to enable to view the list of applications on the Application Inventory page. [zia.dlp.endpoint-inventory:application-inventory-toggle]
