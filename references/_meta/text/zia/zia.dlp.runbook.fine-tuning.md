# DLP runbook: policy fine-tuning with Minimum Data Size, file type fallback, catch-all rules and dictionary combinations (zia.dlp.runbook.fine-tuning)
Also called: Require DLP Feature Configuration Assistance or DLP Policy Fine-Tuning; DLP false positive tuning

**Minimum Data Size.** To fine-tune a DLP policy, the runbook suggests that if a lot of telemetry data smaller than 10 KB contributes to a large volume of false positives, Minimum Data Size (KB) can be configured as 10 KB and monitored again; it also states that Zscaler DLP engines support files up to 400 MB and can scan the first 100 MB of the extracted text, and that if files exceed defined thresholds for size or format compatibility, DLP inspection could fail or skip triggering policies for those files. [zia.dlp.runbook.fine-tuning:minimum-data-size]

**File type fallback.** For HTTP Form Data, the runbook suggests creating a DLP Allowlist rule based on the Custom Allowlist URL category, which includes file type fallback decisions by Zscaler: for single-part non-URL-encoded requests the default is HTTP non-file text data, and for multipart requests and single-part URL-encoded requests the default is HTTP Form data. [zia.dlp.runbook.fine-tuning:file-type-fallback] The runbook says to avoid configuring a catch-all DLP policy rule with ANY file type, and that due to the file type fallback decisions by Zscaler, HTTP Form data can be dropped from the file type list of the last catch-all rule. [zia.dlp.runbook.fine-tuning:avoid-catch-all]

**Dictionaries and engines.** The runbook recommends using a combination of a Predefined Dictionary with a Low or Medium Confidence Score Threshold and a Custom Dictionary for Pattern/Phrase, with an example DLP Engine built from the predefined dictionary NRIC Numbers (Singapore) and a custom dictionary, previewed as ((NRIC Numbers (Singapore) > 5) AND ((Identity Card Number (Phrases 1) > 0) OR (Identity Card Number (Phrases 2) > 0))). [zia.dlp.runbook.fine-tuning:dictionary-combination] [gap:zia.dlp.runbook.fine-tuning:dictionary-thresholds]
