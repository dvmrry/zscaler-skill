# ATP detection categories and what each toggle covers (zia.atp.categories)
Also called: atp toggles; known phishing sites; suspected phishing; crypto mining blocked; web spam; irc tunneling; ssh tunneling; anonymizers; wpad; cookie stealing; bittorrent blocked; google hangouts; malicious active content; fraud protection; xss protection; atp capture pcap

The Advanced Threats Policy tab lists ten groups of advanced threats to configure: Suspicious Content Protection (Page Risk), Botnet Protection, Malicious Active Content Protection, Fraud Protection, Unauthorized Communication Protection, Cross-Site Scripting (XSS) Protection, Suspicious Destinations Protection, P2P File Sharing Protection, P2P Anonymizer Protection and P2P VoIP Protection. [zia.atp.categories:groups] The ATP toggles are Allow or Block booleans, and each applies to the whole tenant rather than to a user, group or location; Page Risk is the exception, an integer threshold. [zia.atp.categories:toggles-tenant-wide-booleans]

**Malicious Active Content.** Malicious Active Content Protection has four Allow or Block toggles (Malicious Content & Sites for exploit kits, compromised websites and malicious advertising; Vulnerable ActiveX Controls; Browser Exploits; File Format Vulnerabilities for Office and PDF content) plus the Blocked Malicious URLs list. [zia.atp.categories:active-content] The Blocked Malicious URLs list has its own subject: [ATP Blocked Malicious URLs list: capacity, matching and API](kb:zia.atp.blocked-urls).

**Fraud.** The Fraud Protection section has toggles for Known Phishing Sites, Suspected Phishing Sites (which inspects page content for phishing indications), Spyware Callback, Web Spam, Cryptomining and Known Adware & Spyware Sites. [zia.atp.categories:fraud] Phishing detection combines signature-based and AI/ML models and covers URL-based techniques such as typosquatting, punycode, character substitution and domain hijacking. [zia.atp.categories:phishing-methods] Blocking Cryptomining can stop sites that use cryptomining as a source of income from working, and can interfere with legitimate attempts to use cryptocurrency for payments. [zia.atp.categories:crypto-mining-false-positive] A site exempted for mining is exempt from all ATP scanning: [ATP Security Exceptions (the allowlist): what it skips and what it does not](kb:zia.atp.security-exceptions).

**Unauthorized communication.** Unauthorized Communication Protection has four toggles: IRC Tunneling and SSH Tunneling (each tunneled over HTTP/S), Anonymizers, and WPAD Protocol, which covers use of the Web Proxy Auto-Discovery protocol from external sources. [zia.atp.categories:unauthorized-communication] No WPAD key appears in the OpenAPI ATP settings object, although the console has a WPAD Protocol toggle. [zia.atp.categories:wpad-no-key]

**XSS.** XSS protection has two toggles: Cookie Stealing, for third-party sites that gather cookie information (often IPS signature-based and so high fidelity), and Potentially Malicious Requests, a type of cross-site scripting request. [zia.atp.categories:xss]

**P2P.** BitTorrent can be allowed or blocked, but its content is encrypted and cannot be inspected. [zia.atp.categories:bittorrent-uninspectable] Tor needs more than the toggle: [Fully blocking Tor: the ATP toggle is not enough](kb:zia.atp.tor). Google Hangouts is deprecated and replaced by Google Chat; controls for Google Chat and other cloud applications are in Data Security > Inline CASB > SaaS/Cloud App Policy, in an Instant Messaging rule. [zia.atp.categories:hangouts-deprecated]

Botnet, Page Risk and Blocked Countries are in [ATP Botnet Protection: C2 servers, C2 traffic, the alert toggle and DGA](kb:zia.atp.botnet), [ATP Page Risk threshold and how the score is built](kb:zia.atp.page-risk) and [ATP Blocked Countries: server location, not user location](kb:zia.atp.blocked-countries).

**Capture.** If Traffic Capture is enabled, the Capture option appears when Block is selected, unlike Malware Protection where it appears for Allow or Block. Capturing Allow and Block traffic for web and non-web threat categories is done in the IPS Control policy. [zia.atp.categories:capture-on-block]

**Names in the API.** The console toggles map to these settings keys: Malicious Content & Sites = malwareSitesBlocked; Vulnerable ActiveX Controls = activeXBlocked; Browser Exploits = browserExploitsBlocked; File Format Vulnerabilities = fileFormatVunerabilitesBlocked; Known Phishing Sites = knownPhishingSitesBlocked; Suspected Phishing Sites = suspectedPhishingSitesBlocked; Spyware Callback = suspectAdwareSpywareSitesBlocked; Web Spam = webspamBlocked; Cryptomining = cryptoMiningBlocked; Known Adware & Spyware Sites = adSpywareSitesBlocked; IRC Tunneling = ircTunnellingBlocked; SSH Tunneling = sshTunnellingBlocked; Anonymizers = anonymizerBlocked; Cookie Stealing = cookieStealingBlocked; Potentially Malicious Requests = potentialMaliciousRequestsBlocked; BitTorrent = bitTorrentBlocked; Tor = torBlocked; Google Hangouts = googleTalkBlocked; Command & Control Servers = cmdCtlServerBlocked; Command & Control Traffic = cmdCtlTrafficBlocked; Domain Generation Algorithm (DGA) Domains = dgaDomainsBlocked. Each is a boolean; the Capture flag is the same key with the Capture suffix, except cookie stealing. [zia.atp.categories:toggle-wire-keys] The field-name traps are in [ATP API: one settings object, two URL lists, and the field-name traps](kb:zia.atp.api-surface). A new block with no matching edit may be a recategorization: [ATP AI/ML recategorization: why a URL can start blocking with no policy change](kb:zia.atp.ai-ml-recategorization).

What to check:
1. Which toggle within the groups matches the user's symptom, and whether that toggle is set to Block.
2. Whether the WPAD Protocol toggle exists in the tenant, since no API key is documented for it.

Inferred, not quoted (say so when an answer rests on one):
- [zia.atp.categories:toggle-wire-keys] Tier B: The mapping rests on each key's API description matching the help page's wording (for example suspectAdwareSpywareSitesBlocked describes spyware callback traffic and googleTalkBlocked names Google Hangouts). No source lists the pairs.
- [zia.atp.categories:wpad-no-key] Tier B: An absence: the spec lists 48 properties and none names WPAD. The SDKs mirror the spec. A toggle that exists only in the console cannot be read or written by the API.
- [zia.atp.categories:toggles-tenant-wide-booleans] Tier B: Allow or Block is stated for the Malicious Active Content group; the other groups are taken to share it because toggle-wire-keys maps every console toggle to a boolean key.
