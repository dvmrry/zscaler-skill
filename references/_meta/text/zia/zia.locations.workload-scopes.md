# AWS workload sublocation scopes (VPC endpoint, VPC, account, namespace) (zia.locations.workload-scopes)
Also called: sub_loc_scope; sub_loc_scope_values; sub_loc_acc_ids; workload sublocation; vpc endpoint scope; namespace scope; cloud connector sublocation; overlapping ip workload

Workload sublocations are the sublocations created for Cloud Connector workloads, and they differ from ordinary ones in several ways. A sublocation scope segregates workload traffic from one sublocation so different Cloud Connector and ZIA policies apply. It exists only for Workload-type sublocations whose parent location is tied to AWS Cloud Connector groups, with scope types Namespace, Account, VPC and VPC Endpoint (`NAMESPACE`, `ACCOUNT`, `VPC`, `VPC_ENDPOINT` in Terraform's `sub_loc_scope`). [zia.locations.workload-scopes:scope-types-and-availability] The VPC, Namespace and Account scope types need workload discovery enabled for the tenant; the VPC Endpoint scope type does not. [zia.locations.workload-scopes:discovery-required] `sub_loc_acc_ids` lists the AWS account IDs associated with the parent location of a sublocation created in the Cloud & Branch Connector Admin Portal. [zia.locations.workload-scopes:account-ids-field]

Every sublocation within one location must use the same criteria: scope only, scope plus IP address range, or IP address range only. [zia.locations.workload-scopes:same-criteria-in-a-location] Duplicate or overlapping IP address ranges within the same namespace are supported when the subnets sit in separate sublocations (stated for the distributed VPC endpoint model), so policy lookup can tell apart workloads that share an address space. [zia.locations.workload-scopes:overlap-allowed-across-scopes] In a centralized VPC endpoint deployment a sublocation can be based on the hub VPC but not on the spoke VPCs; the hub VPC can be combined with a unique IP range for finer sublocations. [zia.locations.workload-scopes:hub-vpc-only]

Authentication is not supported for Workload traffic type sublocations. [zia.locations.workload-scopes:no-authentication] A scoped sublocation holds at most 10 namespace values, 10 account values, 50 VPC values and 50 VPC endpoint values. [zia.locations.workload-scopes:scope-value-limits]

Their default Workload type and group are in [How locations land in groups: location type, defaults, exclusion flags and Terraform support](kb:zia.locations.group-assignment). Ordinary sublocation IP rules are in [Which IP addresses a sublocation matches, overlap rules and XFF](kb:zia.locations.ip-scoping).

Combining a scope with an IP address range makes sublocations more granular, and a scope can be added to existing sublocations that already have an IP address range. [zia.locations.workload-scopes:scope-added-to-ip-range]
