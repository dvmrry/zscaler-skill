# Where Bandwidth Control sits in policy enforcement (zia.bandwidth-control.pipeline-position)
Also called: bandwidth control order of enforcement; bandwidth control after firewall; does blocked traffic reach bandwidth control

Bandwidth Control does not decide whether a transaction is allowed; it decides how much bandwidth the allowed transaction gets, and it does that last. Bandwidth Control is the final entry in the ordered policy lists the web module applies to HTTP GET and POST requests, to responses, and to the domain-only pass on CONNECT or SNI. [zia.bandwidth-control.pipeline-position:last-in-web-order] Bandwidth Control decides whether a request gets full or reduced bandwidth from the organization's Bandwidth Control policy and the current bandwidth usage at the user's location. [zia.bandwidth-control.pipeline-position:usage-decides]

**What it never sees.** In the web module a transaction that violates a policy is blocked immediately and the policies that follow are not enforced. [zia.bandwidth-control.pipeline-position:block-stops-later-policies] The firewall module judges web traffic before the web module does ([Where the firewall sits in the traffic path](kb:zia.firewall.traffic-path)). Traffic blocked by the Firewall module or by an earlier web policy never reaches Bandwidth Control, so Bandwidth Control only shapes transactions that every earlier stage allowed. [zia.bandwidth-control.pipeline-position:only-surviving-traffic] The policies that can block a flow are [ZIA URL Filtering](kb:zia.url-filtering), [Cloud App Control versus URL Filtering: which applies](kb:zia.cloud-app-control.precedence) and the firewall.

Which protocols are shaped at all: [How Bandwidth Control allocates bandwidth: minimum, maximum, contention](kb:zia.bandwidth-control.allocation).

What to check:
1. Whether the transaction was blocked or allowed by the earlier stages, since only transactions that every earlier stage allowed reach Bandwidth Control.
2. Which rules shape the transaction, only once it is known that it was allowed.
