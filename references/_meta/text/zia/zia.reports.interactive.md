# Interactive Reports: standard, custom and scheduled reports, export, import and printing (zia.reports.interactive)
Also called: interactive reports; custom report; standard report; scheduled report; schedule a report; report favorites; print view; exclude location

Interactive Reports is the console area that holds standard reports, custom reports and their schedules. An organization can create up to 500 custom reports, shared across all administrators, and each report can display up to 20 widgets. [zia.reports.interactive:custom-limit-500] Standard reports cannot be deleted or edited; to change one, copy it, which creates a new custom report, and edit the copy. [zia.reports.interactive:standard-not-editable] Admins with the default super admin role can edit or delete any custom report; all other admins can edit or delete only their own. [zia.reports.interactive:owner-or-super-admin] Deleting a custom report also removes it from Favorites, and deletes its schedule if it was scheduled; deleted reports cannot be restored. [zia.reports.interactive:delete-cascades] Each admin can favorite up to 50 reports. [zia.reports.interactive:favorites-50]

**Building a report.** A report title must be unique and can contain up to 75 characters. [zia.reports.interactive:title-75] A new report is created under a report data class; the page lists Firewall, Endpoint DLP (EDLP), Email DLP and Combined among the classes, and says reports can cover web traffic, mobile traffic or a combination of both. [zia.reports.interactive:data-classes] When creating a report, the time frame can be set for all widgets or for each widget separately, and this option can be changed at any time. [zia.reports.interactive:per-widget-time] A custom report time frame cannot start before January 1, 2012 and spans at most 90 days; selecting multiple days shows the sum of bytes or transactions per day in charts. [zia.reports.interactive:custom-time-frame] Some data types are mutually exclusive between report-level and widget-level filters; for example, a Department filter at the report level removes Location at the widget level. [zia.reports.interactive:filter-narrowing] A widget displays the top five items and groups everything else under Other. [zia.reports.interactive:top-five-other] The widgets for the Top Threat Names report cannot be used in custom reports. [zia.reports.interactive:top-threat-names-excluded] The View Logs option is not available for charts that display secure browsing class, data or status, because those charts only use samples as their data units. [zia.reports.interactive:view-logs-not-for-samples]

**Excluding locations.** User-related widgets include locations and users by default. The Exclude Location filter applies to all user-related widgets except those in the default Security dashboard, and also to the Executive Report and all standard, user-related reports in Interactive Reports. [zia.reports.interactive:exclude-location]

**Export, import and print.** Only custom reports can be exported, to a plain-text JSON file that includes the report definitions (to export a standard report, copy it first). Only JSON files exported from the Zscaler Admin Console can be imported, and with more than one organization a report exported from one can be imported into another. [zia.reports.interactive:export-import-json] The page's procedure for duplicating a report edits the exported JSON file in a text editor and changes the report's user name and title. [zia.reports.interactive:duplicate-by-editing-json] Any standard or custom report can be printed from Print View; some settings, such as printing to PDF, depend on the OS and browser. [zia.reports.interactive:print-view] What the exported JSON contains beyond report definitions is open [gap:zia.reports.interactive:export-schema].

**Scheduling.** An organization can schedule up to 500 reports, and a report can be associated with many schedules, for example when a super admin schedules the same reports for department managers in different time zones. [zia.reports.interactive:schedule-limit-500] A scheduled report always reflects the current parameters of the report that is scheduled. [zia.reports.interactive:schedule-uses-current-parameters] A super admin can view and edit all scheduled reports; other administrators can view and manage only their own scheduled reports. [zia.reports.interactive:schedule-ownership] A schedule sends the report to up to 32 email addresses, each on a separate line. [zia.reports.interactive:recipients-32] Daily gives the report for the previous day from 12:00:00 AM to 11:59:00 PM; Monthly delivers it on the first day of every month; the schedule's Time Zone is the one the service uses when it generates the report. [zia.reports.interactive:frequency-semantics] Weekly delivery is described two ways [divergence:zia.reports.interactive:weekly-delivery-time]. For a daily report, the link displays the report for the time interval for which the report was scheduled. [zia.reports.interactive:daily-link-fixed-interval] Scheduled reports are emailed to the recipients as links; when a recipient clicks the link, the report appears in Print View. The link is valid for 15 days only. [zia.reports.interactive:schedule-links] Who can open the link is described two ways [divergence:zia.reports.interactive:link-access]. Recipients can only view the report; they cannot edit it or navigate to any other area of the Zscaler Admin Console. [zia.reports.interactive:recipients-view-only]

What to check:
1. Whether a change to a standard report was made on a copy, since standard reports cannot be edited.
2. Whether deleting a custom report also removed a schedule or a favorite that someone depends on, since deleted reports cannot be restored.
3. When a scheduled report is sent and who can open its link, which the pages describe two ways.
4. Whether a filter change after scheduling is what changed the content recipients receive.

Sources disagree (name both sides):
- The Scheduling Reports page says Weekly delivery is every Monday at 9:00 AM, and the same page lists a Sent at field for the time the report is sent. [divergence:zia.reports.interactive:weekly-delivery-time]
  - zscaler-help: A Weekly schedule delivers the report every Monday at 9:00 AM.
  - zscaler-help: Sent at is the time at which the report is to be sent, without saying it does not apply to Weekly.
  Impact: Whether an administrator can choose the time of a Weekly schedule, or it always goes Monday at 9:00 AM, is not settled by the page. The Sandbox weekly-email pages are a different report type.
- The Scheduling Reports page says anyone with a scheduled report's link can access the report, and also that a recipient who pastes the URL must log in to the Admin Console. [divergence:zia.reports.interactive:link-access]
  - zscaler-help: Anyone who has the link can access the report; the link is valid for 15 days only.
  - zscaler-help: A recipient who copies and pastes the report URL gets the Admin Console login page and must enter a valid user name and password.
  Impact: Whether a scheduled-report link is usable by a person with no Admin Console account is not settled by the page.
