# ZIA Insights chart settings: units, chart types, top-N, filters, history and the data types that appear only on an Insights page (zia.insights.data-types)
Also called: data types and filters; insights data type; history bar; start over; trend chart; top 5 other; pqc key exchange insights

The Web, Mobile, Firewall, DNS, Endpoint DLP, Email DLP and Extranet data types and filters pages each say their data types and filters are used in a dashboard or report widget or on an Insights page; The Web, Firewall, DNS, Endpoint DLP and Email DLP pages add that some data types appear only on the Insights page, not in the New Widget window. [zia.insights.data-types:two-ways] The default Web Insights page is a trend chart of the Overall Traffic data type for the current day, in transactions; a data type works as the "grouped by" of the chart. [zia.insights.data-types:default-chart]

**Time frame and aggregation.** On an Insights page a custom time frame can end up to 92 days after its start date, and a multi-day time frame shows the sum of bytes or transactions per day in the chosen chart type. [zia.insights.data-types:custom-92] Chart data is aggregated on the viewing administrator's local time, except trend charts; for example Current Day covers 12:00 AM to 11:59 PM local time. [zia.insights.data-types:local-time]

**Units.** The About Insights article says chart data is viewed as Units, as Metrics in Tunnel Insights only, and as Time for the Domain and URL Host data types only. [zia.insights.data-types:units-metrics-time] The Web data types page offers time on more data types than this [divergence:zia.insights.data-types:time-unit-scope]. A widget's unit is Transactions or Bytes; Samples are used only with the Secure Browsing Class, Status and Type data types, and bps only with Bandwidth by Department, by Location, by Location Groups, by Rule, Bandwidth Class and Bandwidth Consumption. View Logs is not offered on charts of secure browsing class, data or status because they use samples. [zia.insights.data-types:widget-units] Firewall and DNS Action data can be viewed as sessions or bytes; the Web data type for HTTP POST requests uses only the unit Bytes; Bandwidth Class shows bits per second; a 7-day bandwidth consumption trend chart can drill down to a 5-minute view. [zia.insights.data-types:per-type-units]

**Chart types and top items.** Widgets and the Web, Mobile, Firewall, DNS and Tunnel Insights charts offer pie, bar, line, value and table charts. [zia.insights.data-types:chart-types] For certain data types an Insights bar chart or table can show the top 5, 10, 25, 50 or 100 items; trend and pie charts show only the top 5, with the rest grouped as Other. [zia.insights.data-types:top-n] Among the data types that cannot be used with a trend chart are, on the Web page, the data types for user, URL category, instant messaging, detected viruses or spyware, webmail and a data type that only uses samples; on the Mobile page, application category and user; on the Endpoint DLP and Email DLP pages, document type and user. [zia.insights.data-types:no-trend-chart] How many items a widget shows is in [ZIA dashboards, widgets and notes: predefined dashboards, limits, units, time frames and drill-down](kb:zia.insights.dashboards).

**Filters.** Multi-value filters such as Users, Departments and Locations take up to 200 values in one filter and can include or exclude them; as an example, the Department and Location filters don't appear together in Insights but do in Insights Logs. [zia.insights.data-types:filters-200-values] On the Web and Mobile data types pages the User, Department and Location filters list 200 results at a time; the Endpoint DLP and Email DLP pages say this of the User and Department filters, and the Tunnel page of the Location filter. [zia.insights.data-types:filter-lists-200] The history bar keeps up to 50 versions of the chart and deletes the oldest beyond that; changing an earlier version deletes all later ones. Start Over returns to the default chart with the data type menu on Overall Traffic, filters reset and every chart but the default deleted from the history bar, and choosing a different data type resets the filters. [zia.insights.data-types:history-bar]

**Data types that appear only on an Insights page.** Firewall data types that appear only on the Firewall Insights page are Client Source IP, Client Tunnel IP, Server Destination IP and Threat Name; among the DNS data types that appear only on the DNS Insights page is one for the client IP address, and another for a destination server has no pie chart or trend line. [zia.insights.data-types:insights-only-firewall-dns] Among the web data types that appear only on the Web Insights page are ones for the internet gateway location IP addresses, source IP address information and an associated destination server (each viewable by number of transactions, bytes or time), ones grouped by domain and by host (with a Time unit for the duration spent on each URL), and PQC data types comparing PQC with classical key exchange and ranking client-side negotiated PQC or Hybrid key exchange algorithms and the users who could negotiate them. [zia.insights.data-types:insights-only-web] In the PQC vs. Classical Key Exchange data type, Classical covers transactions whose client key exchange is Classical or Unknown, and PQC those whose client key exchange is PQC or Hybrid. [zia.insights.data-types:pqc-buckets] The Endpoint DLP and Email DLP Insights-only data types are not named [gap:zia.insights.data-types:edlp-insights-only-types], and whether Mobile and Extranet have any is not said [gap:zia.insights.data-types:mobile-extranet-insights-only].

**Tunnel and users.** Tunnel Insights charts are filtered by Location (default All), Location Group (default None), Tunnel Destination IP, Tunnel Source IP, Tunnel Type (All, GRE or IPSec) and VPN Credential (default All). [zia.insights.data-types:tunnel-data-types] With User as the Web Insights data type the page lists top users, and Export All Active Users exports the active users to CSV; user reports include locations by default, which widgets can exclude. [zia.insights.data-types:user-reports] The time-based Web Insights report adds a user's time on the internet across all tabs and devices in the filtered period, covers the last seven days only, and can be inflated by traffic such as scripts and servers throttling update pushes. [zia.insights.data-types:browsing-time]

What to check:
1. Whether a data type is available in a widget or only on the Insights page before building a dashboard around it.
2. Whether a data type supports a trend chart, and which units it offers, before choosing it.
3. Whether a filter list is complete, since the User, Department and Location filters list 200 results at a time on the pages that say so.

Sources disagree (name both sides):
- About Insights offers the Time unit for the Domain and URL Host data types only, while the Web data types page also offers time on the data types for gateway location IP addresses and a destination server. [divergence:zia.insights.data-types:time-unit-scope]
  - zscaler-help: Time is available for Domain and URL Host only.
  - zscaler-help: The data types for gateway location IP addresses and for a destination server can be viewed by transactions, bytes or time.
  Impact: Which data types offer the Time unit depends on which page is read; the pages do not say which is complete.
