# DNS tunnel detection (zia.dns-control.tunnel-detection)
Also called: dns tunneling; dns tunnel detection; dns exfiltration; detecting and controlling dns tunnels; dns tunnels rule

DNS Control can detect and prevent DNS tunneling; Zscaler points to a separate page, Detecting and Controlling DNS Tunnels, for details. [zia.dns-control.tunnel-detection:tunnel-purpose] Detection uses machine learning: DNS proxy logs go to the analytics system and a detection engine that computes a risk score per domain; detected tunnel hostnames propagate to all ZIA Public Service Edges, and the proxy acts per your policy. [zia.dns-control.tunnel-detection:detection-method] Detected tunnels fall into three categories: Commonly Allowed (productive, mostly security services), Commonly Blocked (malicious or harmful) and Unknown (not yet classified); four further application categories (Network Service, Social Networking, Web, Web Search) can be controlled at DNS level. [zia.dns-control.tunnel-detection:three-categories]

A DNS rule's `applications` field holds DNS tunnels and network applications. [zia.dns-control.tunnel-detection:tunnels-as-applications] Selecting a parent tunnel category in a rule includes all tunnels in it. [zia.dns-control.tunnel-detection:category-selection] The predefined Unknown DNS Traffic rule, set to block, stops malformed queries and non-DNS traffic on port 53 and some forms of DNS abuse consistent with tunneling methods; Zscaler also recommends a rule blocking the Commonly Blocked and Unknown tunnel categories. [zia.dns-control.tunnel-detection:unknown-traffic-rule] The service logs all detected DNS tunnels and network apps in DNS Insights, and the DNS Overview dashboard shows the most common ones. [zia.dns-control.tunnel-detection:logged-in-insights]

The detection signals, the log fields and a carve-out for legitimate tunnels are open [gap:zia.dns-control.tunnel-detection:tunnel-mechanics].

**DNS application groups.** DNS application groups group DNS tunneling traffic and other web applications for policy: legitimate, commonly blocked and unrecognized DNS tunnels and DNS network applications (not to be confused with DPI-based network applications), managed in the DNS Control policy. [zia.dns-control.tunnel-detection:dag-contents] DNS application groups manage DNS tunnels and web applications through DNS Control rules; the help's example is one group of tunnels and web applications allowed for specific users and another of tunnels blocked for all users. [zia.dns-control.tunnel-detection:dag-use] A DNS application group's name cannot exceed 255 characters, any number of DNS tunnels and network applications can be selected, and the description cannot exceed 10,240 characters. [zia.dns-control.tunnel-detection:dag-fields] DNS tunnels detected in the network can be investigated and analyzed using Zscaler DNS logs. [zia.dns-control.tunnel-detection:dag-investigation] The selectable tunnels and applications and any group-count limit are open [gap:zia.dns-control.tunnel-detection:dag-members-limits].
