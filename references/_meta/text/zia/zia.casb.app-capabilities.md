# SaaS Security per-application capabilities: onboarding privileges, webhooks, historical scan, licensing, scanned content, actions and activities (zia.casb.app-capabilities)
Also called: supported capabilities; saas security supported capabilities; historical scan; onboarding privileges; which saas apps support webhooks

The Understanding SaaS Security Supported Capabilities article is a per-application matrix. The article lists the supported administrative capabilities and actions for all SaaS Security applications; its capability table has per-application columns Onboarding Privileges, Webhooks, Historical Scan, Malware Support, Incident Management (Workflow Automation), Activity Alerts and Monitoring and Licensing. [zia.casb.app-capabilities:matrix-columns]

**Collaboration.** In the capability table Zoom needs Owner, supports webhooks, scans 1 month and needs Zoom Pro or above; MS Teams needs Admin, Teams, and SharePoint Admin, supports webhooks, scans 6 months and lists a minimum of Microsoft 365 Business Standard with Teams Activity Report if Audit (Standard) is bundled, also working with E3 and E5; Slack needs Org Admin, does not support webhooks, scans 6 years and needs Slack Enterprise Grid; Cisco Webex needs Admin, supports webhooks, scans 15 days and lists a Webex calling License, with a Webex Pro License for real time. [zia.casb.app-capabilities:collaboration]

**File share.** In the capability table OneDrive and SharePoint need Global Admin, SharePoint Admin, support webhooks, scan 6 years and list Min - Microsoft 365 Business Standard with Teams Activity Report would work if Audit (Standard) is bundled, Works with E3 and E5 also; Google Drive needs Super Admin or Custom Role Admin (the row says to check the custom connector), supports webhooks, scans 6 years and needs Google Enterprise or above; Box (1 year, Box Enterprise License) and ShareFile (4 years, ShareFile Enterprise Industry License) need Admin and do not support webhooks; Smartsheet needs Admin, does not support webhooks, scans 30 days, and its activity cell reads Supported (Alerts and Monitoring only) with Smartsheet Enterprise with event reporting plugin; Confluence and Dropbox need Admin, support webhooks, scan 5 years and need their Enterprise licenses. [zia.casb.app-capabilities:file-share]

**Public cloud storage and source code repositories.** In the capability table Amazon S3 Bucket needs Admin, supports webhooks, scans 1 year and lists Free Tier and above; Azure Storage Account needs Storage Account Contributions, does not support webhooks, scans 1 year and lists Pay as you go; GCP needs Org Admin, supports webhooks, scans 1 year and lists Free Tier and above; GitHub needs Admin, does not support webhooks, scans 5 years and needs GitHub Enterprise Cloud; GitLab and Bitbucket need Admin, support webhooks, scan 5 years and need Premium licenses. [zia.casb.app-capabilities:cloud-storage-and-repos]

**Email, CRM, ITSM and Gen AI.** In the capability table Exchange (Admin, Exchange Admin) and Gmail (Super Admin, Custom Role) support webhooks and scan 6 years; Salesforce (Admin) and Dynamics 365 CRM (Admin) do not support webhooks and scan 6 years, with Salesforce working with the Enterprise, Unlimited, Performance, Developer and SandBox editions and needing the Event Monitoring add-on for the Activity Report; Jira needs Admin, supports webhooks, scans 1 year and needs Jira Enterprise; ServiceNow needs Not Necessary, does not support webhooks, scans 6 years and works with all licenses; ChatGPT needs Admin, does not support webhooks, scans 6 years, and its activity cell and licensing cell read Not Supported. [zia.casb.app-capabilities:email-crm-itsm-genai]

**What the matrix leaves open.** What the Historical Scan values mean is open [gap:zia.casb.app-capabilities:historical-scan-meaning]. The Smartsheet and ChatGPT cells are open [gap:zia.casb.app-capabilities:matrix-cell-oddities]. How far back a scan may reach is also in [CASB scan schedules: states, historical data, stop and restart](kb:zia.casb.scans).

**Scanned content.** The Actions table gives each application's scanned content, for example Slack channels (messages and attachments) and 1:1 chats, Amazon S3 buckets and files, GitHub commit files within those repos with repositories only with organizations, Salesforce files, cases and Chatter body, ServiceNow tables (tasks, incident, change, problem, etc.) and attachments, and ChatGPT messages, files uploaded and files generated by ChatGPT. [zia.casb.app-capabilities:scan-content]

**Actions.** Actions differ by application in the Actions table: the MS Teams row lists Notify Users and Report Incident, then None, then Quarantine Malware (Files), Remove Malware and Report Malware; Amazon S3 Bucket lists Remove Public Shareable Link and Report Incident, then None; Azure Storage Account lists Report Incident, then None; GitHub lists Report Incident twice and Report Malware; ChatGPT lists Report Incident, then None, then Report Malware. [zia.casb.app-capabilities:remediation-examples] Labeling actions are application specific in the Actions table, which lists Apply MIP Labels, Apply Google Drive Label and Apply Box Classification Label as actions. [zia.casb.app-capabilities:labels] The Dropbox row's Apply Box Classification Label action disagrees with the DLP actions table [divergence:zia.casb.app-capabilities:dropbox-box-label], which resolves [gap:zia.casb.app-capabilities:dropbox-label].

**DLP actions by application.** The About Data at Rest Scanning DLP page's Supported DLP Actions table maps actions to applications, for example: Admin Quarantine to Box, Citrix ShareFile, Confluence, Dropbox, Google Drive, OneDrive, SharePoint and Smartsheet; Apply MIP Label to OneDrive and SharePoint; Apply Box Classification Label to Box; Notify Users Only to Microsoft Teams, Slack and Webex Teams; Quarantine to Jira, Dynamics 365, Salesforce, ServiceNow, Slack and Webex Teams; Move to Restricted Folder to Confluence; Remove All Collaborators to Dropbox and Google Cloud Platform; Remove External Collaborators to Smartsheet; and Update to Not Discoverable for All to Google Drive. [zia.casb.app-capabilities:dlp-actions-by-app] Smartsheet's place under Admin Quarantine disagrees with the capability matrix [divergence:zia.casb.app-capabilities:smartsheet-admin-quarantine].

**Activities.** The article says Activities is currently not supported for the Smartsheet application; its Activities table lists, for example, Slack user activities Create, Delete, Download, Login Fail, Login Pass, Move, Upload and Share Link and GitHub user activities Create, Fork, Pull Request and Share with NA for admins. [zia.casb.app-capabilities:activities]

What to check:
1. Whether the application's licensing and onboarding privilege in the matrix are met before concluding a tenant cannot be onboarded.
2. Whether the application's Actions row offers the action a rule needs, since remediation differs by application.

Sources disagree (name both sides):
- The About Data at Rest Scanning DLP table lists Smartsheet under Admin Quarantine; the Supported Capabilities matrix's Smartsheet row has no Admin Quarantine action. [divergence:zia.casb.app-capabilities:smartsheet-admin-quarantine]
  - zscaler-help: Admin Quarantine is available for Box, Citrix ShareFile, Confluence, Dropbox, Google Drive, OneDrive, SharePoint and Smartsheet.
  - zscaler-help: Smartsheet's actions are Remove, Remove External Collaborators, Remove Internal Collaborators and Shareable Link, Remove Sharing and Report Incident, with no Admin Quarantine.
  Impact: Whether a Smartsheet DLP rule can use Admin Quarantine is not settled by the documentation. A related page says remediation actions are not supported for Smartsheet on the Assets with Incidents page (zia.reports.saas-security:awi-file-sharing-actions).
- The Supported Capabilities Actions row for Dropbox lists Apply Box Classification Label; the About Data at Rest Scanning DLP table lists that action for Box only. [divergence:zia.casb.app-capabilities:dropbox-box-label]
  - zscaler-help: The Dropbox row lists Admin Quarantine, Apply Box Classification Label and Change to Read Only among its actions.
  - zscaler-help: Apply Box Classification Label is listed for Box.
  Impact: Whether Dropbox offers a Box classification label action is not settled; the matrix row may carry the Box action over, but neither page says which is intended.
