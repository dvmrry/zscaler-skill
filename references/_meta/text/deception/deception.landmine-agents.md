# Landmine agent and agentless: install, requirements, proxies, management and OS feature support (deception.landmine-agents)
Also called: landmine agent; landmine agentless; ZCC Integrated; Standalone agent

A landmine agent is described as a persistent agent giving full-featured active deception, and landmine agentless as a permanent service on endpoints with a limited set of lures. [deception.landmine-agents:agent-vs-agentless-modes] The landmine agentless download article says agentless deploys a subset of the agent's features without the need for a permanently running service. [deception.landmine-agents:agentless-no-permanent-service] Whether agentless is a permanent service is disputed [divergence:deception.landmine-agents:agentless-service]. Landmine Agent installs on Windows, macOS, Linux and Windows via MECM or SCCM, and Landmine Agentless on Windows, macOS and Linux. [deception.landmine-agents:supported-platforms] An agent's Type is ZCC Integrated, Standalone or Agentless and can be filtered. [deception.landmine-agents:agent-types] Hub: [Zscaler Deception: decoys and lures, the Private Access integration, roles, and what can be automated](kb:deception.overview).

**Zscaler Client Connector.** Zscaler ITDR components (CredentialExposure.Console.exe, CredEx.exe, CredExInstaller.exe) are installed with Zscaler Client Connector, are legitimate, and do not run unless the functionality is enabled in ITDR. [deception.landmine-agents:itdr-components]

**Agents page.** The Agents page hides inactive agents by default (Show all agents is disabled); ZCC Integrated and Standalone agents with a last check-in older than 7 days are inactive, and agentless is always active. [deception.landmine-agents:inactive-agents] Safe Mode stops non-essential agent operations while log uploads and cleanup/uninstall stay active; decoy application and deployment, ITDR scans, event generation and other background services stop. [deception.landmine-agents:safe-mode] How Safe Mode is enabled is open [gap:deception.landmine-agents:safe-mode-control].

**Registration and download.** The agent registration token registers an endpoint at install, after which a session key is used for later requests; regenerating the token stops new agents registering with the old one, so automated deployments should be paused first. [deception.landmine-agents:registration-token] Landmine Agent downloads are Windows EXE, Windows MSI, macOS Intel pkg, macOS Apple Silicon pkg, Linux rpm and Linux deb; with endpoint deception via Zscaler Client Connector enabled for Windows, the agent comes from Client Connector instead. [deception.landmine-agents:download-formats] Landmine agentless downloads are Windows, macOS (Intel), macOS (Apple Silicon) and Linux, and the latest version is downloaded. [deception.landmine-agents:agentless-downloads]

**Windows agent.** The Windows install article says the Windows agent needs 64-bit Windows 10 or 11 with .NET 4.6.1 or later (Windows 7, 8 and 8.1 unsupported), 100 MB free memory, 1 GB free storage, 256 Kbps bandwidth and outbound port 443; these are also the agent's maximum utilization. [deception.landmine-agents:windows-requirements] For Windows 10 version 1607 and earlier, installing the latest .NET framework is mandatory for the installation to succeed. [deception.landmine-agents:windows-net-legacy] In the Windows install command, /qn (silent), CMC (portal hostname) and REGKEY (registration token) are required, and PROXIES (comma-separated, no white space) and /l*v log path are optional. [deception.landmine-agents:windows-install-parameters] The Windows agent tries the PROXIES list left to right, then the SYSTEM user's proxy, then a direct connection; proxy credentials with special characters must be URL-encoded. [deception.landmine-agents:windows-proxy-order]

**MECM, SCCM and GPO.** The MECM procedure downloads the Windows EXE installer, and states not to use the Windows MSI Installer with MECM because agents may not install properly with the MECM built-in MSI installation method. [deception.landmine-agents:mecm-not-msi] The MECM article lists 64-bit versions of Windows 10, .NET 4.6.1 or later, and a network file share reachable by all target systems (SYSVOL or any other share). [deception.landmine-agents:mecm-requirements] Whether MECM installs support Windows 11 is open [gap:deception.landmine-agents:mecm-windows-11]. In MECM, if the landmine service is renamed in the Admin Portal a new detection clause must be added, and the existing clause must not be removed or existing agents may not be detected. [deception.landmine-agents:mecm-detection-clause] A landmine agent can be installed on domain-joined machines through an AD Group Policy Object: a batch file with the installation command is added under Computer configuration > Policies > Windows settings > Scripts (Startup/Shutdown), and the command needs the full EXE path if it is on a shared folder. [deception.landmine-agents:gpo-install]

**Linux and macOS agent.** The Linux agent runs on 64-bit desktop Linux (not headless servers): Debian 10+, Ubuntu 20.04+ LTS, RHEL 8+, Fedora 35+ and openSUSE Leap 15.3+, with port 443 connectivity to the portal. [deception.landmine-agents:linux-supported] In the Linux RPM install and the macOS install, the instance name and agent registration token are pasted into /tmp/landmine.txt, which is created as a root-owned file with mode 600, and an optional third line holds comma-separated proxy URLs. [deception.landmine-agents:linux-install-token-file] The macOS agent needs macOS Ventura (13) or later and port 443 connectivity to the portal; Full Disk Access (for XPCServerApp.app, with a reboot) is optional but required for Defense Evasion, file decoy events, brute force login detections and process tree. [deception.landmine-agents:macos-requirements] Beginning with version 4.32, macOS .pkg installs overwrite an existing agent and move it to /opt/ with the previous service name retained, and uninstall.sh is no longer shipped (uninstall via the Admin Portal and manual removal with the updater's landmine remove command continue to be supported). [deception.landmine-agents:macos-4-32-changes] The release that 4.32 refers to is open [gap:deception.landmine-agents:macos-version-number].

**Agentless.** Windows agentless runs Landmine.Agentless.Win.x64.exe with -c (portal hostname) and -k (token) required, optional -l (info, debug, verbose) and -r (removes the policy); it requires .NET 4.6.1 or later, uses the current user's proxy, and runs as the current user. [deception.landmine-agents:agentless-windows] macOS agentless needs macOS Ventura (13) or later, notarization issues might occur if the executable is not downloaded using cURL, it is registered with sudo -i and applied without sudo, it uses the HTTP_PROXY and HTTPS_PROXY environment variables, and some policies may not run unless the binary is run on a GUI terminal session. [deception.landmine-agents:agentless-macos] The macOS agentless article lists the -l log level values as Debug, verbose, and Information. [deception.landmine-agents:agentless-macos-log-levels] Linux agentless lists Debian 10+, Ubuntu 20.04+ LTS, RHEL 8+, Fedora 35+ and openSUSE Leap 15.3+, uses the HTTP_PROXY and HTTPS_PROXY environment variables, and lists -l values info, debug and verbose. [deception.landmine-agents:agentless-linux] The Windows, macOS and Linux agentless articles each state that landmine agentless runs as the current user and that, if multiple users use the same system, it must be run separately for each user. [deception.landmine-agents:agentless-per-user] Removing agentless: run the removal command, separately for each user; delete C:\ProgramData\lma on Windows or /etc/lma (root privileges required) on macOS and Linux to remove the registration; then choose Delete Selected from the Actions menu in the portal. [deception.landmine-agents:agentless-removal]

**Management.** Agent configuration can be exported as CSV or JSON for all agents or filtered agents; the all-agents options export only the agents shown in the table, so Show all agents must be selected to export all agents including inactive ones. [deception.landmine-agents:export-config] Agent logs are fetched with Actions > Trigger Logs, a Download icon appears after 10 minutes, the download is a .zip, and logs cannot be downloaded from landmine agentless. [deception.landmine-agents:agent-logs] Uninstall removes the policies (retrying for three days) and then uninstalls the agent, whereas Force Uninstall removes policies on a best-effort basis before uninstalling. [deception.landmine-agents:uninstall-modes] Remote uninstall from the Admin Portal can occasionally fail or fail on network connectivity issues, in which case Windows agents can be uninstalled with msiexec /qn /x {94e4ac3b-2519-46eb-97bd-d6be9b6c8f55}; the uninstaller continues after 5 consecutive failures to remove the system entry from the portal, and if that is unsuccessful the entry must be deleted manually. [deception.landmine-agents:uninstall-windows-cli] Deleting an agent removes only its portal entry without uninstalling it, and agents whose Last Seen value is under 7 days cannot be deleted. [deception.landmine-agents:delete-agents] Typos in the vendor's install and removal commands are open [gap:deception.landmine-agents:command-typos].

**Feature support by OS.** The Defense Evasion and Privilege Escalation table has a header row listing Landmine Agent and Landmine Agentless and a second row listing Windows, macOS, Linux, Windows, macOS, Linux. [deception.landmine-agents:feature-layout] Reading the six columns in order (agent Windows, macOS, Linux; agentless Windows, macOS, Linux): Fake Security Process is Yes, Yes, No, No, No, No; MITM Detection Yes, Yes, Yes, No, No, No; Brute Force Detection Yes, Yes, No, No, No, No; In-Memory Credential Detection Yes, No, No, No, No, No. [deception.landmine-agents:feature-defense-privilege] Reading the six columns in order: AWS IAM, Chrome are Yes in all six; Firefox is Yes, No, Yes, Yes, No, Yes; Edge and Internet Explorer are each Yes, No, No, Yes, No, No. [deception.landmine-agents:feature-cloud-browser-lures] Reading the six columns in order: DbVisualizer, Network Drives, PuTTY, RDP, Squirrel DB, Windows Credentials and WinSCP Session are each Yes, No, No, Yes, No, No; FileZilla is Yes in all six. [deception.landmine-agents:feature-session-lures-windows] Reading the six columns in order: /etc/hosts File is No, Yes, Yes, No, No, No; Bash History and SSH Config are each No, Yes, Yes, No, Yes, Yes. [deception.landmine-agents:feature-session-lures-unix] Reading the six columns in order: Custom File Decoys are Yes, Yes, No, Yes, No, No; Credential File Decoys Yes, Yes, No, Yes, No, Yes; Preconfigured File Dataset Decoys Yes, Yes, No, No, No, No. [deception.landmine-agents:feature-file-decoys] Reading the six columns in order: PsExec Detection, Ransomware Detection and Kerberoast Detection are each Yes, No, No, No, No, No; Triage is Yes, Yes, No, No, No, No. [deception.landmine-agents:feature-advanced-capabilities]
