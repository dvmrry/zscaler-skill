# What the dated ZPC (Posture Control) release upgrade summary notes for 2022 and 2023 say (zpc.release-notes)
Also called: zpc release upgrade summary; posture control release notes; zpc what is new

The December 08, 2022 note says agentless vulnerability scanning of AWS Windows workloads is supported, for Windows Server 2016, 2019 and 2022. [zpc.release-notes:aws-windows-2022-12] The product hub is [What Zscaler Posture Control (ZPC) is to administer: portal access, setup order, notifications and audit logs](kb:zpc.overview).

**Vulnerability scanning notes.** The October 13, 2022 note says agentless vulnerability scanning of Azure Windows workloads is supported, for Windows Server 2016, 2019 and 2022. [zpc.release-notes:azure-windows-2022-10] The October 13, 2022 note says vulnerability scanning can be performed on AWS managed keys encrypted volumes as well as Customer Managed Keys encrypted volumes, and is supported for Linux workloads created from AWS marketplace AMIs except appliance AMIs. [zpc.release-notes:aws-keys-amis-2022-10] The September 06, 2022 note says vulnerability scanning of Azure Linux workloads is supported with limited availability, and that scanning can be enabled for specific instances and scheduled at regular intervals. [zpc.release-notes:azure-linux-2022-09] The March 01, 2023 note says ZPC supports agentless vulnerability scanning of Linux and Windows GCP workloads, both non-encrypted and encrypted with Google-managed encryption. [zpc.release-notes:gcp-workloads-2023-03] The September 13, 2023 note says the default scan schedule for cloud workloads is set to weekly and can be switched to daily. [zpc.release-notes:default-weekly-2023-09] The January 19, 2023 note says a workload or container image not scanned because of an internal or permission error shows scan status Failed with an error message in the ZPC Admin Portal; the September 13, 2023 note says scan errors related to insufficient privileges or missing cloud resources are shown on the Notification Center page. [zpc.release-notes:failed-scan-errors-2023] The May 17, 2023 note says ZPC supports scanning container images in Google Artifact Registry, in addition to the previous support for Google Container Registry, and says GCR is expected to be deprecated in the near future. [zpc.release-notes:gar-2023-05] The June 19, 2023 note says ZPC supports scanning workload images created in Azure Compute Gallery, where previously only Azure Marketplace images were supported. [zpc.release-notes:compute-gallery-2023-06] The June 19, 2023 note says ZPC supports detecting vulnerabilities in cloud workloads running Ubuntu 23.04 (Lunar Lobster); the April 19, 2023 note says it supports vulnerability scanning for Amazon Linux 2022 and Amazon Linux 2023. [zpc.release-notes:ubuntu-amzn-2023] The May 17, 2023 note says ZPC supports detecting vulnerabilities in some Microsoft packages, naming .NET Framework, .NET Core Runtime, .NET Runtime, ASP .NET, Visual Studio, PowerShell and SQL Server Management Studio. [zpc.release-notes:ms-packages-2023-05] Dated 2023 notes say ZPC identifies all active images used by containers in monitored clusters and scans them for vulnerabilities: EKS (March 23, 2023, scanning images present in ECR), GKE (June 19, 2023) and AKS (July 12, 2023). [zpc.release-notes:container-scanning-2023] The June 19, 2023 note says the Vulnerability Management page can list publicly exposed cloud workloads, and that container status (active or non-active) is shown in the Containers tab with a Running Status filter. [zpc.release-notes:public-exposure-containers-2023-06] The August 17, 2023 note says ZPC scans cloud assets and provides more information on detected security advisories, with links to details of the threat methods and risks. [zpc.release-notes:advisories-2023-08] The September 06, 2022 note says vulnerability scan results can be exported to an Excel file, and the vulnerabilities of a cloud asset can be viewed and exported. [zpc.release-notes:export-2022-09]

**IaC scanning notes.** The December 08, 2022 note says IaC supports scanning Bicep files by converting them with the Bicep CLI into JSON (ARM template) files and scanning the JSON. [zpc.release-notes:bicep-2022-12] The October 13, 2022 note says Zscaler IaC Scan can parse the Date and Numeric functions in ARM templates and the Date, Time and File System functions in Terraform templates. [zpc.release-notes:functions-2022-10] The September 06, 2022 note says ARM templates and specific functions are fully supported for IaC, with partial support of CIS benchmark compliance coverage. [zpc.release-notes:arm-2022-09] Dated 2022 notes on Terraform Cloud: September 06, 2022 says the Zscaler IaC Scan app can scan run tasks in Terraform workspaces; October 13, 2022 says Advanced Settings let you select the severity level for failing a build. [zpc.release-notes:terraform-cloud-2022] The January 19, 2023 note says Zscaler IaC Scan supports scanning Terraform Cloud templates during the pre-plan phase, which shows policy violations for specific lines of code. [zpc.release-notes:terraform-preplan-2023-01] The September 06, 2022 note says ZPC supports IaC scanning of push events in Microsoft Azure Repos, triggering a scan on push events. [zpc.release-notes:azure-repos-push-2022-09] The October 13, 2022 note says IaC integrations with Azure DevOps and GitLab can be reauthorized when authorization expired or the integration was unintentionally revoked, and that Visual Studio Code and CLI authentication launches into the browser and supports users mapped to multiple tenants. [zpc.release-notes:reauth-auth-2022-10] The January 19, 2023 note says IaC Scan can scan specific directories within a version control repository; the March 01, 2023 note says regex patterns can include or exclude file paths, with the include option under Advanced Settings for GitHub, GitLab and Azure Repos. [zpc.release-notes:paths-2023] The January 19, 2023 note says IaC scanning obfuscates secrets such as access keys and database passwords in Terraform and CloudFormation templates. [zpc.release-notes:secrets-2023-01] Dated 2023 notes add IaC scanning for Bitbucket repositories (April 19, 2023), a Zscaler IaC Scan plugin for JetBrains IDEs (March 23, 2023) and IaC CI/CD scanning on Amazon Linux 2 operating systems (September 13, 2023). [zpc.release-notes:scm-ide-2023]

**Alerts and filters notes.** The December 08, 2022 note says actions (Resolve, Unresolve, Ignore or Unignore) can be performed on multiple alerts at once by selecting checkboxes on the Alerts table. [zpc.release-notes:bulk-actions-2022-12] The July 12, 2023 note says ZPC supports manual remediation of AWS alerts: single alerts, bulk alerts, or all alerts generated by a specific policy. [zpc.release-notes:manual-remediation-2023-07] The January 19, 2023 note says an Ignore filter can have an end date; when it passes, the Ignore status is removed and the alert returns to Open or Resolved depending on whether ZPC still detects the misconfiguration. [zpc.release-notes:ignore-end-date-2023-01] The January 19, 2023 note says an icon appears in the Ignore Rule table when an ignore rule is no longer valid, and the rule is automatically disabled. [zpc.release-notes:ignore-rule-invalid-2023-01] The January 19, 2023 note says new ignore filter criteria include Cloud (an entire cloud service provider) and Policy Severity. [zpc.release-notes:ignore-options-2023-01] The August 17, 2023 note says the Add Ignore filter action is available by default to the Administrator and Security Operations roles, other ZPC users have view-only permission, and others can be given it through Ignore Rules permissions in Global Modules in custom roles; the Cloud Accounts attribute on the Filter Scope page is optional. [zpc.release-notes:ignore-permissions-2023-08] Dated 2023 notes say Alert Ignore filters can filter on Kubernetes clusters and namespaces (May 17, 2023) and that the Policy Focus option selects whether the Ignore filter focuses on assets, identities or both (April 19, 2023). [zpc.release-notes:ignore-k8s-focus-2023] The October 30, 2023 note says compliance ignore rules can be configured on combinations of policies, asset types, regions and accounts, and that ZPC does not display ignored compliance findings on compliance dashboards or reports. [zpc.release-notes:compliance-ignore-2023-10] The October 30, 2023 note says using compliance ignore filters can affect ZPC's compliance score evaluation, and that when you ignore or include an asset or policy the score might change. [zpc.release-notes:compliance-score-2023-10] The October 30, 2023 note says ZPC lets you upload a trusted IP list, and excludes those IPs when examining publicly exposed assets or identities. [zpc.release-notes:trusted-ip-2023-10] The March 01, 2023 note says cloud alerts have two time range filters (Created Date and Updated Date) and IaC alerts have three (Scan Time, Created Date, Update Date). [zpc.release-notes:time-filters-2023-03] The March 01, 2023 note defines Created Date as the first time the misconfiguration is identified on the customer's public cloud, and Update Date as the most recent occurrence or the latest ZPC admin action on the alert. [zpc.release-notes:time-definitions-2023-03] The March 01, 2023 note says Alert Age is the number of days since the last time the Alert Status was set to Open; the March 23, 2023 note says an Alert Age filter filters by exact age, older than or newer than an age, in days. [zpc.release-notes:alert-age-2023] The October 13, 2022 note lists Time Range filter options including Last 12 hours and Custom Range. [zpc.release-notes:time-range-2022-10] The October 13, 2022 note says ZPC added Resource Group and Tags filters for Microsoft Azure compliance benchmarks. [zpc.release-notes:azure-compliance-filters-2022-10] The October 13, 2022 note says ZPC offers filter management: you can save a filter, and edit and delete a saved filter. [zpc.release-notes:filter-management-2022-10]The July 12, 2023 note says default filters are retained across revisits to the page and logout/login of the ZPC Admin Portal. [zpc.release-notes:default-filters-2023-07] Dated 2023 notes say alert payloads sent to integrations gained attributes: to cloud storage services AWS S3, Azure Blob and AWS Security Lake, Audit Procedure and Remediation (May 17, 2023); to Amazon S3, Azure Blob Storage, Splunk or AWS Security Lake, Audit Procedure, Remediation and Resource Metadata (July 12, 2023); to ITSM (Jira and ServiceNow), the same three (September 13, 2023). [zpc.release-notes:alert-payload-2023] The July 12, 2023 note says Slack integration is available for receiving ZPC alert notifications on Slack channels. [zpc.release-notes:slack-2023-07] The October 13, 2022 note says Cloud or IaC alert data can be exported to an Excel file. [zpc.release-notes:export-2022-10] The August 17, 2023 note says four remediation attributes and filters were added to the Cloud Alerts table: Supports Remediation, Remediation Allowed, Remediation Status and Remediation Initiated By. [zpc.release-notes:remediation-attrs-2023-08]

**Clouds and Kubernetes notes.** The December 08, 2022 note says ZPC supports onboarding AWS EKS clusters and gaining posture insight via the asset inventory. [zpc.release-notes:eks-2022-12] The January 19, 2023 note says ZPC supports onboarding GCP GKE clusters, and EKS and GKE clusters for multiple accounts in an organization; the March 23, 2023 note says Azure AKS clusters can be onboarded. [zpc.release-notes:gke-aks-2023] The June 19, 2023 note says ZPC supports onboarding AKS clusters with local authentication, in addition to Azure RBAC and Kubernetes RBAC; the August 17, 2023 note says private GKE clusters can be onboarded. [zpc.release-notes:aks-local-private-gke-2023] The April 19, 2023 note lists Kubernetes enhancements: metadata and posture for K8S IAM entities (roles, role bindings, service accounts), Kubelet configuration metadata, closing alerts for offboarded clusters, and a Warning status when metadata cannot be collected for certain services. [zpc.release-notes:k8s-enhancements-2023-04] The June 19, 2023 note lists OCI support under Feature in Limited Availability: onboarding OCI cloud accounts and visibility of OCI posture in the Cloud Asset Inventory. [zpc.release-notes:oci-limited-2023-06] The April 19, 2023 note says EC2 instances connected to a subnet with a default subnet-ACL and a public ID were not detected as publicly exposed, and that this is now corrected and as a result a higher number of publicly exposed instances may be observed. [zpc.release-notes:ec2-exposure-fix-2023-04] The October 13, 2022 note says ZPC supports GCP Functions as an identity in the IAM module when calculating an entitlement path. [zpc.release-notes:gcp-functions-2022-10] The April 19, 2023 note says the Cloud Accounts page shows onboarding and configuration metadata collection status; the January 19, 2023 note says ZPC monitors the state of every account, organization and Kubernetes cluster. [zpc.release-notes:onboarding-status-2023] The June 19, 2023 note gives cloud account Excel export file names as Cloudaccounts_<timestamp>, Cloudaccounts_organizations_<timestamp> and Cloudaccount_kubernetes_<timestamp>, and adds an Onboarded Date column. [zpc.release-notes:cloud-accounts-2023-06] The May 17, 2023 note says publicly exposed assets get a visual indication in the Assets drawer and Assets table and a filter. [zpc.release-notes:public-exposure-2023-05]

**Policies and investigation notes.** The October 13, 2022 note lists new predicates for custom security policies and investigations including CVE Security (Critical, High, Medium, Low or Unknown), CVE Age (days since first published) and Vulnerability Fix Available (True or False, based on NVD). [zpc.release-notes:cve-predicates-2022-10] The August 17, 2023 note says the asset property predicate investigates AWS assets by any key-value pair in asset metadata, with array, multiple and partial value matching; the October 30, 2023 note adds Included In and Not Included In operators for IP address and integer property types. [zpc.release-notes:asset-property-2023] The July 12, 2023 note says investigations and custom policy queries support all cloud-provider-supported tags; the September 13, 2023 note says AWS local identities are supported in investigation and custom policy queries. [zpc.release-notes:tags-local-identities-2023] The May 17, 2023 note says container workload investigation uses Kubernetes asset properties and images used by AWS EKS workloads; the June 19, 2023 note says running containers (as opposed to idle or stale ones) and publicly exposed containers can be identified, and results exported as an Excel file. [zpc.release-notes:container-investigation-2023] The September 06, 2022 note says custom policies can be edited and deleted: editing the query closes existing alerts and generates new ones, and deleting a custom policy closes all its alerts. [zpc.release-notes:custom-policy-edit-2022-09] The March 01, 2023 note says a disabled security policy is not run against collected configuration metadata; the January 19, 2023 note adds a Focus column showing whether a policy is asset focused or identity focused. [zpc.release-notes:policy-catalog-2023] The January 19, 2023 note says Asset Risk Level is Low, Medium, High or Critical, based on the number and type of open alerts on the asset. [zpc.release-notes:asset-risk-level-2023-01]

**Admin, API and reports notes.** The December 08, 2022 note says ZPC supports audit logs recording session information for every administrator who signs in to the ZPC Admin Portal, as a chronological list of activities in tenants onboarded to ZPC. [zpc.release-notes:audit-logs-2022-12] The January 19, 2023 note says audit logs integrate with the vulnerability management and KSPM onboarding modules. [zpc.release-notes:audit-logs-modules-2023-01] The October 13, 2022 note says custom roles can be added, edited or deleted, with permissions set for access to specific modules in the ZPC Admin Portal. [zpc.release-notes:custom-roles-2022-10] The July 31, 2023 note says administrators can be part of multiple groups including SSO groups, roles and business units are defined separately, and business units are mapped to groups. [zpc.release-notes:rbac-2023-07] The June 19, 2023 note says ZPC supports REST APIs for code-based alert retrieval, requiring an API key created and managed in the ZPC Admin Portal. [zpc.release-notes:api-2023-06] The July 12, 2023 note says internal server errors return a correlation ID in an optional response header and the response body. [zpc.release-notes:api-correlation-2023-07] The July 12, 2023 note says the Administrators page displays each administrator's last login time to the ZPC Admin Portal. [zpc.release-notes:last-login-2023-07] The May 17, 2023 note says that at that time ZPC displayed system notifications for cloud account onboarding and data collection failures. [zpc.release-notes:system-notifications-2023-05] The August 17, 2023 note says Executive Reports can be customized and shared in PDF format; the September 13, 2023 note says they can be scheduled for regular distribution to specified recipients at a specified frequency. [zpc.release-notes:executive-reports-2023] The March 01, 2023 note says a ZPC proprietary ML algorithm determines cloud identity types as human or non-human with more precision; the September 13, 2023 note says ZPC aligns with each cloud provider's classification of identities as human and non-human. [zpc.release-notes:identity-types-2023] The July 12, 2023 note says the Cloud Identities page offers complete metadata, power score, authentication methods and open alert count. [zpc.release-notes:cloud-identities-2023-07]
