# ZPA machine groups (zpa.machine-groups)
Also called: machine group; machine groups; MACHINE_GRP; zpa_machine_group; machine tunnel group

"What is a ZPA machine group, how does a device get into one, and what can I do with it?" takes four questions in order.

1. **What is a machine group, and what is in it?** What the group holds and how machines enrol into it: [What a ZPA machine group is and how machines join it](kb:zpa.machine-groups.definition).
2. **Can I create or change one through the API, the SDKs or Terraform?** [Machine groups through the ZPA API, SDKs and Terraform](kb:zpa.machine-groups.api-surface).
3. **How does a policy rule use a machine group?** The `MACHINE_GRP` operand and its pairing with the Machine Tunnel client type: [Using a machine group in a ZPA policy rule](kb:zpa.machine-groups.policy-use).
4. **How does a machine get the key that ties it to a group?** [Machine provisioning keys for ZPA machine tunnels](kb:zpa.machine-tunnels.provisioning-keys), with the tunnel itself in [ZPA machine tunnels](kb:zpa.machine-tunnels).
