# China Premium Service for Private Access: the partner-hosted Private Service Edge, data centers, traffic flows and prerequisites (zpa.private-service-edges.china-premium)
Also called: china premium service for private access; zpa china premium; private access in china; zpa use in china

Zscaler's China Premium Service for Private Access provides a way for users residing in mainland China to access private applications both inside and outside mainland China. It uses a Private Service Edge for Private Access hosted at a partner site within China, which uses a premium Chinese internet service provider (ISP) with access to both the domestic private applications in China and premium access to international private applications, and it allows traffic to be broken and inspected in China and the partner premium fabric to be used for any destination (domestic or international). [zpa.private-service-edges.china-premium:what-it-is] The page lists as key benefits reliable access with multiple ISPs, resulting in improved peering among ISPs in premium data centers (Beijing and Shanghai), multi-region dual premium data centers where traffic goes based on the user's proximity to the data centers, and data redundancy in the event that a premium data center is unreachable. [zpa.private-service-edges.china-premium:premium-data-centers] The Internet & SaaS service is in [China Premium and Premium Plus Internet Access: service model, provisioning, backup, licensing and DNS](kb:zia.traffic-forwarding.china-premium).

**Traffic flows.** For private applications outside China, the user does not connect to the public data center; the user connects to the closest Private Service Edge, based on the user's location (either the Beijing or Shanghai Premium data centers), creating a Z-Tunnel which forms the M-Tunnel, and the App Connector outside China connects through the premium circuit back to the Private Service Edge, creating a Z-Tunnel which forms the M-Tunnel. The page says the Great Firewall of China doesn't block it as it is a private application. [zpa.private-service-edges.china-premium:apps-outside-china] For private applications inside China, the App Connector in China connects to the Private Service Edge in China, creating a Z-Tunnel which forms the M-Tunnel; the page says the Great Firewall of China doesn't apply in this use case, as the traffic is inside China and never crosses the China borders. [zpa.private-service-edges.china-premium:apps-inside-china]

**Operation and prerequisites.** Zscaler is the single point of contact for Private Access China Premium services, and the bandwidth utilization for premium services can be viewed on Health360. [zpa.private-service-edges.china-premium:single-contact-and-health360] The prerequisites are that Private Access should be operational in China with private applications access provided to users there, that the Private Access bandwidth is appropriately sized in megabits per second (Mbps) for the configured private applications, and that the Zscaler Private Access Firewall Allowlist is consulted for the correct protocols, ports, domains and IP addresses. The feature is only available with a license, which allows Private Access users from China to be connected to a Private Service Edge with the Premium Circuit. [zpa.private-service-edges.china-premium:prerequisites-and-license] Licensing and bandwidth accounting for the Private Access service are open [gap:zpa.private-service-edges.china-premium:licensing-and-bandwidth].

What to check:
1. Whether the application is inside or outside China, since the connection flow differs: an in-China App Connector connects to the in-China Private Service Edge, while one outside China connects back through the premium circuit.
2. Whether the tenant has the license and an operational Private Access deployment in China, which the service requires.
