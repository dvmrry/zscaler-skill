# ZPA software components: Manager software, OAuth enrollment, network settings and STIG images (zpa.software-components)
Also called: software components; private access software components; zpa software component group

A question about App Connectors, Private Service Edges, Private Cloud Controllers or Network Connectors that is not specific to one of them splits by what the reader is trying to learn:

1. **What does the Manager do, and why did an update fail?** The Manager service, its child process, its upgrades and update troubleshooting: [The Manager software and its updates on ZPA software components](kb:zpa.software-components.manager).
2. **How does a component enroll with an OAuth token, and why did it not?** Token and provisioning key precedence, the network needs and the enrollment failure list: [OAuth 2.0 enrollment for ZPA software components and its troubleshooting](kb:zpa.software-components.oauth-enrollment).
3. **What network settings can a group have?** DNS, NTP, static routes, explicit proxy, TCP keepalive and split DNS zones: [Network settings for ZPA software component groups](kb:zpa.software-components.network-settings).
4. **What are the password rules and the 2024 expiry issue of STIG images?** [STIG-hardened ZPA images: password rules and the 2024 password-expiration issue](kb:zpa.software-components.stig-images).
5. **What are the ZPA appliance's models, ports and enrollment steps?** Hardware, power, port mapping, installation troubleshooting and enrollment: [The ZPA appliance: models, hardware and power, ports, installation troubleshooting and enrollment](kb:zpa.software-components.appliance).

Each component has its own subjects: [ZPA App Connectors](kb:zpa.app-connectors), [ZPA Private Service Edges](kb:zpa.private-service-edges), [Private Cloud Controllers and Private Clouds as the Business Continuity layer](kb:zpa.private-service-edges.private-cloud-controller) and [Network Connectors and Network Connector groups (VPN for Legacy Apps)](kb:zpa.vpn.network-connectors). The enrollment (CA) certificates they enroll with are in [ZPA certificates: enrollment (CA) certificates and web server certificates](kb:zpa.certificates).
