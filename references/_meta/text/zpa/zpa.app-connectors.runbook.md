# How the Private Access App Connector support troubleshooting runbook is organized and which pages cover each topic (zpa.app-connectors.runbook)
Also called: Private Access App Connector Support Troubleshooting Runbook; app connector support runbook

The App Connector support runbook's key topics are resolving enrollment failures, addressing upgrade challenges, troubleshooting Public Service Edge connectivity issues, and managing high CPU, memory and disk utilization concerns. [zpa.app-connectors.runbook:topics]

**Runbook pages.** Enrollment failures are in [What the App Connector runbook checks when enrollment fails: sizing, DNS, broker reachability, SSL interception, clock, provisioning key and VM moves](kb:zpa.app-connectors.runbook.enrollment), upgrade problems and rebuilds are in [What the App Connector runbook checks for upgrade problems: the healthy status block, clean restart, update servers, revert to default version and rebuild](kb:zpa.app-connectors.runbook.upgrades), Public Service Edge connectivity is in [How the App Connector runbook checks Public Service Edge connectivity: Diagnostics filter, MTR, TCP and TLS tests, packet capture TTL and control connection journal lines](kb:zpa.app-connectors.runbook.connectivity), and CPU, memory and disk checks are in [How the App Connector runbook checks high CPU, memory and disk utilization: process checks, thresholds, local memory endpoints and cleanup](kb:zpa.app-connectors.runbook.resources). The sizing, DNS and ping checks that precede the connectivity and high-utilization checks are in [What the App Connector runbook checks when enrollment fails: sizing, DNS, broker reachability, SSL interception, clock, provisioning key and VM moves](kb:zpa.app-connectors.runbook.enrollment).
