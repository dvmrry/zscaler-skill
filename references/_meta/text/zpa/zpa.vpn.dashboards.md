# VPN Service Edges, Network Connectors and BGP Peers dashboards (zpa.vpn.dashboards)
Also called: vpn dashboard; vpn service edges dashboard; network connectors dashboard; bgp peers dashboard; bgp session status

The VPN Service Edges, Network Connectors and BGP Peers dashboards each show data over a period from 1 hour to 14 days, or a custom range whose start and end dates must be within the last 14 days, and each displays by default information about events that occurred in the last hour. [zpa.vpn.dashboards:ranges] On the VPN Service Edges and Network Connectors dashboards, data is aggregated differently for different time period filters, so the same point in time in an Activity Monitor widget might show slightly different values depending on the selected time. [zpa.vpn.dashboards:aggregation] The App Connector, Private Service Edge and Private Cloud Controller dashboards are in [App Connector, Private Service Edge and Private Cloud Controller dashboards](kb:zpa.troubleshooting.component-dashboards).

**VPN Service Edges dashboard.** The VPN Service Edges dashboard displays interactive timeseries charts for the VPN Service Edge selected from the drop-down menu: the total number of Client Connectors currently connected with the bytes received from and sent to them, the total count of Network Connectors currently connected with the throughput received from and sent to them, and the total number of VPN Service Edges deployed in the organization with the bytes received and sent. [zpa.vpn.dashboards:vse-widgets]

**Network Connectors dashboard.** On the Network Connectors dashboard, the Top Network Connectors widgets need at least 4 widgets selected to display, with no more than 8 available to view at one time, and the Activity Monitor widgets need at least 4 selected, with no more than 6 available at one time. [zpa.vpn.dashboards:nc-widget-limits] Each Top Network Connectors widget displays up to the top 10 Network Connectors in the selected time frame: Minimum Available Disk Space (those with the least disk space available, not the average disk space used over the time frame), Peak CPU Utilization, Peak Memory Utilization, Peak TCP Port Utilization and Peak UDP Port Utilization (both for IPv4), Peak System File Descriptor Utilization, and Peak Network Connector Throughput (in percentage and bandwidth in bytes). [zpa.vpn.dashboards:nc-top-widgets] If no Network Connectors are selected, the top Network Connectors from the Minimum Available Disk Space widget are selected by default for the Activity Monitor widgets. The filters between Network Connectors and Network Connector groups use the OR operator, instead of AND, and at most 25 Network Connectors can be selected at one time. A widget can be searched by name, or by value, using >, < or = operators. [zpa.vpn.dashboards:nc-selection] Network Connectors dashboard widgets might show solid lines, which represent actual data for the time period, or dashed lines, which indicate the expected trajectory of the data but are not actual data. [zpa.vpn.dashboards:nc-lines] The Network Connector Details table gives each Network Connector's Location, the city and country that the Network Connector is connecting from. [zpa.vpn.dashboards:nc-details]

**BGP Peers dashboard.** The BGP Peers dashboard filters its table by VPN Service Edge, with the first option applied by default, and shows that VPN Service Edge's Local AS Number and its BGP service status: Active when the BGP service is running, Inactive when it is not running, and Failed when it failed or crashed. [zpa.vpn.dashboards:bgp-service] The BGP Peers table shows a Peer AS Number (the ASN assigned to the Network Connector), prefixes sent and received and the session uptime in seconds, and a BGP session status of Idle, Connect, Active, OpenSent, OpenConfirm or Established, where Established is the operational state of a successful BGP session in which routes are advertised and learned. [zpa.vpn.dashboards:bgp-sessions] The page's descriptions of the Connect and Active states are its own wording [gap:zpa.vpn.dashboards:bgp-state-wording].

BGP configuration is in [BGP for VPN Service Edges and Network Connectors: AS numbers, failure detection, external routers](kb:zpa.vpn.bgp), the components in [VPN Service Edges: what they are, statuses, client IP pools, update schedule, BGP configuration mode and China](kb:zpa.vpn.service-edges) and [Network Connectors and Network Connector groups (VPN for Legacy Apps)](kb:zpa.vpn.network-connectors), and the hub is [ZPA VPN (for Legacy Apps): what it is, its components and where each question goes](kb:zpa.vpn).

2. Whether a dashed line on the Network Connectors dashboard is being read as actual data.
3. Whether two time filters are being compared for the same point in time on the VPN Service Edges or Network Connectors dashboard.
