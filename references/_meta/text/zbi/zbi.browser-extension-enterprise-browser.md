# Browser Extension and Enterprise Browser for Zero Trust Browser: what each is, desktop and mobile (zbi.browser-extension-enterprise-browser)
Also called: Browser Extension for Zero Trust Browser; Enterprise Browser; Enterprise Browser for Mobile; ZTB browser detection and response; deployztbrowser

**Browser Extension.** Browser Extension for Zero Trust Browser is a lightweight solution that enhances existing browsers with browser detection and response (BDR) and data loss prevention (DLP) capabilities. [zbi.browser-extension-enterprise-browser:extension-purpose] Browser Extension supports Adaptive App Access (device posture enforcement), Browser-Based Threat Protection and Data Exfiltration Prevention (including screenshot protection and keystroke logger prevention). [zbi.browser-extension-enterprise-browser:extension-features] Device posture controls, screenshot protection and keystroke logger prevention require the lightweight agent to be installed along with the extension. [zbi.browser-extension-enterprise-browser:extension-agent-required]

**Enterprise Browser.** Enterprise Browser for Zero Trust Browser is a dedicated, hardened Chromium browser for SaaS applications and private web, RDP, SSH and VNC applications. [zbi.browser-extension-enterprise-browser:enterprise-browser-definition]

**Enterprise Browser for Mobile.** Enterprise Browser for Zero Trust Browser is available as a native mobile application for iOS, iPadOS and Android, on personal or corporate phones and tablets. [zbi.browser-extension-enterprise-browser:enterprise-browser-mobile-platforms] The mobile app applies URL, category and content policy to each page and lets users request time-boxed exceptions, governs copy and paste at the browser boundary, evaluates device posture before opening a protected application and restricts screen capture and recording inside the app. [zbi.browser-extension-enterprise-browser:enterprise-browser-mobile-capabilities] The mobile app inspects what users type into web forms with outcomes of allow, warn, block or mask, applies guardrails to generative AI prompts, uploads and clipboard transfers, restricts printing from sensitive applications and watermarks browser sessions. [zbi.browser-extension-enterprise-browser:enterprise-browser-mobile-input-output]

**Getting them.** Browser Extension and Enterprise Browser are obtained by contacting Zscaler Support, with deployment information in the Zero Trust Browser Documentation for Browser Extension; the Enterprise Browser for Mobile article directs readers to the Zscaler Account team to learn more. [zbi.browser-extension-enterprise-browser:availability-contact] Configuration, platform versions and licensing are open [gap:zbi.browser-extension-enterprise-browser:config-and-licensing].
