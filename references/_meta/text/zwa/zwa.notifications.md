# Workflow Automation notification templates (email, Slack, Teams): default families, status and edit rules, the digest flag and email builder settings (zwa.notifications)
Also called: notification templates; email notification template; slack notification template; teams notification template; digest notification template; template family; end-user justification template; escalation template

Notification templates set the format of the notifications Workflow Automation sends when an admin asks the end user to justify actions or escalates an incident to an approver, of the digest notifications to users and DLP admins, and of the notifications sent from workflows. [zwa.notifications:purpose] The merge tags and links available in the builders are in [Merge tags in Workflow Automation notification templates: tag group names, example digest tags, per-notification caps and the special links](kb:zwa.notifications.merge-tags), the surveys the notifications link to are in [Workflow Automation survey (questionnaire) templates: the mandatory Reason question, default families, toolbox question types and edit rules](kb:zwa.notifications.survey-templates), and which templates are used for which incident is in [Workflow Automation incident and digest template mappings: which notification and survey templates are used per source type, source action and notification type](kb:zwa.notifications.template-mappings).

**Default families.** The system default email notification template families are End-user Justification - Email Template, Escalation - Email Template, Digest - Email Template and DLP Admin Digest - Email Template, each with a default template of the same name. [zwa.notifications:default-email-families] The system default Slack notification template families are End-user Justification - Slack Template, Escalation - Slack Template, Digest - Slack Template and DLP Admin Digest - Slack Template, each with a default template of the same name, and are available only if Workflow Automation is integrated with Slack. [zwa.notifications:default-slack-families] The system default Microsoft Teams notification template families are End-user Justification - Teams Template, Escalation - Teams Template, Digest - Teams Template and DLP Admin Digest - Teams Template, each with a default template of the same name, and are available only if Workflow Automation is integrated with Microsoft Teams. [zwa.notifications:default-teams-families] Slack notification templates can only be added if Workflow Automation is integrated with Slack, and Microsoft Teams notification templates only if it is integrated with Microsoft Teams. [zwa.notifications:slack-teams-integration-required]

**The templates page.** The Notification Templates page lists each template's type (Email, Slack or Teams) and status (Draft, Published or System Default); Slack and Teams types are present only if Workflow Automation is integrated with Slack and Microsoft Teams respectively. [zwa.notifications:list-type-status] For each notification template family, only one template can be created in each language; two templates of the same language cannot be created for a single family. [zwa.notifications:one-per-language] The template family of a notification template cannot be edited after the template is added. [zwa.notifications:family-fixed]

**Editing and status.** Admins cannot edit the system default notification templates, only view and clone them; only draft and published templates can be edited, and system default templates cannot be deleted. [zwa.notifications:defaults-view-clone-only] Saving an edited draft template as a draft keeps it on the Notification Templates page with draft status, and updating an edited published template keeps its published status. [zwa.notifications:draft-and-published-edit] Workflow Automation only uses published templates for its notifications. [zwa.notifications:published-only] Which templates a mapping can select is stated two ways [divergence:zwa.notifications:mapping-template-status]. A cloned notification template's Template Name starts with "Clone of" followed by the name of the template that was cloned. [zwa.notifications:clone-name-prefix] Reset in the email template Translate window reverts the template to its original language and also reverts any changes made after translation. [zwa.notifications:translate-reset]

**Template settings.** The Digest option on a notification template marks it as a digest notification template (user digest or DLP admin digest) rather than a non-digest one (user notification or escalation); the Digest Type field then appears, with digest types End User and Admin. [zwa.notifications:digest-flag] An email notification template's Subject Line defaults to "DLP Incident Notification - ACTION REQUIRED", supports only English, and is limited to 100 characters; the Source Language defaults to English. [zwa.notifications:email-subject-line] The optional Time Zone field sets the time zone in which time-related merge tags appear in notifications that use the template; the Time merge tag is the time the incident occurred. [zwa.notifications:time-zone]

**Email builder.** The email template builder's Rich Text Editor provides the tools Columns, Button, Divider, Heading, Paragraph, Image, Menu, HTML and Table; the template design area starts as a single row with one column. [zwa.notifications:email-builder-tools] In the email template builder the Preheader Text follows the subject line in the notification email, and the HTML Title field sets the HTML title tag in the exported HTML. [zwa.notifications:email-preheader-title]

How a published template is chosen when a family has several languages is open [gap:zwa.notifications:language-selection], and so is whether Slack and Teams digests differ from email [gap:zwa.notifications:chat-digest-differences].

What to check:
1. Whether the template is Draft, Published or System Default before editing it, since only draft and published templates can be edited and only published ones are used.
2. Whether Workflow Automation is integrated with Slack or Microsoft Teams before looking for Slack or Teams templates.

Sources disagree (name both sides):
- The notification templates page says template mappings can only be updated with published templates, while the template mappings page says all template families that have been added are available for selection. [divergence:zwa.notifications:mapping-template-status]

  - zscaler-help: All email notification template families added on the Notification Templates page are available for selection.
  Impact: It is not stated whether a family that has only draft templates can be selected in a mapping.
