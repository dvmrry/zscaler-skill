# Workflow Automation for Data Protection: incidents, workflows, notifications, settings and the cloud DLP integrations (zwa.overview)
Also called: workflow automation; zwa; workflow automation for data protection

**Incidents and workflows.** Incidents and their details, filters, group mappings, notifications and integrations are in [Workflow Automation incidents: where they come from, who gets them, statuses, search limits and closing or deleting](kb:zwa.incidents), with the analytics dashboard in [Workflow Automation Incident Analytics dashboard: access by workflow permission, time ranges, KPI tiles, triage and resolve times, and top-10 views](kb:zwa.incident-analytics); workflows, the custom builder and mappings in [Workflow Automation workflows: the nine templates, custom workflows, mappings and what the API does not cover](kb:zwa.workflows); notification templates, merge tags and surveys in [Workflow Automation notification templates (email, Slack, Teams): default families, status and edit rules, the digest flag and email builder settings](kb:zwa.notifications).

**Administration.** Access, activity and alerts, API keys, email domains and user attributes are in [Workflow Automation account settings: notification expiry, digests and reminders, approver domains, user data source, obfuscation and quarantine release](kb:zwa.settings); audit logs in [Workflow Automation audit logs: the customer audit search, what it records, and how the SDKs read it](kb:zwa.audit-logs); the API in [The Workflow Automation API from a client's side: hosts, the Python and Go clients, and what neither SDK covers](kb:zwa.api).

**Cloud DLP integrations.** The DLP application integrations are in [The AWS DLP application integration for Workflow Automation: the two forwarding methods, the three AWS resources, regions, support role and validation](kb:zwa.aws-dlp-integration), [The Azure DLP application integration for Workflow Automation: the two forwarding methods, required outputs, fields, validation and privacy settings](kb:zwa.azure-dlp-integration) and [The GCP DLP application integration for Workflow Automation: Cloud-to-Cloud only, fields, validation and privacy settings](kb:zwa.gcp-dlp-integration).
