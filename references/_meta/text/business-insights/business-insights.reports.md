# Business Insights scheduled reports: workplace, application and Data Explorer reports, and the exclusion list (business-insights.reports)
Also called: scheduled reports; workplace reports; application reports; data explorer; exclusion list; inactivity period report

**Workplace reports.** Scheduled workplace reports are emailed to recipients as links, with a Time Period of Daily, Weekly or Monthly. [business-insights.reports:workplace-report-delivery] A workplace report's Frequency (data aggregation) can be Daily, Weekly, Monthly or Quarterly and must be less than or equal to the selected Time Period. [business-insights.reports:workplace-report-frequency] [gap:business-insights.reports:quarterly-frequency] Workplace report office selection has four options: All Offices (excluding remote users), Select Offices, All Offices and Remote Users, and Remote Users; users with zero office visits are categorized as remote users. [business-insights.reports:workplace-report-remote-users] The scheduling article says a workplace report organized by Office shows date, workplace and visits, and organized by User shows user, date, timespan and workplace. [business-insights.reports:workplace-report-organize-by] The release summary lists more columns [divergence:business-insights.reports:workplace-report-columns].

**Application reports.** Application reports schedule an application's activity or inactivity reports for regular distribution to specified recipients, and are described as a way to track application usage and act on unused user licenses. [business-insights.reports:app-reports-purpose] The Application Reports page (Analytics > Reports > Business Insights Reports > Application Reports) lists scheduled reports with Name, an autogenerated Summary and Next Run date, and offers search, the exclusion list, and enable or disable, edit, download and delete for each report. [business-insights.reports:app-reports-page] An application report is either an Inactivity Period or an Activity Period report, with a cadence of 1 day, 30 days, 60 days or 90 days. [business-insights.reports:application-report-types] Application reports are scheduled for Daily, Weekly, Monthly or Quarterly delivery; the scheduling article describes scheduling activity reports for applications and distribution to various email recipients and Workflow Automation. [business-insights.reports:application-report-delivery] When an application report includes a subset of users, up to 128 users and departments can be selected. [business-insights.reports:application-report-subset-limit] An application report can exclude users via the Exclusion List and/or a Custom list; changes to the exclusion list affect all reports using it, and Zscaler recommends the Custom option for report-specific exclusions. [business-insights.reports:application-report-exclusions] [gap:business-insights.reports:delivery-method]

**Exclusion list.** In the Application Reports Exclusion List, multiple exclusions can be added but only up to 8 can be enabled at any time; an exclusion is associated only with scheduled reports whose applications match the exclusion's applications. [business-insights.reports:exclusion-limit-and-match] In the Application Reports Exclusion List, disabling an exclusion disassociates it from all scheduled reports using the exclusion list; only enabled exclusions are associated, and reports are generated with the latest exclusion list after any disable, modify or enable. [business-insights.reports:exclusion-enable-disable] The Application Reports Exclusion List drawer shows, per exclusion, its users, departments, applications and the number of reports the exclusion is associated with. [business-insights.reports:exclusion-list-reports-column]

**Enabling and disabling.** The enable/disable article, reached from Workplace Reports or Application Reports, says disabling a scheduled report stops report generation and distribution to recipients and that enabling it resumes them. [business-insights.reports:enable-disable-report] The Data Explorer Reports page lists, per scheduled report, a Scheduled column that indicates whether the report is active or not. [business-insights.reports:data-explorer-scheduled-column] [gap:business-insights.reports:data-explorer-enable-disable]

**Data Explorer.** The About Data Explorer Reports article says Data Explorer reports can be organized by department, geolocation, user or workplace. [business-insights.reports:data-explorer-reports-page] A Data Explorer view can combine the metrics Bytes, Visits, Transactions, Occupancy and Attendance, grouped by Office or Work Mode, with filters for Geolocation and Work Mode. [business-insights.reports:data-explorer-metrics] The two articles name different dimensions [divergence:business-insights.reports:data-explorer-grouping]. In Data Explorer the Aggregation Type function (Sum, Maximum, Minimum, Average) is not available for daily aggregation. [business-insights.reports:data-explorer-aggregation] [gap:business-insights.reports:aggregation-options] A Data Explorer view processes data for the Last 7 days, Last Day, Last Week, Last Month, Week, Month or 3 Months. [business-insights.reports:data-explorer-time-periods] A Data Explorer view can be scheduled only when the time period is Last Day, Last Week or Last Month; the schedule delivers Daily or Weekly. [business-insights.reports:data-explorer-schedule] Data Explorer results can be exported as a CSV file (Export) or as a detailed report (Export Full Report). [business-insights.reports:data-explorer-export]

[gap:business-insights.reports:report-retention] The applications the reports cover are in [Business Insights Application Insights: discovered apps, overlap, cost savings, All Applications and application details](kb:business-insights.applications), the workplace metrics in [Business Insights Workplace Insights: discovered locations, map and chart views, workplace details, filters and occupancy and attendance formulas](kb:business-insights.workplace), and the product overview is in [Business Insights: SaaS usage and spend, workplace utilization, prerequisites and data sources](kb:business-insights.overview).

Sources disagree (name both sides):
- The workplace report scheduling article lists a short set of columns for the Office and User organizations, while the 2025 release summary says scheduled workplace reports gained many CSV columns and a User Aggregated Daily report type. [divergence:business-insights.reports:workplace-report-columns]
  - zscaler-help: The scheduling article describes Office reports as date, workplace and visits and User reports as user, date, timespan and workplace.
  - zscaler-help: Scheduled workplace reports gained new CSV columns depending on report type, with Office, User and User Aggregated Daily listed as report types.
  Impact: The column sets in the scheduling article are not the complete CSV contents, and the article does not describe the User Aggregated Daily type.
- The About Data Explorer Reports article says reports can be organized by department, geolocation, user or workplace, while the Data Explorer view configuration article groups by Office or Work Mode and filters on Geolocation and Work Mode. [divergence:business-insights.reports:data-explorer-grouping]
  - zscaler-help: Data Explorer reports can be organized by department, geolocation, user or workplace.
  - zscaler-help: A view groups data by Office or Work Mode and can be narrowed by Geolocation and Work Mode.
  Impact: Which dimensions a scheduled Data Explorer report can actually be organized or grouped by is not settled; the report article lists dimensions the view configuration does not offer.
