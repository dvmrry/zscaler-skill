# Business Insights Application Insights: discovered apps, overlap, cost savings, All Applications and application details (business-insights.applications)
Also called: application insights; applications insights; all applications; engagement index; growth trend; saas efficiency matrix; licensing insights

The Application Insights page is divided into three tabs: Discovered Apps, Overlapping Apps and Cost Savings; Discovered Apps lists the top 10 discovered applications. [business-insights.applications:application-insights-tabs]

**Discovered Apps.** The Discovered Apps tab of Application Insights charts, for the last 12 months, the number of high- and low-usage applications and newly discovered applications; high-usage apps have over 80% active users for the month compared to the total number of active users, and low-usage apps have less than 30%. [business-insights.applications:discovered-trend-thresholds] The Application Insights page defines Engagement Index as the percentage of active users in the last 30 days over the last 90 days for an app; the vendor's example of 50 active users in 30 days and 100 in 90 days gives 50%. [business-insights.applications:engagement-index] The Business Insights terminology article says the Engagement Index calculation varies with metadata availability: with plan details it is active users in the last 30 days over purchased seats, falling back to assigned seats if purchased seats are unavailable and to the no-plan calculation if both are unavailable; with multiple plans the service shows the plan with the lowest engagement index. [business-insights.applications:engagement-index-with-plan] Application Insights discovers app usage via the IdP, Internet & SaaS traffic, custom apps and direct connector configurations, so the same application tenant can appear in several entries with different Data Source values. [business-insights.applications:multiple-entries-per-tenant]

**Cost Savings.** Until costs are entered or edited, Application Insights shows Zscaler-estimated costs, which are underlined; the vendor describes them as conservative, based on enterprise premium plans with over 50% discounts, with greater discounts for larger deployment scale. [business-insights.applications:cost-estimates] The Cost Savings tab lists the Top 50 Cost Savings Applications; Potential Savings is the opportunity from removing inactive users, with an asterisk marking savings based on Zscaler-estimated costs. [business-insights.applications:cost-savings-table] The SaaS Efficiency Matrix places applications by license usage percentage and expense, and shows applications with greater savings opportunities in the bottom right of the graph. [business-insights.applications:efficiency-matrix] Onboarding an application from the Cost Savings table that has connector integration support offers two options: configure an application connector, or skip it and set up subscription details using insights from other data sources (IdP or ZIA). [business-insights.applications:cost-savings-connector-or-skip] Connecting an application is in [Onboarding a SaaS application to Business Insights: connector or plan information, and per-application prerequisites](kb:business-insights.onboarding).

**Overlapping Apps.** On the Overlapping Apps tab, Overlapping Users for a capability is the number of users using at least one of the applications listed for that capability. [business-insights.applications:overlap-users] The terminology article defines the overlap differently [divergence:business-insights.applications:overlap-users-definition]. The Application Overlap Details page compares overlap metrics for up to 4 apps at a time and charts the weekly active user trend for each application. [business-insights.applications:overlap-details-compare] The Application Comparison table on the Overlap Details page shows the top 5 departments by app usage, spend in US dollars, and Contract Date as the date the app subscription ends. [business-insights.applications:overlap-comparison-columns] [gap:business-insights.applications:contract-date-meaning]

**All Applications.** The All Applications page lists apps discovered from identity providers, Internet & SaaS traffic, connector integrations and custom application signatures; its data can be downloaded as a CSV file and shown 15, 50 or 100 rows per page. [business-insights.applications:all-applications-sources-and-export] On the All Applications page, ACV is the annual contract value of the application's subscription, and Top Departments lists departments with their active-user counts in ascending order for the last 30 days. [business-insights.applications:all-applications-columns] Growth Trend is the percentage increase or decrease in user activity for every 30 days, calculated as the change in active users divided by the active users before the last 30 days, times 100. [business-insights.applications:growth-trend] In the legacy Business Insights All Applications page, Risk Index is the risk index assigned to the application, and this setting for the app is configured in the ZIA Admin Portal. [business-insights.applications:risk-index-definition] [gap:business-insights.applications:risk-index]

**Application details.** The Application Details Data Source field names where usage was discovered: identity provider, Internet Access, connector integration or custom application signature, shown as IDP, ZIA, Connector or Custom ZIA. [business-insights.applications:data-source-values] The Status field on Application Details shows whether the application is onboarded to Business Insights and, for connector-integrated apps, whether the connector's API connection is valid or expired. [business-insights.applications:details-status] The Application Details Users table filters by the last 30, 60 or 90 days (last month, 2 months or 3 months for the ZIA table), defaults to Active Users, and can be searched by email address; the active vs. inactive graph can be filtered for the last 30 days or 12 months. [business-insights.applications:details-users-table] Which of three Users tables the Application Details page shows depends on the data source: Internet Access discovered or custom Internet Access apps, IDP discovered apps, or CONNECTOR apps. [business-insights.applications:details-users-table-by-source] [gap:business-insights.applications:users-table-columns] For Microsoft 365 the Application Details User field shows obfuscated data by default; usernames require enabling settings in the Microsoft 365 admin center. [business-insights.applications:details-m365-obfuscated] The Licensing Insights tab shows unused licenses, potential cost savings and assigned vs. active users; the page says the Assigned Seats information is only applicable for a connector-based datasource, and the data can be filtered for the last 30 days, month or 2 months. [business-insights.applications:licensing-insights]

Scheduled reports for applications are in [Business Insights scheduled reports: workplace, application and Data Explorer reports, and the exclusion list](kb:business-insights.reports); the product overview is in [Business Insights: SaaS usage and spend, workplace utilization, prerequisites and data sources](kb:business-insights.overview).

Sources disagree (name both sides):
- The Application Insights article counts Overlapping Users as users of at least one of the applications listed for a capability, while the terminology article defines Overlapping Apps as users using multiple apps with similar capabilities. [divergence:business-insights.applications:overlap-users-definition]
  - zscaler-help: Overlapping Users are users of at least one of the applications listed for the capability.
  - zscaler-help: Overlapping Apps are users using multiple apps with similar capabilities.
  Impact: Whether an overlapping user uses one or several of a capability's apps is not settled, so the Overlapping Users count may or may not require more than one app.
