# Cloud & Branch Connector locations and location templates: automatic creation, the default template and template settings (cloud-connector.overview.locations)
Also called: cloud connector location; location template; template prefix; cloud connector locations page

When Cloud Connector or Branch Connector is deployed, the Zscaler service automatically creates a location using a location template with defined attributes, and locations apply forwarding and security policies to workload traffic. [cloud-connector.overview.locations:auto-created] A location can be configured with settings such as Firewall Control, Acceptable Usage Policy (AUP), Caution, Authentication and XFF Forwarding, and can enforce Bandwidth Control with maximum bandwidth limits for download and upload. [cloud-connector.overview.locations:location-settings]

**Locations page.** The Locations page (Infrastructure > Location Management > Locations > Cloud tab) can sync locations and sublocations, lists all locations with the scope type if configured and the number of associated sublocations, and shows information about Edge locations. [cloud-connector.overview.locations:locations-page] What the Edge locations are and what Sync does is not described [gap:cloud-connector.overview.locations:edge-locations-sync].

**Location templates.** To have a location automatically created from a template, a location template must be selected when configuring a Cloud Provisioning Template or Branch Configuration Template. [cloud-connector.overview.locations:template-required] A default location template is automatically created for the organization; it can be viewed but not edited. [cloud-connector.overview.locations:default-template] A location template's Name is mandatory, and its optional Template Prefix is contained by all locations created using the template. [cloud-connector.overview.locations:template-name-prefix]

**Template settings.** A location template offers Enable XFF Forwarding (use of the X-Forwarded-For headers an on-premises proxy inserts in outbound HTTP requests), Enforce Authentication (require users from the location to authenticate), and Enable Caution (an end user notification for unauthenticated traffic; without it the action is treated as an allow policy), and Enable AUP (display an Acceptable Use Policy (AUP) for unauthenticated traffic and require users to accept it), which when enabled shows a Custom AUP Frequency (Days) field for how frequently the AUP is displayed to users, in days. [cloud-connector.overview.locations:template-options] IPS controls in a location template require a subscription to the advanced firewall SKU, and enabling one of the template's settings makes an Enable IPS Control setting appear. [cloud-connector.overview.locations:template-ips] A template's Enforce Bandwidth Control setting takes maximum bandwidth limits for Download (Mbps) and Upload (Mbps). [cloud-connector.overview.locations:template-bandwidth-mbps] The bandwidth unit on the wire is open; see gap bandwidth-unit in [Where the ZTC provider documentation is wrong or incomplete, and the location template checks it does not mention](kb:cloud-connector.terraform.doc-errata).
