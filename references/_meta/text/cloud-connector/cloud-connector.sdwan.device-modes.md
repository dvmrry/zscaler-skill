# Zero Trust SD-WAN devices: gateway and one-arm modes, zero touch provisioning (cloud-connector.sdwan.device-modes)
Also called: zero trust sd-wan device; branch connector gateway mode; one-arm mode branch connector; non-gateway mode; zero touch provisioning branch; branch configuration template staged ready to deploy; zsroot

Zero Trust SD-WAN Devices are hardware devices that use Zero Trust Branch Connectivity; the device is deployed as a Branch Connector virtual machine. [cloud-connector.sdwan.device-modes:hardware-runs-bc] A Zero Trust SD-WAN Device is deployed in one of two modes: gateway or non-gateway (one-arm). [cloud-connector.sdwan.device-modes:two-modes]

**Gateway mode.** In gateway mode the device gives access to the rest of the private network, cloud applications and the internet over one or more ISP connections; it can dynamically determine the best quality link, forward specific traffic toward it, and function as a local router so local devices communicate without an external router. It can also sit inside the LAN while an existing device connects to the internet. [cloud-connector.sdwan.device-modes:gateway-mode] Whether the device runs dynamic routing protocols in this mode is not stated [gap:cloud-connector.sdwan.device-modes:routing-protocols].

**One-arm mode.** In non-gateway (one-arm) mode the device does not connect directly to the ISP; it sits in the organization's internal network and requires an external router. [cloud-connector.sdwan.device-modes:one-arm-mode]

**Zero touch provisioning.** Devices receive their deployment configuration from Branch Configuration Templates staged in the Admin Console before the device is powered on; changing the template status from Staged to Ready to Deploy lets the ZTE adopt it, and once powered up with network connectivity the device connects to the Zscaler cloud, authenticates and is given its configuration. [cloud-connector.sdwan.device-modes:ztp] Deployment ties a Branch Configuration Template to the device's serial number; an LED shows provisioning progress (solid red initializing, blinking red pending, blinking green in progress, solid green all services running), and the template's status becomes Deployed when deployment completes. [cloud-connector.sdwan.device-modes:deploy-steps] The templates page names the statuses differently, a divergence recorded in [cloud-connector.sdwan.configuration-templates:template-status-values](kb:cloud-connector.sdwan.configuration-templates:template-status-values). A device deployed in gateway mode can have its configuration edited after deployment from the Branch Configuration Template page. [cloud-connector.sdwan.device-modes:gateway-edit]

**Device account.** Hardware Zero Trust SD-WAN devices also contain the zsroot service account, a privileged user; on these devices the password is changed by logging in through the console or management interface as zsroot and running passwd zsroot. [cloud-connector.sdwan.device-modes:zsroot] The account on virtual devices and Zscaler's rotation recommendation: [Cloud & Branch Connector virtual devices contain a Zscaler Service Account called zsroot, a privileged user for administrative access and management of the device, and Zscaler strongly recommends routine rotation of its password.](kb:cloud-connector.upgrades.zsroot-rotation:zsroot-account).

**Models.** The Branch Connector details help names the hardware models ZT400, ZT600 and ZT800 (the management interface is fixed by the model: GE1 for ZT400 and ZT600, GE3 for ZT800), and the API contract's `modelType` enumerates `ZT600`, `ZT800` and `ZT400` for a connector VM's hardware information. [cloud-connector.sdwan.device-modes:hardware-model-names] Mounting, console settings, cabling, port maps and reset per model are in [Installing ZT400, ZT600 and ZT800 devices: mounting, console, cabling, port maps and reset](kb:cloud-connector.sdwan.hardware-install), and the template that configures a device in [Branch Connector configuration templates: VM and hardware settings, HA, WAN uplinks, LAN, DHCP and static routes](kb:cloud-connector.sdwan.configuration-templates). The package lists 19-inch mounting brackets for all three models, and the mount manual gives rack and wall kits; throughput, rack-unit height and dimensions are not stated [gap:cloud-connector.sdwan.device-modes:device-models].

What to check:
1. Which mode the device was deployed in, since gateway mode is what WAN selection and the predefined forwarding rules require.
2. For a device stuck before operation, the configuration template's status and the device's LED state.
3. Whether the zsroot password has been rotated from its initial value.
