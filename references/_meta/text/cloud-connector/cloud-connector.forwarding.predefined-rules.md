# Predefined Cloud Connector traffic forwarding rules (cloud-connector.forwarding.predefined-rules)
Also called: default forwarding rule cloud connector; ZPA Pool For Stray Traffic; ZPA Forwarding Rule; Direct rule for Zscaler Cloud Endpoints; Direct rule for WAN Destinations Group; Direct rule for LAN Destinations Group; predefined forwarding rule gateway mode

**Internet & SaaS.** A default forwarding rule with a default gateway is predefined for Internet & SaaS: each tenant comes with a default rule that forwards internet-bound traffic to Internet & SaaS using automatically selected gateways. [cloud-connector.forwarding.predefined-rules:default-zia]

**Private Access.** A ZPA Forwarding Rule with a default gateway is created when the tenant subscribes to the Private Access license. [cloud-connector.forwarding.predefined-rules:zpa-rule] ZPA Pool For Stray Traffic is a rule with the Drop method, created automatically with view-only access when a ZPA server's SKU is enabled on the Cloud or Branch Connector. [cloud-connector.forwarding.predefined-rules:zpa-stray] What the stray-traffic rule is meant to catch is not stated [gap:cloud-connector.forwarding.predefined-rules:zpa-predefined-purpose].

**Direct rules for gateway-mode devices.** Three predefined Direct rules, disabled by default and shown according to the tenant's licenses, send to Direct traffic whose destination is the Zscaler Cloud Endpoints application service group, a WAN IP group, or a LAN IP group. [cloud-connector.forwarding.predefined-rules:direct-rules] These predefined rules apply only to hardware devices deployed in gateway mode; they can be enabled only once a location or Branch Connector group is configured for them, and only gateway-mode devices can join that mandatory group. [cloud-connector.forwarding.predefined-rules:gateway-mode-only] On predefined forwarding rules only Rule Order, Rule Status, Location/Sublocation and Cloud & Branch Connector Groups can be edited. [cloud-connector.forwarding.predefined-rules:editable-fields]

Same-named ZIA Forwarding Control rules are a different product's policy: [Predefined Forwarding Control rules](kb:zia.forwarding-control.predefined-rules). Whether the Terraform provider stops a predefined rule from being deleted is covered in [Whether the ZTC Terraform provider protects predefined traffic rules](kb:cloud-connector.terraform.rule-protection).

What to check:
1. Whether a predefined Direct rule is enabled at all (they ship disabled) and whether the device is in gateway mode.
2. For dropped Private Access traffic, whether it matched the view-only ZPA Pool For Stray Traffic rule.
