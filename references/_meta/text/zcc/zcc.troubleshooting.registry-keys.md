# Client Connector state in the Windows registry: ZNW_State, ZPA_State, ZWS_State and ZPA_AuthState values (zcc.troubleshooting.registry-keys)
Also called: ZNW_State; ZPA_State; ZWS_State; ZPA_AuthState; zcc registry keys; HKEY_CURRENT_USER Software Zscaler App

Client Connector records its network, service and Private Access authentication state in registry keys that can be read on the device. Client Connector's state values ZNW_State, ZPA_State, ZWS_State and ZPA_AuthState are registry keys under HKEY_CURRENT_USER\Software\Zscaler\App. The vendor's list is not exhaustive, and the registry entries are removed when the user logs out of Client Connector. [zcc.troubleshooting.registry-keys:location]

**Network state.** ZNW_State is the device's Client Connector network state: TRUSTED (a trusted network), NON_TRUSTED (an off-trusted network), TRUSTED_VPN (a trusted full-tunnel VPN) or TRUSTED_SPLIT_VPN (a split VPN-trusted network). [zcc.troubleshooting.registry-keys:znw-state]

**Service state.** ZPA_State is the Private Access service state and ZWS_State the Internet & SaaS service state. The table lists OFF, ON, CONNECTING, NONE_FORWARDING and TUNNEL_FORWARDING for both, and defines the last two alike (traffic intercepted by network drivers). LOCAL_PROXY_FORWARDING (traffic intercepted through a PAC file, the local proxy) and ENFORCE_PROXY_FORWARDING (a PAC file enforced on the system) are listed under ZWS_State only. [zcc.troubleshooting.registry-keys:service-state-values] Both service keys list DR_ON (Disaster Recovery, safe mode, is active and traffic follows the app profile settings), CAPTIVE_PORTAL_DETECTED, CAPTIVE_PORTAL_ERROR (a captive portal was detected and the open timeout expired) and SAFEMODE_FAILOPEN (interception stops temporarily to allow authentication). PRE_ENROLMENT_PROXY_ENFORCEMENT is listed under ZWS_State only: strict enforcement is blocking network access until the user logs in to Client Connector. [zcc.troubleshooting.registry-keys:failover-values]

**Error values.** SERVER_DOWN_ERROR (both keys) means the Public Service Edge for Private Access or Internet & SaaS cannot be reached; INTERNET_UNREACHABLE_ERROR (ZPA_State) that the network is connected but Private Access cannot resolve the broker name; ADAPTER_DOWN_ERROR (ZWS_State) that no adapter with a default route is found, which might occur during DHCP renewal. The vendor says to run the ipconfig /all command and verify the lease-obtained timestamp coincides with the exact moment the issue occurs. [zcc.troubleshooting.registry-keys:reachability-errors] DRIVER_ERROR (both keys) means a network driver (TAP, TUN or LWF) fails to load; FIREWALL_BLOCK_ERROR (both) that the outbound or inbound connection to itself fails; SYSTEM_SOCKETS_EXHAUSTED_ERROR (ZWS_State) that the system is at the maximum socket limit; SERVICE_DOWN_ERROR (ZPA_State) that a required microservice is not operational. [zcc.troubleshooting.registry-keys:local-errors] SERVER_AUTH_ERROR (both keys) means the Public Service Edge does not accept the authentication credentials; SERVER_AUTH_TERMINATED_AT_UNKNOWN (both) that the user domain does not match the service's authentication domain; ZPA_UNTRUSTED_SERVER_CERT_ERROR (ZPA_State, applicable only for Private Access) that the Private Access connection receives an SSL exception while connecting; ZIA_REGISTRATION_REQUIRED (ZWS_State) that the device is not registered with Internet & SaaS and the user must register to proceed. [zcc.troubleshooting.registry-keys:auth-errors]

**Private Access authentication.** ZPA_AuthState is the device's Private Access authentication status: AUTHENTICATED (a valid Private Access session; access proceeds per policy), AUTHENTICATION_REQUIRED (no valid session; the user must sign in or reauthenticate), REGISTRATION_REQUIRED (the device or user must complete registration or enrollment before authentication) or ZPN_DISABLED (Client Connector does not initiate Private Access). [zcc.troubleshooting.registry-keys:zpa-auth-state]

**What is not defined.** The keys are described for Windows only [gap:zcc.troubleshooting.registry-keys:windows-only]. How NONE_FORWARDING differs from TUNNEL_FORWARDING is undefined [gap:zcc.troubleshooting.registry-keys:none-vs-tunnel-forwarding]. Whether the values update live, and how ZNW_State maps onto the forwarding profile network types, is not stated [gap:zcc.troubleshooting.registry-keys:live-update-and-network-mapping].
