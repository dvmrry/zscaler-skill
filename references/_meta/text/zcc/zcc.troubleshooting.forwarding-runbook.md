# Client Connector forwarding runbook: the five errors and where each is worked (captive portal and driver error held here) (zcc.troubleshooting.forwarding-runbook)
Also called: Zscaler Client Connector Traffic Forwarding Support Troubleshooting Runbook; Common Zscaler Client Connector Errors and Troubleshooting Steps

**Scope.** The Client Connector forwarding runbook covers common Client Connector error scenarios, identifying the issue from application logs and the app, and suggested resolutions; it says to make sure to collect Client Connector logs. [zcc.troubleshooting.forwarding-runbook:scope] Connection Error and Server Down Error are in [Runbook: Connection Error and Server Down Error, getSmeProxyState values and Tunnel 2.0 logs](kb:zcc.troubleshooting.forwarding-runbook.connection-error), Endpoint FW/AV Error is in [Runbook: Endpoint FW/AV Error and FIREWALL_BLOCK_ERROR, 100.64.0.0/24 health checks and the Windows firewall rule](kb:zcc.troubleshooting.forwarding-runbook.endpoint-firewall), and Network Error is in [Runbook: Network Error (Network Connection Failed. -8.), its log strings and DNS checks](kb:zcc.troubleshooting.forwarding-runbook.network-error). The Service Status meanings are in [Error messages in Client Connector's Service Status field and the action for each](kb:zcc.troubleshooting.service-status-errors).

**Captive portal.** Client Connector bypasses traffic during captive portal detection but might transition into an error state if the user does not accept or agree to the captive terms within the timeout period. [zcc.troubleshooting.forwarding-runbook:captive-portal-behavior] Whether the timeout is the fail-open captive portal minutes in [Client Connector fail-open: captive portals, unreachable Service Edges and tunnel failures](kb:zcc.forwarding-profiles.fail-open) is open [gap:zcc.troubleshooting.forwarding-runbook:captive-portal-timeout]. Captive portal symptoms include browser errors such as The page cannot be displayed and the Internet Security window displaying Captive Portal Detected or Captive Portal Error. [zcc.troubleshooting.forwarding-runbook:captive-portal-symptoms] In Client Connector logs and packet captures the runbook says to look for HTTP requests to http://gateway.<cloud>.net:443/generate_204; if HTTP status 204 is not returned, it indicates captive portal detection. [zcc.troubleshooting.forwarding-runbook:captive-portal-generate-204] Listed causes of the captive portal error are the captive portal login page not being prompted and network components blocking access to required Zscaler URLs such as gateway.<cloudname>.net. [zcc.troubleshooting.forwarding-runbook:captive-portal-causes] Suggested captive portal fixes: confirm the login page opens in a browser, make sure DNS is not blocking gateway.<cloudname>.net and firewall or network security devices do not block captive portal detection traffic, allow gateway.<cloudname>.net and pac.<cloudname>.net through a third-party VPN, increase the captive portal timeout in Client Connector settings if login pages are slow, and run the latest version. [zcc.troubleshooting.forwarding-runbook:captive-portal-resolution]

**Driver error.** Driver Error appears in the Service Status section of the Internet Security or Private Access window and indicates that required network drivers, such as the Lightweight Filter (LWF) driver, are not installed or are malfunctioning. [zcc.troubleshooting.forwarding-runbook:driver-error-meaning] Driver Error symptoms include the ZSATray log messages ERR LWF: Unable to load driver!, ERR lwf: Initial driver check FAILED! and LightWeightFilter not loaded!, followed in the sample by ZApp moves to DRIVER ERROR!; setupapi.dev.log shows a failed driver package import with Error = 0x00000002. [zcc.troubleshooting.forwarding-runbook:driver-error-logs] The runbook lists these common causes of Driver Error: driver cache corruption in C:\Windows\System32\DriverStore, missing registry keys for the driver services, endpoint protection or tampering protection blocking driver installation, and Windows Driver Store corruption. [zcc.troubleshooting.forwarding-runbook:driver-error-causes] Suggested Driver Error fixes: More > Troubleshoot > Repair App, restart the device and validate; temporarily disable tools like Carbon Black or CrowdStrike and retry the driver installation process; uninstall and reinstall with forced driver re-installation using the CLI flag --reinstallDriver 1, for which the runbook points to the install options for EXE. [zcc.troubleshooting.forwarding-runbook:driver-error-resolution] The driver install side is in [Windows filter driver install parameters (LWF)](kb:zcc.install.windows-driver).
