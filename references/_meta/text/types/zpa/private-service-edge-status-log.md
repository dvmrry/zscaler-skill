# ZPA Private Service Edge Status Log (LSS zpn_sys_auth_log) (zpa/private-service-edge-status-log)
Also called: zpn_sys_auth_log; private service edge status log; pse status log
- LogTimestamp string: The timestamp when the log was generated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- Customer string: The customer name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- SessionID string: The TLS session ID (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- SessionType string: The type of session. The expected value for this field is ZPN_TUNNEL_CONTROL, which denotes the session from the Private Service Edge for Private Access towards the closest Public Service Edge for Private Access. (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- SessionStatus string: The status of the session. The expected values for this field are: ZPN_STATUS_AUTHENTICATED: The Private Service Edge successfully authenticated in Private Access ZPN_STATUS_AUTH_FAILED: The Private Service Edge failed to authenticate in Private Access ZPN_STATUS_DISCONNECTED: The Private Service Edge disconnected from a Service Edge for Private Access (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PackageVersion string: The Private Service Edge package version (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Platform string: The host platform (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ZEN string: The Public Service Edge that was selected for the connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ServiceEdge string: The Service Edge name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ServiceEdgeGroup string: The Service Edge group name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PrivateIP string: The private IP address of the Private Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Latitude number: The latitude coordinate of the Private Service Edge location (LSS formats: %[OPT]f %[OPT]o)
- Longitude number: The longitude coordinate of the Private Service Edge location (LSS formats: %[OPT]f %[OPT]o)
- CountryCode string: The country code (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- TimestampAuthentication string: The timestamp in microseconds when the Private Service Edge was authenticated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampUnAuthnetication string: The timestamp in microseconds when the Private Service Edge was unauthenticated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- CPUUtilization integer: The CPU utilization in % (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- MemUtilization integer: The memory utilization in % (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- InterfaceDefRoute string: The name of the interface to default route (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- DefRouteGW string: The IP address of the gateway to default route (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PrimaryDNSResolver string: The IP address of the primary DNS resolver (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- HostStartTime string: The time in seconds at which host was started (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ServiceEdgeStartTime string: The time in seconds at which the Private Service Edge was started (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- NumOfInterfaces integer: The number of interfaces on the Private Service Edge host (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- BytesRxInterface integer: The bytes received on the interface (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- PacketsRxInterface integer: The packets received on the interface (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ErrorsRxInterface integer: The errors received on the interface (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- DiscardsRxInterface integer: The discards received on the interface (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- BytesTxInterface integer: The bytes transmitted on the interface (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- PacketsTxInterface integer: The packets transmitted on the interface (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- DiscardsTxInterface integer: The discards transmitted on the interface (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ErrorsTxInterface integer: The errors transmitted on the interface (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TotalBytesRx integer: The total bytes received (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TotalBytesTx integer: The total bytes transmitted (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- MicroTenantID string: The Microtenant ID of the Private Service Edge (LSS formats: %[OPT]s %[OPT]j)
- Version string: Emitted by the default zpn_sys_auth_log template; the field table does not list it.
- PublicIP string: Emitted by the default zpn_sys_auth_log template; the field table does not list it.
- TimestampUnAuthentication string: Emitted by the default zpn_sys_auth_log template; the field table does not list it.
- HostUpTime string: Emitted by the default zpn_sys_auth_log template; the field table does not list it.
- Status codes: 3 listed for this log type in the LSS API's status-codes response; read one by its code (`read ZPN_STATUS_AUTH_FAILED`)

Each status code and policy reason has its own file under references/_meta/text/codes/ (`<code>.md`, `reason-<the reason>.md`): search that directory for the code or the reason's text.
