# ZPA Private Cloud Controller Metrics Log (LSS zpn_sitec_comprehensive_stats) (zpa/private-cloud-controller-metrics-log)
Also called: zpn_sitec_comprehensive_stats; private cloud controller metrics log
- LogTimestamp string: The timestamp when the log was generated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- PrivateCloudController string: The Private Cloud Controller name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- CPUUtilization string: The maximum CPU usage in the past 5 minutes (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- SystemMemoryUtilization string: The memory utilization of the entire VM (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ProcessMemoryUtilization string: The memory utilization of the Private Cloud Controller process (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedTCPPortsIPv4 string: The number of used TCP ports for an IPv4 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedUDPPortsIPv4 string: The number of used UDP ports for an IPv4 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedTCPPortsIPv6 string: The number of used TCP ports for an IPv6 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedUDPPortsIPv6 string: The number of used UDP ports for an IPv6 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AvailablePorts string: The number of usable ports (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- SystemMaximumFileDescriptors string: The number of total Private Cloud Controller system file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- SystemUsedFileDescriptors string: The number of used Private Cloud Controller system file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ProcessMaximumFileDescriptors string: The number of total Private Cloud Controller process file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ProcessUsedFileDescriptors string: The number of used Private Cloud Controller process file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AvailableDiskBytes string: The number of free bytes available for a Private Cloud Controller (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
