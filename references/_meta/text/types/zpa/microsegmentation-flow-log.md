# ZPA Microsegmentation Flow Log (LSS zms_flow_log) (zpa/microsegmentation-flow-log)
Also called: zms_flow_log; microsegmentation flow log; zms flow log
- LogTimestamp string: The timestamp when the log was generated (LSS formats: %[OPT]s %[OPT]j)
- Customer string: The customer name (LSS formats: %[OPT]s %[OPT]j)
- AgentID string: The Microsegmentation agent ID (192-bit string) (LSS formats: %[OPT]s %[OPT]j)
- AgentName string: The Microsegmentation agent name (LSS formats: %[OPT]s %[OPT]j)
- ResourceID string: The resource ID associated with the agent generating the flow log (192-bit string) (LSS formats: %[OPT]s %[OPT]j)
- ResourceName string: The resource name associated with the agent generating the flow log (LSS formats: %[OPT]s %[OPT]j)
- AppZoneID string: The AppZone identifier the agent generating the flow log belongs to (192-bit string) (LSS formats: %[OPT]s %[OPT]j)
- AppZoneName string: The AppZone name the agent generating the flow log belongs to or is a member of (LSS formats: %[OPT]s %[OPT]j)
- ConnectionStartTime string: The timestamp when the earliest of an aggregated set of connections was initiated (LSS formats: %[OPT]s %[OPT]j)
- SourceIP string: The source IP address used in the connection (LSS formats: %[OPT]s %[OPT]j)
- DestinationIP string: The destination IP address used in the connection (LSS formats: %[OPT]s %[OPT]j)
- SourcePorts array: The source port used in the connection. In the case of multiple connections between the same endpoints (i.e., same source, destination address, protocol, and destination port), this becomes an aggregated source port list. (LSS formats: %[OPT]d)
- DestinationPort integer: The destination port used in the connection (LSS formats: %[OPT]d)
- Protocol integer: The transport protocol used in the connection (LSS formats: %[OPT]d)
- AppName array: The application name (LSS formats: %[OPT]s %[OPT]j)
- AppExecutablePath array: The underlying operating system path of the application generating the connection (LSS formats: %[OPT]s %[OPT]j)
- Direction string: The connection direction. Allowed values: UNKNOWN INBOUND OUTBOUND (LSS formats: %[OPT]s %[OPT]j)
- PolicyID string: The policy ID (LSS formats: %[OPT]s %[OPT]j)
- PolicyName string: The policy name (LSS formats: %[OPT]s %[OPT]j)
- EnforcementReason string: The policy enforcement configured on the connection. Allowed values: POLICY_DISABLED RULE NO_POLICY_EXISTS FORCED (LSS formats: %[OPT]s %[OPT]j)
- EnforcementAction string: The policy enforcement action configured on the connection. Allowed values: ALLOW BLOCK SIMBLOCK (LSS formats: %[OPT]s %[OPT]j)
- EnforcementDisposition string: The policy enforcement decision on the connection. Allowed values: UNKNOWN CONNECTED REJECTED DROPPED (LSS formats: %[OPT]s %[OPT]j)
