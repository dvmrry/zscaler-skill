# ZPA Private Service Edge Metrics Log (LSS zpn_pbroker_comprehensive_stats) (zpa/private-service-edge-metrics-log)
Also called: zpn_pbroker_comprehensive_stats; private service edge metrics log; pse metrics log
- LogTimeStamp string: The timestamp when the log was generated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- PrivateSE string: The name of the Private Service Edge for Private Access (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- CPUUtilization string: The maximum CPU usage in the past 5 minutes (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- SystemMemoryUtilization string: The memory utilization of the entire virtual machine (VM) (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ProcessMemoryUtilization string: The memory utilization of the Private Service Edge process (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedTCPPortsIPv4 string: The number of used TCP ports for an IPv4 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedUDPPortsIPv4 string: The number of used UDP ports for an IPv4 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedTCPPortsIPv6 string: The number of used TCP ports for an IPv6 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedUDPPortsIPv6 string: The number of used UDP ports for an IPv6 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AvailablePorts string: The number of usable ports (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- SystemMaximumFileDescriptors string: The number of total Private Service Edge system file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- SystemUsedFileDescriptors string: The number of used Private Service Edge system file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ProcessMaximumFileDescriptors string: The number of total Private Service Edge process file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ProcessUsedFileDescriptors string: The number of used Private Service Edge process file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AvailableDiskBytes string: The number of free bytes available for the Private Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- MicroTenantID string: The Microtenant ID of the Private Service Edge (LSS formats: %[OPT]s %[OPT]j)
