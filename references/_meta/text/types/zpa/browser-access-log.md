# ZPA Browser Access Log (LSS zpn_http_trans_log) (zpa/browser-access-log)
Also called: zpn_http_trans_log; browser access log; zpa http log
- LogTimestamp string: The timestamp when the log was generated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- ConnectionID string: The application connection ID (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Exporter string: The Browser Access service instance to the Public Service Edge for Private Access or Private Service Edge for Private Access instance (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- TimestampRequestReceiveStart string: The timestamp in microseconds when the Browser Access service receives the first byte of the HTTP request from web browser (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampRequestReceiveHeaderFinish string: The timestamp in microseconds when the Browser Access service receives the last byte of the HTTP header corresponding to the request from web browser (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampRequestReceiveFinish string: The timestamp in microseconds when the Browser Access service receives the last byte of the HTTP request from web browser (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampRequestTransmitStart string: The timestamp in microseconds when the Browser Access service sends the first byte of the HTTP request to the web server (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampRequestTransmitFinish string: The timestamp in microseconds when the Browser Access service sends the last byte of the HTTP request to the web server (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampResponseReceiveStart string: The timestamp in microseconds when the Browser Access service receives the first byte of the HTTP response from the web server (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampResponseReceiveFinish string: The timestamp in microseconds when the Browser Access service receives the last byte of the HTTP response from the web server (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampResponseTransmitStart string: The timestamp in microseconds when the Browser Access service sends the first byte of the HTTP response to the web browser (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampResponseTransmitFinish string: The timestamp in microseconds when the Browser Access service sends the last byte of the HTTP response to the web browser (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TotalTimeRequestReceive integer: The time difference between reception of the first and last byte of the HTTP request from the web browser as seen by the Browser Access service (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TotalTimeRequestTransmit integer: The time difference between transmission of the first and last byte of the HTTP request towards the web server as seen by the Browser Access service (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TotalTimeResponseReceive integer: The time difference between reception of the first and last byte of the HTTP response from the web server as seen by the Browser Access service (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TotalTimeResponseTransmit integer: The time difference between transmission of the first and last byte of the HTTP response towards the web browser as seen by the Browser Access service (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TotalTimeConnectionSetup integer: The time difference between reception of the first byte of the HTTP request from web browser and transmission of the first byte towards the web server, as seen by the Browser Access service (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TotalTimeServerResponse integer: The time difference between transmission of the last byte of the HTTP request towards the web server and reception of the first byte of the HTTP response from web server, as seen by the Browser Access service (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- Method string: The HTTP request method (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Protocol string: The HTTP protocol (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Host string: The web application (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- URL string: The URL requested by the user (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- UserAgent string: The user agent string as specified in the HTTP host request header (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- XFF string: The X-Forwarded-For (XFF) HTTP header (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- NameID string: The NameID received by Private Access in the SAML assertion from the IdP (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- StatusCode integer: The HTTP status code (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- RequestSize integer: The size of the HTTP request (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ResponseSize integer: The size of the HTTP response (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ApplicationPort integer: The application port on the web server (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ClientPublicIp string: The public IP address of the user's device (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ClientPublicPort integer: The source port used by the user's device (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ClientPrivateIp string: The private IP address of the user's device (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Customer string: The name of the customer (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ConnectionStatus string: The status of the connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ConnectionReason string: The internal reason (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- CorsToken string: The token from the CORS request (LSS formats: %[OPT]s)
- Origin string: The Browser Access domain that led to the origination of the CORS request (LSS formats: %[OPT]s)
