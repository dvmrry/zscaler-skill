# ZPA AppProtection Log (LSS zpn_waf_http_exchanges_log) (zpa/appprotection-log)
Also called: zpn_waf_http_exchanges_log; appprotection log; inspection log; zpa waf log
- LogTimestamp string: The timestamp when the log was generated (LSS formats: %[OPT]s %[OPT]j)
- Customer string: The customer name (LSS formats: %[OPT]s %[OPT]j)
- ConnectionID string: The application connection ID (LSS formats: %[OPT]s %[OPT]j)
- UserID string: The user ID (LSS formats: %[OPT]s %[OPT]j)
- AssistantID string: The App Connector ID (LSS formats: %[OPT]s %[OPT]j)
- ExchangeSequenceIndex integer: The HTTP exchange sequence index within the TCP connection (LSS formats: %[OPT]d)
- TimestampRequestReceiveStart integer: The timestamp in microseconds when the received request was started (LSS formats: %[OPT]d)
- TimestampRequestReceiveHeaderFinish integer: The timestamp in microseconds when the received request header was finished (LSS formats: %[OPT]d)
- TimestampRequestReceiveFinish integer: The timestamp in microseconds when the received request was finished (LSS formats: %[OPT]d)
- TimestampRequestTransmitStart integer: The timestamp in microseconds when the transmitted request was started (LSS formats: %[OPT]d)
- TimestampRequestTransmitFinish integer: The timestamp in microseconds when the transmitted request was finished (LSS formats: %[OPT]d)
- TimestampResponseReceiveStart integer: The timestamp in microseconds when the received response was started (LSS formats: %[OPT]d)
- TimestampResponseReceiveFinish integer: The timestamp in microseconds when the received response was finished (LSS formats: %[OPT]d)
- TimestampResponseTransmitStart integer: The timestamp in microseconds when the transmitted response was started (LSS formats: %[OPT]d)
- TimestampResponseTransmitFinish integer: The timestamp in microseconds when the transmitted response was finished (LSS formats: %[OPT]d)
- TotalTimeRequestReceive integer: The total time taken in microseconds for the request to be received (LSS formats: %[OPT]d)
- TotalTimeRequestTransmit integer: The total time taken in microseconds for the request to be transmitted (LSS formats: %[OPT]d)
- TotalTimeResponseReceive integer: The total time taken in microseconds for the response to be received (LSS formats: %[OPT]d)
- TotalTimeResponseTransmit integer: The total time taken in microseconds for the response to be transmitted (LSS formats: %[OPT]d)
- Domain string: The domain or IP address (LSS formats: %[OPT]s %[OPT]j)
- Method string: The HTTP request method (LSS formats: %[OPT]s %[OPT]j)
- Protocol string: The protocol (i.e., 1.0 or 1.1) (LSS formats: %[OPT]s %[OPT]j)
- ProtocolVersion string: The protocol version (LSS formats: %[OPT]s %[OPT]j)
- ContentType string: The content type (LSS formats: %[OPT]s %[OPT]j)
- ContentEncoding string: The value of the content encoding within the HTTP header (LSS formats: %[OPT]s %[OPT]j)
- TransferEncoding string: The value of the transfer encoding within the HTTP header (LSS formats: %[OPT]s %[OPT]j)
- Host string: The host domain or IP address (LSS formats: %[OPT]s %[OPT]j)
- OriginDomain string: The value of the origin header in the cross-origin HTTP header (LSS formats: %[OPT]s %[OPT]j)
- URL string: The URL field within the HTTP header (LSS formats: %[OPT]s %[OPT]j)
- UserAgent string: The user agent string as specified in the HTTP host request header (LSS formats: %[OPT]s %[OPT]j)
- HTTPError string: The HTTP error (LSS formats: %[OPT]s %[OPT]j)
- ClientPublicIp string: The public IP of the client (LSS formats: %[OPT]s %[OPT]j)
- ClientPort integer: The port of the client (LSS formats: %[OPT]d)
- UpgradeHeaderPresent integer: If the upgrade header is present or not (LSS formats: %[OPT]d)
- StatusCode integer: HTTP status code of the response (LSS formats: %[OPT]d)
- RequestHdrSize integer: The size of the request header (LSS formats: %[OPT]d)
- ResponseHdrSize integer: The size of the response header (LSS formats: %[OPT]d)
- RequestBodySize integer: The size of the request body (LSS formats: %[OPT]d)
- ResponseBodySize integer: The size of the response body (LSS formats: %[OPT]d)
- Application integer: The application name (LSS formats: %[OPT]d)
- ApplicationGroup integer: The application group name (LSS formats: %[OPT]d)
- InspectionPolicy integer: The AppProtection policy (LSS formats: %[OPT]d)
- InspectionProfile integer: The AppProtection profile (LSS formats: %[OPT]d)
- ParanoiaLevel integer: The OWASP Predefined Paranoia Level (LSS formats: %[OPT]d)
- InspectionControlsHitCount integer: The number of AppProtection control hits (LSS formats: %[OPT]d)
- InspectionRuleProcessingTime integer: The time in microseconds taken for processing the AppProtection rule (LSS formats: %[OPT]d)
- InspectionReqHeadersProcessingTime integer: The time in microseconds taken for processing the AppProtection request headers (LSS formats: %[OPT]d)
- InspectionReqBodyProcessingTime integer: The time in microseconds taken for processing the AppProtection request body (LSS formats: %[OPT]d)
- InspectionRespHeadersProcessingTime integer: The time in microseconds taken for processing the AppProtection response headers (LSS formats: %[OPT]d)
- InspectionRespBodyProcessingTime integer: The time in microseconds taken for processing the AppProtection response body (LSS formats: %[OPT]d)
- CertificateId integer: The certificate ID (LSS formats: %[OPT]d)
- DoubleEncryption integer: The double encryption status. The expected values for this field are: On Off (LSS formats: %[OPT]d)
- SSLInspection integer: If the HTTPS traffic inspected was terminated (LSS formats: %[OPT]d)
- TotalBytesProcessed integer: The total bytes processed (LSS formats: %[OPT]d)
- Destination string: Emitted by the default zpn_waf_http_exchanges_log template; the field table does not list it.
- InspectionControls array: Emitted by the default zpn_waf_http_exchanges_log template; the field table does not list it.
- InspectionControlTypes array: Emitted by the default zpn_waf_http_exchanges_log template; the field table does not list it.
- InspectionControlCategories array: Emitted by the default zpn_waf_http_exchanges_log template; the field table does not list it.
- Actions array: Emitted by the default zpn_waf_http_exchanges_log template; the field table does not list it.
- Severities array: Emitted by the default zpn_waf_http_exchanges_log template; the field table does not list it.
- Descriptions array: Emitted by the default zpn_waf_http_exchanges_log template; the field table does not list it.
