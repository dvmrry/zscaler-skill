# ZPA User Status Log (LSS zpn_auth_log) (zpa/user-status-log)
Also called: zpn_auth_log; user status log; zpa auth log
- LogTimestamp string: The timestamp when the log was generated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- Customer string: The customer name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Username string: The user name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- SessionID string: The TLS session ID (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- SessionStatus string: The status of the session. The expected values for this field are: ZPN_STATUS_AUTHENTICATED: The user successfully authenticated in Private Access ZPN_STATUS_AUTH_FAILED: The user failed to authenticate in Private Access ZPN_STATUS_DISCONNECTED: The user connected from a Public Service Edge for Private Access or a Private Service Edge for Private Access (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Version string: The Zscaler Client Connector version. When a connection is established through a Private Service Edge, the system sends an additional log with the version field updated to the Private Service Edge version. (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ZEN string: The Public Service Edge that was selected for the connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- CertificateCN string: The certificate common name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PrivateIP string: The private IP address of Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PublicIP string: The public IP address of Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Latitude number: The latitude coordinate of the Zscaler Client Connector location (LSS formats: %[OPT]f %[OPT]o)
- Longitude number: The longitude coordinate of the Zscaler Client Connector location (LSS formats: %[OPT]f %[OPT]o)
- CountryCode string: The country code of the Zscaler Client Connector location (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- TimestampAuthentication string: Timestamp in microseconds when Zscaler Client Connector was authenticated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampUnAuthentication string: Timestamp in microseconds when Zscaler Client Connector was unauthenticated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TotalBytesRx integer: The total bytes received (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TotalBytesTx integer: The total bytes transmitted (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- Idp string: The name of the identity provider (IdP) as configured in the Zscaler Admin Console (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Hostname string: The name of the device as reported by Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Platform string: The platform on the device as reported by Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ClientType string: The client type for the request (i.e., Zscaler Client Connector, ZPA LSS, or Web Browser) (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- TrustedNetworks array: The unique IDs for the trusted networks that Zscaler Client Connector has determined for this device (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- TrustedNetworksNames array: The names for the trusted networks that Zscaler Client Connector has determined for this device (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- SAMLAttributes string: The list of SAML attributes reported by the IdP (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- PosturesHit array: The posture profiles that Zscaler Client Connector verified for this device (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PosturesMiss array: The posture profiles that Zscaler Client Connector failed to verify for this device (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ZENLatitude number: The latitude coordinates for the Public Service Edge (LSS formats: %[OPT]f %[OPT]o)
- ZENLongitude number: The longitude coordinates for the Public Service Edge (LSS formats: %[OPT]f %[OPT]o)
- ZENCountryCode string: The country code for the Public Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- FQDNRegistered string: The status of the hostname for the client-to-client connection. The expected values for this field are true or false. (LSS formats: %[OPT]s)
- FQDNRegisteredError string: The status of the registered hostname. The expected value if the hostname matches the regular expression is FQDN_MATCH. The expected values if the hostname does not match the regular expression are: FQDN_NO_MATCH: The hostname does not match with the configured regular expression FQDN_BAD_SCHEMA: Client-to-client communication is disabled for the Public Service Edge FQDN_BAD_REGEX: The configured regular expression in the Zscaler Admin Console is incorrect FQDN_TOO_MANY_REGEX: Invalid regular expression configuration due to multiple configured regular expressions FQDN_NO_ENTRIES: Your admin has not configured a regular expression in the Zscaler Admin Console FQDN_EMPTY: The FQDN received from the Zscaler Client Connector is null or empty BROKER_NOT_ENABLED: Client-to-client communication is disabled for the Public Service Edge CUSTOMER_NOT_ENABLED: Client-to-client communication is disabled for the current customer (LSS formats: %[OPT]s)
- City string: The city of the client (LSS formats: %[OPT]s %[OPT]j)
- MicroTenantID string: The Microtenant ID of the user accessing the application (LSS formats: %[OPT]s %[OPT]j)
- Status codes: 3 listed for this log type in the LSS API's status-codes response; read one by its code (`read ZPN_STATUS_AUTH_FAILED`)

Each status code and policy reason has its own file under references/_meta/text/codes/ (`<code>.md`, `reason-<the reason>.md`): search that directory for the code or the reason's text.
