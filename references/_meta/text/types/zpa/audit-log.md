# ZPA Audit Log (LSS zpn_audit_log) (zpa/audit-log)
Also called: zpn_audit_log; zpa audit log; admin audit log
- modifiedTime string: The time when an object is created, deleted, or updated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- creationTime string: The time when the log was generated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- modifiedBy integer: The user ID for the admin that made the change (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- requestID string: The ID for the associated configuration change, as related to the action that was made (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- auditOldValue string: The previous value that was changed if the action type is delete, sign out, or update. If the modified object is policy related, the value depends on the policy type. Then the expected values for this field are: Allow: the policy type is access policy Intercept: the policy type is client forwarding policy Re_Auth: the policy type is timeout policy (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- auditNewValue string: The new value that was changed if the action type is create, sign in, or update. If the modified object is policy related, the value depends on the policy type. Then the expected values for this field are: Allow: the policy type is access policy Intercept: the policy type is client forwarding policy Re_Auth: the policy type is timeout policy (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- auditOperationType string: The action performed. The expected values for this field: Create Client Session Revoked Delete Download Sign In Sign In Failure Sign Out Update (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- objectType string: The location within the Zscaler Admin Console where the Action was performed. This corresponds to the Resource Type on the Audit Log page. To learn more, see About Audit Logs. View the expected values for this field. - objectName string: The name of the object. This corresponds to the Resource Name on the Audit Log page. To learn more, see About Audit Logs. (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- objectID integer: The ID associated with the object name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- customerID integer: The Private Access tenant ID of the customer. To learn more, see Configuring the Company Profile. (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- modifiedByUser string: The username of the admin associated with the audit action (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- clientAuditUpdate integer: Indicates whether the logs are associated with admin or client credentials. The expected values for this field are 0 and 1. (LSS formats: %[OPT]d)
- SessionID string: Emitted by the default zpn_audit_log template; the field table does not list it.
