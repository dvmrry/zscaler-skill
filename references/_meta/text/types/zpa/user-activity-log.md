# ZPA User Activity Log (LSS zpn_trans_log) (zpa/user-activity-log)
Also called: zpn_trans_log; user activity log; zpa access log; lss user activity
- AppGroup string: The application group name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- AppLearnTime string: The time in microseconds taken for App Connectors to learn about the requested application and report the learned information to the central authority (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- Application string: The application name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- AppMicroTenantID string: The Microtenant ID of the application (LSS formats: %[OPT]s %[OPT]j)
- CAProcessingTime string: The time in microseconds taken for processing in the central authority (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- ClientCountryCode string: The country code of the Zscaler Client Connector location (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ClientLatitude number: The latitude coordinate of the Zscaler Client Connector location (LSS formats: %[OPT]f %[OPT]o)
- ClientLongitude number: The longitude coordinate of the Zscaler Client Connector location (LSS formats: %[OPT]f %[OPT]o)
- ClientPrivateIP string: The private IP address of the Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ClientPublicIP string: The public IP address of the Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ClientCity string: The city of the client (LSS formats: %[OPT]s %[OPT]j)
- ClientToClient string: The status of the client-to-client connection (LSS formats: %[OPT]s)
- ClientZEN string: The Public Service Edge for Private Access that received the request from the Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ConnectionID string: The application connection ID (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ConnectionSetupTime string: The time taken by the App Connector to process a notification from the App Connector selection microservice and set up the connection to the application server (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- ConnectionStatus string: The status of the connection. The expected values for this field are: Open Close Active (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Connector string: The App Connector name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ConnectorIP string: The source IP address of the App Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ConnectorPort integer: The source port of the App Connector (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ConnectorZEN string: The Public Service Edge that sent the request from the App Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ConnectorZENSetupTime string: The time in microseconds taken for setting up the connection between the App Connector and Public Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- Customer string: The customer name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- DoubleEncryption integer: The double encryption status. The expected values for this field are: On Off (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Host string: The destination host domain or IP address (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Hostname string: The name of the device as reported by Zscaler Client Connector. This field only provides valid values for Zscaler Client Connector and machine tunnel client types. (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Idp string: The name of the identity provider (IdP) as configured in the Zscaler Admin Console (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- InternalReason string: The internal reason for the status of the transaction (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- IPProtocol integer: The IP protocol number (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- LogTimestamp string: The timestamp when the log was generated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- MicroTenantID string: The Microtenant ID of the user accessing the application (LSS formats: %[OPT]s %[OPT]j)
- Platform string: The platform on the device as reported by Zscaler Client Connector (e.g., Windows) (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Policy string: The access policy rule name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PolicyProcessingTime integer: The time in microseconds taken for processing the access policy associated with the application (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- PRAApprovalID integer: The privileged approval ID (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- PRAConsolesPolicyID number: The consoles policy ID (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- PRAConnectionID string: The Privileged Remote Access (PRA) connection ID (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PRAConsoleType string: The privileged console type. The expected values for this field are: RDP SSH VNC (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PRACredentialLoginType string: The login type of the privileged credential. The expected values for this field are: Username/Password SSH Key Password (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PRACredentialPolicyID integer: The privileged credential policy ID (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- PRACredentialUserName string: The name of the user that is logged in to the target privileged console (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PRAErrorStatus string: The PRA session error status, if available (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PRAFileTransferList string: The files transferred during the PRA session (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PRARecordingStatus string: The recording status of the PRA file transfer. The expected values for this field are: Available Not Available Started (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PRASessionType string: The PRA session type. The expected value is PRA. (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PRASharedMode string: The PRA shared mode. The expected values for this field are: Monitor Control (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- PRASharedUserList string: The users that the PRA session was shared with (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- Server string: The server ID name. The server ID must be set to zero if Dynamic Server Discovery is enabled. (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ServerIP string: The destination IP address of the server (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ServerPort integer: The destination port of the server (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ServerSetupTime integer: The time in microseconds taken to set up the connection at the server (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- ServicePort integer: The service port associated with the application request (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- SessionID string: The TLS session ID (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- TimestampConnectionStart string: The timestamp in microseconds when the Public Service Edge or Private Service Edge for Private Access received the initial request from Zscaler Client Connector to start the connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampConnectionEnd string: The timestamp in microseconds when the Public Service Edge or Private Service Edge terminated the connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampCATx string: The timestamp in microseconds when the central authority sent a request to the Public Service Edge or Private Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampCARx string: The timestamp in microseconds when the central authority received a request from the Public Service Edge or Private Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampAppLearnStart string: The timestamp in microseconds when Private Access services start the process to learn about an application (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampZENFirstRxClient string: The timestamp in microseconds when the Public Service Edge received the first byte from the Zscaler Client Connector (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TimestampZENFirstTxClient string: The timestamp in microseconds when the Public Service Edge sent the first byte to the Zscaler Client Connector (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TimestampZENLastRxClient string: The timestamp in microseconds when the Public Service Edge received the last byte from the Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampZENLastTxClient string: The timestamp in microseconds when the Public Service Edge sent the last byte to the Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampConnectorZENSetupComplete string: The timestamp in microseconds when the Public Service Edge received a request from the App Connector to set up a data connection. The request from the App Connector is triggered by the initial request for a specific application from Zscaler Client Connector. (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampZENFirstRxConnector string: The timestamp in microseconds when the Public Service Edge received the first byte from the App Connector (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TimestampZENFirstTxConnector string: The timestamp in microseconds when the Public Service Edge sent the first byte to the App Connector (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- TimestampZENLastRxConnector string: The timestamp in microseconds when the Public Service Edge received the last byte from the App Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- TimestampZENLastTxConnector string: The timestamp in microseconds when the Public Service Edge sent the last byte to the App Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- Username string: The username as entered into Zscaler Client Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- ZENBytesRxClient integer: The additional bytes received from Zscaler Client Connector since the last transaction log (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ZENBytesTxClient integer: The additional bytes transmitted to Zscaler Client Connector since the last transaction log (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ZENBytesRxConnector integer: The additional bytes received from the App Connector since the last transaction log (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ZENBytesTxConnector integer: The additional bytes transmitted by the App Connector since the last transaction log (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ZENTotalBytesRxClient integer: The total bytes received from Zscaler Client Connector by the Public Service Edge (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ZENTotalBytesTxClient integer: The total bytes transmitted to Zscaler Client Connector from the Public Service Edge (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ZENTotalBytesRxConnector integer: The total bytes received from the App Connector by the Public Service Edge (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- ZENTotalBytesTxConnector integer: The total bytes transmitted to the App Connector from the Public Service Edge (LSS formats: %[OPT]d %[OPT]x %[OPT]f %[OPT]o)
- PRACapabilityPolicyID integer: Emitted by the default zpn_trans_log template; the field table does not list it.
- PRASharedUsersList string: Emitted by the default zpn_trans_log template; the field table does not list it.
- Status codes: 201 listed for this log type in the LSS API's status-codes response and the session status codes help article; each has its own file, `references/_meta/text/codes/<code>.md`
