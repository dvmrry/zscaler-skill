# ZPA App Connector Metrics Log (LSS zpn_ast_comprehensive_stats) (zpa/app-connector-metrics-log)
Also called: zpn_ast_comprehensive_stats; app connector metrics log; connector metrics log
- LogTimestamp string: Timestamp when the log was generated (LSS formats: %[OPT]s %[OPT]j %[OPT]J)
- Connector string: The App Connector name (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]o)
- CPUUtilization string: The maximum CPU usage in the past 5 minutes (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- SystemMemoryUtilization string: The memory utilization of the entire VM (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ProcessMemoryUtilization string: The memory utilization of the App Connector process (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AppCount string: The number of applications configured for access via this App Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ServiceCount string: The number of services configured for access via this App Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- TargetCount string: The number of targets configured for access via this App Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AliveTargetCount string: The number of targets alive for access via this App Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ActiveConnectionsToPublicSE string: The number of active Microtunnel (M-Tunnel) connections to the Public Service Edge for Private Access (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- DisconnectedConnectionsToPublicSE string: The number of disconnected Microtunnel (M-Tunnel) connections to the Public Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ActiveConnectionsToPrivateSE string: The number of active Microtunnel (M-Tunnel) connections to the Private Service Edge for Private Access (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- DisconnectedConnectionsToPrivateSE string: The number of disconnected Microtunnel (M-Tunnel) connections to the Private Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- TransmittedBytesToPublicSE string: The number of bytes transmitted by the App Connector to the Public Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ReceivedBytesFromPublicSE string: The number of bytes received by the App Connector from the Public Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- TransmittedBytesToPrivateSE string: The number of bytes transmitted by the App Connector to the Private Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ReceivedBytesFromPrivateSE string: The number of bytes received by the App Connector from the Private Service Edge (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AppConnectionsCreated string: The number of created application Microtunnel (M-Tunnel) connections (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AppConnectionsCleared string: The number of cleared application Microtunnel (M-Tunnel) connections (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AppConnectionsActive string: The number of active application Microtunnel (M-Tunnel) connections (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedTCPPortsIPv4 string: The number of used TCP ports for an IPv4 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedUDPPortsIPv4 string: The number used UDP ports for an IPv4 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedTCPPortsIPv6 string: The number of used TCP ports for an IPv6 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- UsedUDPPortsIPv6 string: The number of used UDP ports for an IPv6 connection (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AvailablePorts string: The number of usable ports (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- SystemMaximumFileDescriptors string: The number of total App Connector system file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- SystemUsedFileDescriptors string: The number of used App Connector system file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ProcessMaximumFileDescriptors string: The number of total App Connector process file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- ProcessUsedFileDescriptors string: The number of used App Connector process file descriptors (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- AvailableDiskBytes string: The number of free bytes available for an App Connector (LSS formats: %[OPT]s %[OPT]j %[OPT]J %[OPT]d)
- MicroTenantID string: The Microtenant ID of the App Connector (LSS formats: %[OPT]s %[OPT]j)
