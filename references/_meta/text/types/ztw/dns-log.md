# Cloud & Branch Connector DNS log (NSS feed) (ztw/dns-log)
Also called: cloud connector dns log; branch connector dns log; cbc dns logs
- eventtime string: The time and date the transaction happened. This excludes the time zone. (example: Mon Oct 28 22:55:48 2024) [Date/Time]
- time string: The date and time the event was logged. (example: Mon Oct 28 22:55:53 2024) [Date/Time]
- tz string: The time zone. This is the same as the time zone you specified when you configured the NSS feed. (example: GMT) [Date/Time]
- ss integer: Second of timestamp (0–59) (example: 48) [Date/Time]
- mm integer: Minute of timestamp (0–59) (example: 55) [Date/Time]
- hh integer: Hour of timestamp (0–23) (example: 22) [Date/Time]
- dd integer: Day of timestamp (1–31) (example: 28) [Date/Time]
- mth integer: Month of timestamp (1-12) (example: 10) [Date/Time]
- yyyy integer: Year of timestamp (example: 2024) [Date/Time]
- mon string: The name of the month (example: Oct) [Date/Time]
- day string: The day of the week (example: Mon) [Date/Time]
- req_rulename string: Name of the rule that was applied to the DNS request (example: Private Access Resolver) [Transaction Action]
- req_action string: Name of the action that was applied to the DNS request (example: REQ_ALLOW REQ_BLOCK) [Transaction Action]
- res_rulename string: Name of the rule that was applied to the DNS response (example: Default Connector DNS Rule) [Transaction Action]
- res_action string: Name of the action that was applied to the DNS response (example: Allow) [Transaction Action]
- inbytes integer: Number of bytes sent from the server to the client. (example: 10,000) [Transaction Information]
- outbytes integer: Number of bytes sent from the client to the server. (example: 10,000) [Transaction Information]
- clt_ip string: The IP address of the user. This can be the internal IP address if it is visible—for example, traffic sent through a GRE tunnel or an internal IP address indicated using XFF. Otherwise, it's the client internet (NAT Public) IP address. (example: 192.0.2.135) [Transaction Information]
- req_duration integer: Duration of the DNS request in milliseconds (example: 65) [Transaction Information]
- resolver string: Server IP address of the request (example: 203.0.113.200) [Transaction Information]
- recordid integer: Unique record identifier for each log (example: sys_cloud_branch_id) [Transaction Information]
- location string: Gateway location or sublocation of the source (example: Headquarters) [Transaction Information]
- dom_str string: Fully Qualified Domain Name (FQDN) in the DNS request (example: mail.safemarch.com) [Transaction Information]
- odom_str string: Obfuscated FQDN in the DNS request [Transaction Information]
- res_type string: Response type [Transaction Information]
- resp_val_str string: Response value (example: 51.xx.192.49 blob.xxz21prdxxxx7a.store.core.windows.net) [Transaction Information]
- oresp_val_str string: Obfuscated response value [Transaction Information]
- req_type string: DNS record being requested (example: A record) [Transaction Information]
- srv_port integer: Server port of the request (example: 80) [Transaction Information]
- num_resp integer: Number of DNS responses (example: 52) [Transaction Information]
- dns_err string: DNS error, if any (example: DNS server not available NXDOMAIN SERVFAIL) [Transaction Information]
- protocol string: Protocol used (example: TCP UDP DOH) [Transaction Information]
- dnsgw_flags string: Flags indicating the DNS Gateway status (example: PRIMARY_SERVER_RESPONSE_PASS FO_DEST_ERR) [Transaction Information]
- dnsgw_slot string: DNS Gateway rule [Transaction Information]
- name string: Cloud Connector or Branch Connector name (example: CC_304) [Cloud Connector or Branch Connector Information]
- vm_name string: Cloud Connector or Branch Connector virtual machine (VM) name (example: zs-cc-vpc-xxxx) [Cloud Connector or Branch Connector Information]
- group_name string: Cloud Connector or Branch Connector group name (example: zs-cc-vpc-xxxx-us-west-2x) [Cloud Connector or Branch Connector Information]
- region_name string: Cloud Connector or Branch Connector region name (example: (US) West US 2) [Cloud Connector or Branch Connector Information]
- platform_name string: Cloud Connector or Branch Connector platform name (example: Azure) [Cloud Connector or Branch Connector Information]
- platformgeo_name string: Cloud Connector or Branch Connector platform geolocation name (availability zone) (example: San Jose, United States) [Cloud Connector or Branch Connector Information]
- account_id string: AWS account ID, or Azure subscription ID, or GCP project ID (example: 506xxx032xxx (AWS) f60abxxx-bb7d-43xx-84xx-4axxxx7xxxxx (Azure) gcs-xxx-cc-gcp-project (GCP)) [Cloud Connector or Branch Connector Information]
