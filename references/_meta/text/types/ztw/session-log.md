# Cloud & Branch Connector Session log (NSS feed) (ztw/session-log)
Also called: cloud connector session log; branch connector session log; cbc session logs
- time string: The log time (i.e., when the NSS logs a transaction) (example: Tue Nov 12 22:55:48 2024) [Date/Time]
- eventtime string: The time and date of the transaction. This excludes the time zone. (example: Tue Nov 12 22:55:48 2024) [Date/Time]
- tz string: The time zone. This is the same as the time zone you specified when you configured the NSS feed. (example: GMT) [Date/Time]
- ss integer: Second of timestamp (0–59) (example: 48) [Date/Time]
- mm integer: Minute of timestamp (0–59) (example: 55) [Date/Time]
- hh integer: Hour of timestamp (0–23) (example: 22) [Date/Time]
- dd integer: Day of timestamp (1–31) (example: 12) [Date/Time]
- mth integer: Month of timestamp (1-12) (example: 11) [Date/Time]
- yyyy integer: Year (example: 2024) [Date/Time]
- mon string: The name of the month (example: Nov) [Date/Time]
- day string: The day of the week (example: Tue) [Date/Time]
- clt_dst_name string: Client destination host name (example: Hostname) [Client Information]
- oclt_dest_name string: Obfuscated client destination host name [Client Information]
- clt_src_ip string: Client source IPv4 address. For aggregated sessions, this is the client source IP address of the last session in the aggregate. (example: 192.0.2.6) [Client Information]
- clt_src_port integer: Client source port. For aggregated sessions, this is the client source port of the last session in the aggregate. (example: 22) [Client Information]
- clt_dst_ip string: Client destination IPv4 address. For aggregated sessions, this is the client destination IP address of the last session in the aggregate. (example: 192.0.2.184) [Client Information]
- clt_dst_port integer: Client destination port. For aggregated sessions, this is the client destination port of the last session in the aggregate. (example: 80) [Client Information]
- fwdtypename string: Traffic forwarding method used to send the traffic to the firewall (example: L2 tunnel) [Client Information]
- zapptunname string: Zscaler Client Connector tunnel name used to send the traffic to the firewall [Client Information]
- srv_dst_port integer: Server destination port. For aggregated sessions, this is the server destination port of the last session in the aggregate. (example: 443) [Server Information]
- gw_dst_port integer: Gateway destination port (example: 443) [Server Information]
- zia_src_port integer: Internet & SaaS source port (example: 443) [Server Information]
- srv_dst_ip string: Server destination IPv4 address. For aggregated sessions, this is the server destination IP address of the last session in the aggregate. (example: 203.0.113.199) [Server Information]
- gw_name string: Gateway name (example: FWD_1) [Server Information]
- ogw_name string: Obfuscated gateway name [Server Information]
- gw_dst_ip string: Gateway destination IPv4 address (example: 203.0.113.1) [Server Information]
- zia_src_ip string: Internet & SaaS source IPv4 address (example: 198.51.100.48) [Server Information]
- srv_src_ip string: Server source IPv4 address. For aggregated sessions, this is the server source IP address of the last session in the aggregate. (example: 203.0.113.64) [Server Information]
- srv_src_port integer: Server source port. For aggregated sessions, this is the server source port of the last session in the aggregate. (example: 22) [Server Information]
- srv_ip_country string: Abbreviated code of the country of the server IP address (example: USA) [Server Information]
- session_duration integer: Session duration in milliseconds (example: 600,000) [Session Information]
- num_sess integer: Number of sessions (example: 36) [Session Information]
- num_aggr_sess integer: Number of sessions that were aggregated (example: 5) [Session Information]
- aggrname string: Type of aggregation [Session Information]
- rdrrulename string: Name of redirect rule that was applied to the transaction (example: FWD_Rule_1) [Forwarding Control]
- ordrrulename string: Obfuscated redirect rule name [Forwarding Control]
- self_rulename string: Cloud Connector or Branch Connector self-rule name that was applied to the transaction (example: CONNECTOR_SELF) [Forwarding Control]
- oself_rulename string: Obfuscated Cloud Connector or Branch Connector self rule name (example: AVG) [Forwarding Control]
- clt_tx_bytes integer: Number of bytes sent from the server to the client (example: 10,000) [Transaction Information]
- clt_rx_bytes integer: Number of bytes sent from the client to the server (example: 10,000) [Transaction Information]
- nw_service string: The network service that was used (example: HTTP) [Transaction Information]
- traffic_type string: Traffic type (example: INTERNAL) [Transaction Information]
- clt_nw_protocol string: Client network protocol (example: TCP) [Transaction Information]
- srv_nw_protocol string: Server network protocol (example: TCP) [Transaction Information]
- zia_gw_protocol string: Internet & SaaS gateway protocol [Transaction Information]
- zpa_appseg string: Private Access application segment (example: Any) [Transaction Information]
- name string: Cloud Connector or Branch Connector name (example: CC_304) [Cloud & Branch Connector Information]
- vm_name string: Cloud Connector or Branch Connector virtual machine (VM) name (example: zs-cc-vpc-xxxx) [Cloud & Branch Connector Information]
- group_name string: Cloud Connector or Branch Connector group name (example: zs-cc-vpc-xxxx-us-west-2x) [Cloud & Branch Connector Information]
- region_name string: Cloud Connector or Branch Connector region name (example: (US) West US 2) [Cloud & Branch Connector Information]
- location string: Cloud Connector or Branch Connector location (example: Headquarters) [Cloud & Branch Connector Information]
- platform_name string: Cloud Connector or Branch Connector platform name (example: Azure) [Cloud & Branch Connector Information]
- platformgeo_name string: Cloud Connector or Branch Connector platform geolocation name (availability zone) (example: San Jose, United States) [Cloud & Branch Connector Information]
- account_id string: Amazon Web Services (AWS) account ID, Microsoft Azure subscription ID, or Google Cloud Platform (GCP) project ID (example: 506xxx032xxx (AWS) f60abxxx-bb7d-43xx-84xx-4axxxx7xxxxx (Azure) gcs-xxx-cc-gcp-project (GCP)) [Cloud & Branch Connector Information]
