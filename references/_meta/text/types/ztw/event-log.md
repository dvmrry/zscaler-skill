# Cloud & Branch Connector Event log (NSS feed) (ztw/event-log)
Also called: cloud connector event log; branch connector event log; cbc event logs
- inteventtime integer: Event time in epoch format (example: 1687170925) [Date/Time]
- abstime integer: Event time if logs are delayed (example: 0) [Date/Time]
- time string: Time at which events are generated (example: Mon Oct 14 03:35:25 2024) [Date/Time]
- tz string: Time zone specified when configuring the NSS feed (example: GMT) [Date/Time]
- ss integer: Second of timestamp (0–59) (example: 25) [Date/Time]
- mm integer: Minute of timestamp (0–59) (example: 35) [Date/Time]
- hh integer: Hour of timestamp (0-23) (example: 03) [Date/Time]
- dd integer: Day of timestamp (1–31) (example: 14) [Date/Time]
- mth integer: Month of timestamp (1-12) (example: 10) [Date/Time]
- yyyy integer: Year of timestamp (example: 2024) [Date/Time]
- day string: Name of the day (example: Mon) [Date/Time]
- mon string: Name of the month (example: Oct) [Date/Time]
- rtime string: Log time at which NSS receives the logs (example: Mon Oct 14 03:35:28 PDT 2024) [Date/Time]
- rmon string: Name of the month (example: Oct) [Date/Time]
- company string: Company name (example: Test2) [Metadata]
- location string: Location name (example: TempLoc) [Metadata]
- name string: Cloud Connector or Branch Connector name (example: Instance 5) [Metadata]
- vm_name string: Cloud Connector or Branch Connector virtual machine (VM) name (example: zs-cc-vps-xxxx) [Metadata]
- group_name string: Cloud Connector or Branch Connector group name (example: zs-cc-vpc-xxxx-us-east-2-x) [Metadata]
- platform_name string: Cloud Connector or Branch Connector platform name (example: AWS) [Metadata]
- platformgeo_name string: Cloud Connector or Branch Connector platform geolocation name (example: Columbus, United States) [Metadata]
- region_name string: Region name (example: vk_location-us-east-2-x) [Metadata]
- connector_type string: The type of connector (example: CC) [Metadata]
- event_name string: Event type (example: VM_HEALTH ZIA_TUNNEL ZIA_GW SVC_HEALTH_CHK INST_HEALTH_CHK CTL_PLANE DATA_PLANE UPGRADE_ST UPGRADE_END) [Metadata]
- category string: Category (example: TRAFF_FWD CONN_VM CONN_INST) [Metadata]
- severity string: Severity (example: ERR INFO WARN) [Metadata]
- attr1_name string: Attribute 1 name, Attribute 1 string value (example: prev_state, Inactive) [Events]
- attr1_val string: Attribute 1 name, Attribute 1 string value (example: prev_state, Inactive) [Events]
- attr2_name string: Attribute 2 name, Attribute 2 string value (example: curr_state, Active) [Events]
- attr2_val string: Attribute 2 name, Attribute 2 string value (example: curr_state, Active) [Events]
- attr3_name string: Attribute 3 name, Attribute 3 string value (example: gid, 613x53) [Events]
- attr3_val string: Attribute 3 name, Attribute 3 string value (example: gid, 613x53) [Events]
- attr4_name string: Attribute 4 name, Attribute 4 string value (example: gwip, 192.0.2.1) [Events]
- attr4_val string: Attribute 4 name, Attribute 4 string value (example: gwip, 192.0.2.1) [Events]
- error_code string: Error code (if any) (example: None) [Events]
- account_id string: Account ID (alphanumeric string) (example: subscription_id2) [Events]
