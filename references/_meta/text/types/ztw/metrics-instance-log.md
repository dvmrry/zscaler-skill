# Cloud & Branch Connector Metrics (Instance) log (NSS feed) (ztw/metrics-instance-log)
Also called: cloud connector instance metrics log; cbc instance metrics
- tz string: The time zone. This is the time zone you specified when you configured the NSS feed. (example: GMT) [Date/Time]
- time string: Time at which events are generated (example: Thu Nov 14 11:39:59 2024) [Date/Time]
- eventtime string: The time and date of the transaction. This excludes the time zone. (example: Thu Nov 14 11:39:59 2024) [Date/Time]
- inteventtime integer: Event time in epoch format (example: 1691667599) [Date/Time]
- ss integer: Second of timestamp (0–59) (example: 59) [Date/Time]
- mm integer: Minute of timestamp (0–59) (example: 39) [Date/Time]
- hh integer: Hour of timestamp (0–23) (example: 11) [Date/Time]
- dd integer: Day of timestamp (1 –31) (example: 14) [Date/Time]
- mth integer: Month of timestamp (1-12) (example: 11) [Date/Time]
- yyyy integer: Year of timestamp (example: 2024) [Date/Time]
- day string: Name of the day (example: Thu) [Date/Time]
- mon string: Name of the month (example: Nov) [Date/Time]
- rtime string: Log time at which NSS receives logs (example: Thu Nov 14 11:40:33 2024) [Date/Time]
- rss integer: Second of timestamp (0–59) (example: 33) [Date/Time]
- rmm integer: Minute of timestamp (0–59) (example: 40) [Date/Time]
- rhh integer: Hour of timestamp (0–23) (example: 11) [Date/Time]
- rdd integer: Day of timestamp (1–31) (example: 14) [Date/Time]
- rmth integer: Month of timestamp (1-12) (example: 11) [Date/Time]
- ryyyy integer: Year of timestamp (example: 2024) [Date/Time]
- rday string: Name of the day (example: Thu) [Date/Time]
- rmon string: Name of the month (example: Nov) [Date/Time]
- recordid string: Unique record identifier for each log (example: sys_cloud_branch_id) [Metadata]
- location string: Location name (example: bc-location-0) [Metadata]
- group_name string: Group name (example: bc-group-0) [Metadata]
- vm_name string: VM name (example: bc-group-0-VM-yVIbR) [Metadata]
- platform_name string: Platform name (example: VMware ESXi) [Metadata]
- platformgeo_name string: Platform geolocation name (example: N/A) [Metadata]
- region_name string: Region name (example: N/A) [Metadata]
- connector_type string: Connector type (example: Branch Connector) [Metadata]
- instance_name string: Instance name (example: bc-group-0-VM-y VIbR_INSTANCE_1_3jHxn) [Metadata]
- icpu string: CPU utilization for the data-processing instance (example: 0.12) [Metrics]
- imem string: Memory utilization for the data-processing instance (example: 2746220544) [Metrics]
- ithroughput_tx string: Throughput in bytes per second for the data transferred out from the instance (example: 2685) [Metrics]
- ithroughput_rx string: Throughput in bytes per second for the data that the instance received (example: 3434) [Metrics]
- ziathroughput_tx string: Throughput in bytes per second for the data sent to Internet & SaaS from the instance (example: 1542) [Metrics]
- ziathroughput_rx string: Throughput in bytes per second for the data that the instance received from Internet & SaaS (example: 2658) [Metrics]
- nodata string: Data not available (example: False) [Metrics]
