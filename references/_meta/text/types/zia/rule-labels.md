# zia/rule-labels (zia/rule-labels)
- Names: zscalerctl `zia rule-labels`; terraform `zia_rule_labels`; terraform_data_source `zia_rule_labels`
- Live read (read-only): `zscalerctl zia rule-labels list`
- createdBy
- description string: The rule label description.
- id integer: The unique identifier for the rule label.
- lastModifiedBy
- lastModifiedTime integer: Timestamp when the rule label was last modified.
- name string: The rule label name.
- referencedRuleCount integer: The number of rules that reference the label.
