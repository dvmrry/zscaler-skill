# ZIA tunnel log (NSS tunnel feed) (zia/tunnel-log)
Also called: nss tunnel log; zia tunnel logs; tunnel insights logs
- Names: nss `tunnel`
- datetime (Logged Time) string: The date and time of the event [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- tz string: The time zone. This is the same as the time zone you specified when you configured the NSS feed. [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- ss integer: Seconds (0–59) (Insights: This field is derived from Logged Time) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- mm integer: Minutes (0–59) (Insights: This field is derived from Logged Time) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- hh integer: Hours (0–23) (Insights: This field is derived from Logged Time) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- dd integer: The day of the month (1–31) (Insights: This field is derived from Logged Time) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- mth integer: The month of the year (Insights: This field is derived from Logged Time) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- yyyy integer: Year (Insights: This field is derived from Logged Time) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- mon string: The name of the month (Insights: This field is derived from Logged Time) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- day string: The day of the week (Insights: This field is derived from Logged Time) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- tunnelactionname (Log Type) string: Internet Key Exchange (IKE) Phase 1: Equals WL_TUNNEL_IPSECPHASE1 for this record type; IKE Phase 2: Equals WL_TUNNEL_IPSECPHASE2 for this record type; Tunnel Events: Equals WL_TUNNEL_EVENT for this record type; Tunnel Samples: Equals WL_TUNNEL_SAMPLES for this record type [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- vpncredentialname (VPN Credential) string: The VPN credential name for the IPSec tunnel [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- locationname (Location) string: The location name [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- destvip (Tunnel Destination IP) string: Internet Key Exchange (IKE) Phase 1: The tunnel destination VIP address; Tunnel Events: The destination VIP address [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- sourceip (Tunnel Source IP) string: Internet Key Exchange (IKE) Phase 1: The tunnel source IP address; Tunnel Events: The source IP address [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- lifetime (Tunnel Lifetime) integer: Internet Key Exchange (IKE) Phase 1: The lifetime of IKE Phase 1 (seconds); IKE Phase 2: The lifetime of IKE Phase 2 (seconds) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2]
- spi_in (Initiator Cookie) string: The initiator cookie [Internet Key Exchange (IKE) Phase 1]
- spi_out (Responder Cookie) string: The responder cookie [Internet Key Exchange (IKE) Phase 1]
- srcport (Tunnel Source Port) integer: Internet Key Exchange (IKE) Phase 1: The tunnel source port; Tunnel Events: The source port [Internet Key Exchange (IKE) Phase 1, Tunnel Events, Tunnel Samples]
- dstport (Tunnel Destination Port) integer: The tunnel destination port [Internet Key Exchange (IKE) Phase 1]
- algo (Encryption Algorithm) string: The encryption algorithm [Internet Key Exchange (IKE) Phase 1, IKE Phase 2]
- authentication (Authentication Algorithm) string: The authentication algorithm [Internet Key Exchange (IKE) Phase 1, IKE Phase 2]
- authtype (Authentication Type) string: The authentication type [Internet Key Exchange (IKE) Phase 1, IKE Phase 2]
- vendorname (Vendor ID) string: The vendor name of the edge device [Internet Key Exchange (IKE) Phase 1]
- ikeversion integer: The IKE version (1 or 2) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2]
- recordid integer: The unique record identifier for each log (Insights: This field is specific to NSS) [Internet Key Exchange (IKE) Phase 1, IKE Phase 2, Tunnel Events, Tunnel Samples]
- spi (IKE Phase 2 SPI) integer: The Security Parameter Index (SPI) [IKE Phase 2]
- destipstart (P2 Policy Dest IP - Start) string: Phase 2 policy proposal - Destination IP start [IKE Phase 2]
- destipend (P2 Policy Dest IP - End) string: Phase 2 policy proposal - Destination IP end [IKE Phase 2]
- srcipstart (P2 Policy Src IP - Start) string: Phase 2 policy proposal - Source IP start [IKE Phase 2]
- srcipend (P2 Policy Src IP - End) string: Phase 2 policy proposal - Source IP end [IKE Phase 2]
- srcportstart (P2 Policy Src Port - Start) integer: Phase 2 policy proposal - Source port start [IKE Phase 2]
- destportstart (P2 Policy Dest Port - End) integer: Phase 2 policy proposal - Destination port start [IKE Phase 2]
- lifebytes (Life Bytes) integer: Life bytes. The amount of traffic to be transacted through a tunnel before renegotiation. [IKE Phase 2]
- tunnelprotocol (IPSec Protocol) string: The IPSec tunnel protocol type. Zscaler only supports ESP. [IKE Phase 2]
- protocol (P2 Policy Protocol) string: Phase 2 policy proposal - Protocol [IKE Phase 2]
- tunneltype (Tunnel Type) string: The tunnel type [Tunnel Events, Tunnel Samples]
- event (Tunnel Status) string: The tunnel status [Tunnel Events]
- eventreason (Event Reason) string: The reason for the tunnel status change [Tunnel Events]
- txbytes (Sent Bytes) string: The bytes transmitted in a 60-second sample window from Zscaler to the customer [Tunnel Samples]
- rxbytes (Received Bytes) string: The bytes received in a 60-second sample window by Zscaler from the customer [Tunnel Samples]
- txpackets (Sent Packets) integer: The packets transmitted in a 60-second sample window from Zscaler to the customer [Tunnel Samples]
- rxpackets (Received Packets) integer: The packets received in a 60-second sample window by Zscaler from the customer [Tunnel Samples]
- dpdrec (Keep Alive Packets) integer: The number of DPD packets received in a 60-second sample window. Only for IPSec tunnels, empty for GRE. [Tunnel Samples]
