# ZIA Posture Management log (NSS Posture Management feed) (zia/posture-management-log)
Also called: nss posture management log; zia posture management logs
- Names: nss `posture-management`
- time string: The time that the alert was sent
- recordid integer: The unique record identifier
- platformname string: The name of the application associated with the posture control
- tenant string: The name of the onboarded tenant
- tenantlabel string: The labels that you created and associated with the tenant
- controltitle string: The title of the posture control
- controlid string: The unique ID of the posture control
- categories string: The category of the posture control
- severity string: The severity of the posture control
- compliance string: The compliance frameworks applicable to the posture control
- status string: The status of the posture control
- remediationaction string: Indicates if any remediation action was done
