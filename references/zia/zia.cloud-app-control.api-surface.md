**Application entries.** {{app-entry-fields}} {{val-echoed}} When an app's behavior under a rule changes unexpectedly, look at these flags on the app entry, but only as a lead: what they mean is not documented (gap `flag-meanings`). The reference and the SDKs also disagree on the request shape for application entries (divergence `cloud-apps-element-shape`); see [[zia.cloud-app-control.actions]] for how discovery is used in practice.

**Duplicating a rule.** The Go SDK's `CreateDuplicate` cannot send a request, so it is not a way to clone a rule: [[zia.sdk-go.service-defects]]. {{python-duplicate-exists}} Whether the Python call works against a tenant is not shown by any source; the alternative is to read the rule and create a new one with the scope changed.
